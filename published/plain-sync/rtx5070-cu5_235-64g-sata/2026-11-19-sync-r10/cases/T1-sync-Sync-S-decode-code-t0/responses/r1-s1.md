# 単語出現頻度集計ツール

以下に、テキストファイルを読み込み、単語の出現頻度を上位 N 件を表形式で表示するコマンドラインツールを提示します。

## 実装ファイル: `word_freq.py`

```python
"""
word_freq.py - テキストファイルの単語出現頻度を上位 N 件で表示する CLI ツール。

使い方:
    python word_freq.py input.txt -n 10
    python word_freq.py input.txt -n 5 --case-sensitive
"""

from __future__ import annotations

import argparse
import re
import sys
from collections import Counter
from pathlib import Path
from typing import List, Tuple


def tokenize(text: str, case_sensitive: bool = False) -> List[str]:
    """
    テキストから単語を抽出する。

    Args:
        text: 入力テキスト。
        case_sensitive: True の場合、大文字・小文字を区別する。

    Returns:
        単語のリスト（正規化済み）。
    """
    if not case_sensitive:
        text = text.lower()
    # 英数字とハイフンを含むトークンを抽出
    tokens = re.findall(r"[a-zA-Z0-9]+(?:-[a-zA-Z0-9]+)*", text)
    return tokens


def count_words(text: str, case_sensitive: bool = False) -> Counter[str]:
    """
    テキスト内の単語出現頻度をカウントする。

    Args:
        text: 入力テキスト。
        case_sensitive: 大文字・小文字の区別有無。

    Returns:
        単語 -> 出現回数の Counter。
    """
    tokens = tokenize(text, case_sensitive=case_sensitive)
    return Counter(tokens)
