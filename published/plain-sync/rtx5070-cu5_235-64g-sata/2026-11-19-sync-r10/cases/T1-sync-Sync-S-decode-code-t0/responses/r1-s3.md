# 単語出現頻度集計ツール

以下に、テキストファイルを読み込み、単語の出現頻度を上位 N 件を表形式で表示するコマンドラインツールを、`argparse`・型ヒント・docstring・pytest テスト付きで実装します。

## 実装ファイル: `word_freq.py`

"""
word_freq.py - テキストファイルの単語出現頻度を上位 N 件で表形式表示する CLI ツール。

使い方:
    python word_freq.py input.txt
    python word_freq.py input.txt -n 10
    python word_freq.py input.txt -n 5 --case-sensitive
    python word_freq.py input.txt --sort-by count
"""

from __future__ import annotations

import argparse
import sys
from collections import Counter
from pathlib import Path
from typing import List, Tuple


def tokenize(text: str, case_sensitive: bool = False) -> List[str]:
    """
    テキストから単語を抽出する。

    Args:
        text: 入力テキスト。
        case_sensitive: True の場合、大文字小文字を区別する。

    Returns:
        単語のリスト（句読点や空白は除去される）。
    """
    if not case_sensitive:
        text = text.lower()

    # 英数字とハイフン、アポストロフィを単語の一部として扱い、
    # それ以外は区切り文字として扱う
    import re
    words = re.findall(r"[a-zA-Z0-9]+(?:[-'][a-zA-Z0-9]+)*", text)
    return words


def count_words(text: str, case_sensitive: bool = False) -> Counter[str]:
    """
    テキスト内の単語出現頻度をカウントする。

    Args:
        text: 入力テキスト。
        case_sensitive: True の場合、大文字小文字を区別する。

    Returns:
        単語をキー、出現回数を値とする Counter。
    """
    words = tokenize(text, case_sensitive=case_sensitive)
    return Counter(words)
