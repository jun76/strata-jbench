word_freq.py: テキストファイルから単語の出現頻度を計算し、上位N件を表示するツール。

オプション:

def count_words(text: str, case_insensitive: bool = False, min_length: int = 1) -> Counter:
    """
    テキスト内の単語を抽出し、出現回数をカウントする。

    Args:
        text: 解析対象のテキスト
        case_insensitive: Trueの場合、大文字小文字を区別しない
        min_length: 集計対象にする単語の最小文字数

    Returns:
        Counter: 単語 -> 出現回数のマッピング
    """
    # 正規表現で単語を抽出 (アルファベット、数字、ハイフンを含む)
    # \b\w+\b は日本語や一部の記号を拾わないが、一般的な英単語抽出には十分
    # より広範なサポートが必要な場合は \p{L}+ などが使えるが、標準ライブラリにはないため \w+ を使用
    pattern = r"\b\w+\b"
    words = re.findall(pattern, text)

    if case_insensitive:
        words = [w.lower() for w in words]

    # 長さでフィルタリング
    words = [w for w in words if len(w) >= min_length]

    return Counter(words)
