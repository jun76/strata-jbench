与えられた条件を整理して、5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の到着順を推論します。

**1. 条件の整理**
*   (1) ハルト < ミズキ （ハルトはミズキより前）
*   (2) ユイ $\neq$ 1位, 5位 （ユイは2, 3, 4位のいずれか）
*   (3) ソウタはアオイのすぐ後 （アオイの位置を $n$ とすると、ソウタは $n+1$）
*   (4) ミズキ $\neq$ 3位
*   (5) アオイ > ユイ （アオイはユイより後）
*   (6) ハルト $\neq$ 2位
*   (7) ミズキ $\neq$ 5位

**2. 推論プロセス**

**ステップ1: ハルトとミズキの位置を考えます。**
*   (1) より、ハルトはミズキより前です。
*   (4) より、ミズキは3位ではありません。
*   (7) より、ミズキは5位ではありません。
    *   したがって、ミズキの可能性がある順位は 2位 または 4位 です。

    **ケースA: ミズキが2位のとき**
    *   (1) ハルト < ミズキ(2位) なので、ハルトは1位です。
    *   この場合、1位: ハルト、2位: ミズキ となります。
    *   (6) ハルトは2位ではない、という条件を満たしています。
    *   残りの順位は 3位, 4位, 5位 です。
    *   人物は アオイ, ソウタ, ユイ です。
    *   (3) ソウタはアオイのすぐ後。つまり [アオイ, ソウタ] のペアが連続している必要があります。
        *   残りの枠に連続するペアを入れると、
        *   [3位: アオイ, 4位: ソウタ] の組み合わせか、
        *   [4位: アオイ, 5位: ソウタ] の組み合わせしかあり得ません。
    *   **サブケースA1: 3位: アオイ, 4位: ソウタ の場合**
        *   残りの5位は ユイ になります。
        *   しかし、(2) 「ユイは5位ではない」という条件に矛盾するため、このパターンは却下されます。
    *   **サブケースA2: 4位: アオイ, 5位: ソウタ の場合**
        *   残りの3位は ユイ になります。
        *   (2) ユイは3位でもよい（1位でも5位でもない）のでOK。
        *   (5) アオイ(4位) > ユイ(3位) はOK。
        *   この場合の並びは:
            1. ハルト
            2. ミズキ
            3. ユイ
            4. アオイ
            5. ソウタ
        *   他の条件を確認:
            *   ハルト(1) < ミズキ(2) OK
            *   ユイ(3) $\neq$ 1,5 OK
            *   ソウタ(5) は アオイ(4) のすぐ後 OK
            *   ミズキ(2) $\neq$ 3 OK
            *   アオイ(4) > ユイ(3) OK
            *   ハルト(1) $\neq$ 2 OK
            *   ミズキ(2) $\neq$ 5 OK
        *   **このケースは有効です。この場合、3位は「ユイ」です。**

    **ケースB: ミズキが4位のとき**
    *   (1) ハルト < ミズキ(4位) なので、ハルトは 1, 2, 3位のいずれか。
    *   (6) ハルト $\neq$ 2位 なので、ハルトは 1位 または 3位。
    *   残りの人物は アオイ, ソウタ, ユイ, ハルト です。
    *   (3) [アオイ, ソウタ] のペアが連続。

    *   **サブケースB1: ハルトが1位の場合**
        *   1位: ハルト, 4位: ミズキ。
        *   残りの順位: 2, 3, 5。人物: アオイ, ソウタ, ユイ。
        *   [アオイ, ソウタ] が連続する可能性:
            *   [2位: アオイ, 3位: ソウタ] -> 残りは5位: ユイ。 -> (2) ユイは5位NG。却下。
            *   [3位: アオイ, 4位: ソウタ] -> 4位はミズキで確定済み。矛盾。却下。
            *   [4位: アオイ, 5位: ソウタ] -> 4位はミズキで確定済み。矛盾。却下。
        *   よって、ハルトが1位のサブケースは成立しない。

    *   **サブケースB2: ハルトが3位の場合**
        *   3位: ハルト, 4位: ミズキ。
        *   残りの順位: 1, 2, 5。人物: アオイ, ソウタ, ユイ。
        *   [アオイ, ソウタ] が連続する可能性:
            *   [1位: アオイ, 2位: ソウタ] -> 残りは5位: ユイ。 -> (2) ユイは5位NG。却下。
            *   [2位: アオイ, 3位: ソウタ] -> 3位はハルトで確定済み。矛盾。却下。
        *   よって、ハルトが3位のサブケースも成立しない。

    *   **その他のミズキが4位の場合の検討:**
        *   もしミズキが4位で、ハルトが1位でも3位でもない場合、(6)と(1)によりハルトの位置は制限されますが、上記で網羅済みです。
        *   さらに、(5) アオイ > ユイ による制約も考慮する必要がありますが、上記の矛盾検出によりケースB全体が成立しないことが分かります。

    *   **念のため、ケースA以外の可能性を検討:**
        *   ミズキが2位のケース（ケースA）で、サブケースA1が却下され、サブケースA2が採用されました。
        *   ミズキが4位のケース（ケースB）では、[アオイ, ソウタ]の連続ペアを配置できる枠が、残りの3枠（1,2,5 or 1,2,5）に収まらない、またはユイが5位になるなどの制約に反しました。

        Let's re-verify Case B just to be absolutely sure.
        Positions: 1, 2, 3, 4, 5
        Mizuki = 4.
        Hardt < Mizuki => Hardt is 1, 2, or 3.
        Hardt != 2 => Hardt is 1 or 3.
        
        If Hardt = 1:
        Remaining spots: 2, 3, 5. People: Aoi, Souta, Yui.
        Aoi/Souta must be adjacent.
        Option 1: Aoi=2, Souta=3. Then Yui=5. But Yui!=5. Invalid.
        Option 2: Aoi=3, Souta=4. But 4 is Mizuki. Invalid.
        Option 3: Aoi=4, Souta=5. But 4 is Mizuki. Invalid.
        So Hardt!=1.

        If Hardt = 3:
        Remaining spots: 1, 2, 5. People: Aoi, Souta, Yui.
        Aoi/Souta must be adjacent.
        Option 1: Aoi=1, Souta=2. Then Yui=5. But Yui!=5. Invalid.
        Option 2: Aoi=2, Souta=3. But 3 is Hardt. Invalid.
        So Hardt!=3.

        Thus, Mizuki cannot be 4th.

    *   **結論:**
        ミズキは2位で、ハルトは1位です。
        ユイは3位、アオイは4位、ソウタは5位です。
        
        到着順:
        1. ハルト
        2. ミズキ
        3. ユイ
        4. アオイ
        5. ソウタ
