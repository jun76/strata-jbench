## 1. レコードの構造

このレコードは、次のような構造になっています。

- ID: `record000001` のように、`record` という接頭辞と、連番の番号を 6 桁で持っています。
- 内容: `alpha beta gamma delta epsilon zeta eta theta` という 8 個の単語が順に並んでいます。

つまり、各レコードは「ID」と「内容」の 2 つの部分から構成されています。

- ID は検索キーとして使われます。
- 内容はデータ本体として使われます。

この形は、次のようなデータ管理に向いています。

- レコードを一意に識別したい
- ID から内容を取り出したい
- たくさんのレコードを効率よく検索したい

## 2. ID からレコードを探す手順

ID からレコードを探す手順は、次のようになります。

### 手順 1: ID を正規化する

まず、探したい ID を受け取します。

例えば、

`record000123`

のように、ID は文字列として扱われます。

### 手順 2: ID をキーとして使う

次に、ID をキーとして、レコードを探します。

たとえば、次のような方法が考えられます。

- 辞書（dictionary）やハッシュテーブルに `record000123 -> 内容` を保存する
- ID を主キーとして、データベースで検索する
- インデックスファイルを使って、ID とレコードの位置を結びつける

### 手順 3: 一致するレコードを取得する

ID に一致するレコードが見つかれば、その内容を取り出します。

`record000123`
