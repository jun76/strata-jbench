If the prize is in A, then labels A and C cannot both be false (A true, C false), and B would be true (prize not in B), giving two true labels. If the prize is in C, then A and C would both be false? Let's just use the complements.

Labels A and C are opposites: A says prize in A; C says prize not in A. So exactly one of A and C is true. Since exactly one label overall is true, label B must be false. B false means the prize is in box B.

Answer: B
