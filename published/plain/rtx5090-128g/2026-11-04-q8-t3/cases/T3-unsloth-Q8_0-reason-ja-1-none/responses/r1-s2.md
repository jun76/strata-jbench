この論理パズルを解くために、5人の到着順（1位から5位）を確定させていきます。

与えられた条件は以下の通りです。
1. ハルト < ミズキ （ハルトはミズキより前）
2. ユイ ≠ 1位, 5位
3. ソウタ = アオイ + 1 （ソウタはアオイのすぐ後）
4. ミズキ ≠ 3位
5. アオイ > ユイ （アオイはユイより後）
6. ハルト ≠ 2位
7. ミズキ ≠ 5位

**ステップ1: ミズキの順位を絞り込む**
条件1（ハルト < ミズキ）、条件4（ミズキ ≠ 3位）、条件7（ミズキ ≠ 5位）より、ミズキになれる順位は1位、2位、4位です。
しかし、条件1より「ハルトはミズキより前」なので、ミズキが1位になることはできません（その前に誰もいないため）。
したがって、**ミズキは2位または4位**です。

**ステップ2: ハルトの順位を絞り込む**
条件6（ハルト ≠ 2位）と条件1（ハルト < ミズキ）を考慮します。

*   **ケースA: ミズキが2位の場合**
    ハルトはミズキより前なので、ハルトは1位でなければなりません。
    このとき、残り順位は3位、4位、5位で、残った人はアオイ、ソウタ、ユイです。
    条件3「ソウタはアオイのすぐ後」を満たすペア（アオイ、ソウタ）が連続している必要があります。
    残っている順位は3, 4, 5です。連続するペアは(3,4)または(4,5)です。
    *   もし(アオイ, ソウタ)が(3,4)なら、ユイは5位です。
        しかし条件2で「ユイは5位ではない」とあるので、これは不可能です。
    *   もし(アオイ, ソウタ)が(4,5)なら、ユイは3位です。
        条件5「アオイはユイより後」を確認します。アオイ(4) > ユイ(3) ですので、これは合致します。
        
        このケースでの順序は以下のようになります。
        1位: ハルト
        2位: ミズキ
        3位: ユイ
        4位: アオイ
        5位: ソウタ
        
        他の条件を確認します。
        - ハルト(1) < ミズキ(2) → OK
        - ユイ(3)は1位でも5位でもない → OK
        - ソウタ(5)はアオイ(4)のすぐ後 → OK
        - ミズキ(2)は3位ではない → OK
        - アオイ(4)はユイ(3)より後 → OK
        - ハルト(1)は2位ではない → OK
        - ミズキ(2)は最後ではない → OK
        
        このケースはすべての条件を満たします。この場合、3位は**ユイ**です。

    *   **ケースB: ミズキが4位の場合**
        ハルトはミズキ(4位)より前で、かつハルトは2位ではありません。
        したがって、ハルトは1位または3位です。
        
        *   サブケースB1: ハルトが1位の場合
            残り順位は2, 3, 5です。残った人はアオイ、ソウタ、ユイです。
            (アオイ, ソウタ)のペアは連続している必要があります。
            残った順位{2, 3, 5}の中で連続するペアはありません（2と3は連続ですが、もしアオイ=2, ソウタ=3ならユイは5位になるが、ユイは5位不可。もしアオイ=4,ソウタ=5ならミズキが4位なので衝突。そもそも残り枠が2,3,5なので(2,3)ペアしか作れません）。
            もし(アオイ, ソウタ)が(2,3)なら、ユイは5位になります。
            条件2「ユイは5位ではない」により、このサブケースは却下です。
        
        *   サブケースB2: ハルトが3位の場合
            この場合、ミズキは4位です。
            残り順位は1, 2, 5です。残った人はアオイ、ソウタ、ユイです。
            (アオイ, ソウタ)のペアは連続している必要があります。
            残った順位{1, 2, 5}の中で連続するペアは(1, 2)のみです。
            したがって、アオイ=1位、ソウタ=2位でなければなりません。
            すると、ユイは5位になります。
            しかし、条件2「ユイは5位ではない」により、これは矛盾します。
            また、条件5「アオイはユイより後」も確認しますが、アオイ(1) < ユイ(5) なのでこれも矛盾します。
            
            したがって、ミズキが4位になるケースはすべて成立しません。

**結論**
唯一成立するのは「ケースA」のみです。

到着順は以下の通りです。
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

3位に到着したのはユイです。

答え: ユイ
