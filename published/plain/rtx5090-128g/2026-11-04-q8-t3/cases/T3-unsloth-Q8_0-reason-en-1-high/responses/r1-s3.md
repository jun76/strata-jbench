If the prize is in Box A, then labels A and B would both be true, which violates “exactly one label is true.”

If the prize is in Box B, then label A is false, label B is false, and label C is true. Exactly one label is true.

If the prize is in Box C, then labels B and C would both be true, which violates the condition.

Therefore, the prize is in Box B.
