以下、ご提示いただいたレコード群の構造、ID からレコードを探す基本的な手順、そして件数が増えた場合に高速に検索するための工夫について、できるだけ詳しく説明します。

## 1. レコードの構造

### 1.1 各行の形式

すべての行はまったく同じ形式です：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると、以下の 3 要素で構成されています：

| 要素 | 内容 | 説明 |
|---|---|---|
| ① ID 部 | `record000001` | レコードを一意に識別する識別子 |
| ② 区切り | `: ` | ID と本文を分離するコロン＋半角スペース |
| ③ 本文部 | `alpha beta gamma delta epsilon zeta eta theta.` | 8 個のギリシャ文字アルファベットが半角スペースで並び、末尾にピリオド |

### 1.2 ID の構造

- 接頭辞：`record`（固定文字列）
- 数字部：6 桁のゼロ埋め十进制整数（`000001` ～ `000212` まで確認できます）
- 形式を正規表現で表すと：

```regex
^record\d{6}: [a-z]+ [a-z]+ [a-z]+ [a-z]+ [a-z]+ [a-z]+ [a-z]+ [a-z]+\.$
```

あるいはより正確に：

```regex
^record(\d{6}): alpha beta gamma delta epsilon zeta eta theta\.$
```

### 1.3 本文の構造

本文は常に同じ 8 トークンです：

```
alpha  beta  gamma  delta  epsilon  zeta  eta  theta
```

- 位置（インデックス）で見ると：

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |

- 末尾に `.` が付きます（theta の直後）。
- 本文は ID に依存しません（すべてのレコードで同一）。
