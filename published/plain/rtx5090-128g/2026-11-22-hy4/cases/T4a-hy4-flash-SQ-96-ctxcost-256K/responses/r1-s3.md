## 1. レコード構造の説明

### 1.1 全体形式

各レコードは次のような固定形式のテキスト行です：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると：

| 要素 | 内容 | 説明 |
|---|---|---|
| ID 部分 | `record000001` | レコード識別子（固定長・連番） |
| 区切り | `:` | ID と本文を分離 |
| 空白 | ` ` | 可読性のための区切り |
| 本文 | `alpha beta gamma delta epsilon zeta eta theta.` | 8 個のギリシャ文字名 + 末尾ピリオド |
| 改行 | `\n` | 1 レコード = 1 行 |

### 1.2 ID の特徴

- 接頭辞：`record`
- 数字部分：**6 桁ゼロ埋め**（例：`000001`, `000212`）
- 連番：1 から開始（観測範囲では 1〜212）
- 辞書順 = 数値順になるよう設計されている

> 重要なポイント  
> `record000010` < `record000011` < … < `record000100` の順になるため、**文字列ソートしても数値順が崩れません**。

### 1.3 本文の特徴

- トークン数：8 個（空白区切り）
- トークン一覧（常に同一順）：

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |

- 末尾に `.` が付与（9 トークン目ではない）
- 全レコードで本文は **完全に同一**

つまり、このデータセットは：

> **「構造は均一で、ID だけが異なる連番レコード集合」**

です。
