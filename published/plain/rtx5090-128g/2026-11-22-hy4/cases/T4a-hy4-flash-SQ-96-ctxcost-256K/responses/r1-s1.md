以下、提示されたレコード群の構造、ID からレコードを探す基本手順、そして件数が増えた場合に高速に検索するための工夫を、できるだけ詳しく説明します。

---

## 1. レコード構造の説明

### 1.1 各行のフォーマット

すべての行は完全に同一のパターンです：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると、以下の 3 要素で構成されています。

| 要素 | 内容 | 例 |
|---|---|---|
| ① ID 部 | `record` + 6 桁のゼロ埋め整数 + `:` | `record000001:` |
| ② 区切り | コロン `:` の直後の半角スペース 1 文字 | `: ` |
| ③ 本体（ペイロード） | 8 個のギリシャ文字名が半角スペースで連結され、末尾にピリオド | `alpha beta gamma delta epsilon zeta eta theta.` |

より形式的に書くと：

```
^record(\d{6}): (alpha beta gamma delta epsilon zeta eta theta)\.$
```

### 1.2 ID の特徴

- 接頭辞：`record`
- 数値部分：**6 桁固定・ゼロ埋め（zero-padding）**
  - `000001` → 1
  - `000212` → 212
- コロン `:` で ID と本体を分離
- 現在の最大 ID は `record000212`（全 212 件）

> 重要なポイント  
> 数値部分が常に 6 桁なので、**文字列比較しても数値比較と同じ順序になります**。  
> つまり `"record000010" < "record000002"` は起きず、辞書順＝番号順です。

### 1.3 本体の特徴

- トークン数：8
- トークン一覧（常に同一順）：

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
