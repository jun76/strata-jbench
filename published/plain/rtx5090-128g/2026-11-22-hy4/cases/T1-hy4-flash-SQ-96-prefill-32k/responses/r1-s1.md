The records are a simple, uniform list:

- Each line has the form: `recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.`
- The ID is a zero-padded 6-digit number, from `record000001` through `record001721`.
- Every record has the same payload/value: `alpha beta gamma delta epsilon zeta eta theta.`
- There is one record for each consecutive ID in that range, with no visible gaps.
