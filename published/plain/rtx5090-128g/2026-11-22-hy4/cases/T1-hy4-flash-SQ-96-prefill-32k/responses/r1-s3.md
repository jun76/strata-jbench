The records are a simple, uniform list:

- Each line has the form:  
  `recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.`
- The ID is the zero-padded number after `record`, e.g. `record000001`, `record001721`.
- Every record contains the same eight Greek-letter tokens in the same order:  
  `alpha beta gamma delta epsilon zeta eta theta`
- Each line ends with a period.
- The IDs shown run consecutively from `record000001` through `record001721`.
