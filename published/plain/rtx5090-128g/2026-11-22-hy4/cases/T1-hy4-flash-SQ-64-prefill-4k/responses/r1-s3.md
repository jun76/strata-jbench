The dataset is a simple numbered list of records.

Structure:

- Each line has the form:

  `recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta`

- The ID prefix is `record`.
- The numeric ID is a 6-digit zero-padded number, from `000001` through `000212`.
- Each record body contains the same eight Greek-letter tokens in the same order:
  `alpha beta gamma delta epsilon zeta eta theta`
- A colon separates the record ID from the record content.
- The records are listed sequentially in ascending numeric order.
