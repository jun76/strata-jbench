The records are a numbered list of identical entries.

Structure:

- Each line has the form: `recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.`
- IDs are zero-padded 6-digit numbers, from `record000001` through `record000212`.
- Every record contains the same eight Greek-letter tokens in the same order:
  1. alpha
  2. beta
  3. gamma
  4. delta
  5. epsilon
  6. zeta
  7. eta
  8. theta
- The content is identical across all records; only the ID
