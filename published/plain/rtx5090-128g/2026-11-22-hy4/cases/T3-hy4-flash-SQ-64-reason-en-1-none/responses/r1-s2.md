If the prize is in **A**:

- A’s label: “The prize is in this box.” → true  
- B’s label: “The prize is not in this box.” → true  
- C’s label: “The prize is not in box A.” → false  

That gives **two true labels**, so the prize cannot be in A.

If the prize is in **B**:

- A’s label → false  
- B’s label → false  
- C’s label → true  

Exactly one label is true, so this fits.

If the prize is in **C**:

- A’s label → false  
- B’s label → true  
- C’s label → true  

That gives **two true labels**, so the prize cannot be in C.

Answer: B
