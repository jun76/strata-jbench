Let’s check each possibility.

**Labels:**
- A: "The prize is in this box." → True if prize is in A.
- B: "The prize is not in this box." → True if prize is **not** in B.
- C: "The prize is not in box A." → True if prize is **not** in A.

We are told **exactly one label is true**.

---

**Case 1: Prize in A**  
- A: True (prize in A)  
- B: True (prize not in B)  
- C: False (prize in A → "not in A" is false)  
→ Two truths (A and B) → ❌

---

**Case 2: Prize in B**  
- A: False (prize not in A)  
- B: False (prize in B → "not in B" is false)  
- C: True (prize not in A)  
→ One truth (C) → ✅

---

**Case 3: Prize in C**  
- A: False (prize not in A)  
- B: True (prize not in B)  
- C: True (prize not in A)  
→ Two truths (B and C) → ❌

---

Only **Case 2** satisfies exactly one true label.

Answer: B
