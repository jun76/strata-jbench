If the prize were in A:

- A’s label “The prize is in this box” would be true.
- B’s label “The prize is not in this box” would be true.
- C’s label “The prize is not in box A” would be false.

That gives two true labels, so the prize is not in A.

If the prize were in B:

- A’s label would be false.
- B’s label “The prize is not in this box” would be false.
- C’s label “The prize is not in box A” would be true.

That gives exactly one true label.

If the prize were in C:

- A’s label would be false.
- B’s label would be true.
- C’s label would be true.

That gives two true labels.

Answer: B
