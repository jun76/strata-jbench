## 1. レコードの構造の説明

### 1.1 全体フォーマット

各レコードは以下のような 1 行テキストです：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると、以下の 3 つの要素に分けられます。

| 要素 | 内容 | 例 |
|---|---|---|
| ① ID 部分 | `record` + 6 桁のゼロ埋め整数 + `:` | `record000001:` |
| ② 区切り | コロン `:` と半角スペース 1 つ | `: ` |
| ③ 本文 | 8 つのギリシャ文字名が半角スペースで並び、末尾にピリオド `.` | `alpha beta gamma delta epsilon zeta eta theta.` |

つまり、一般形は次のように表せます。

```
record{NNNNNN}: alpha beta gamma delta epsilon zeta eta theta.
```

ここで `NNNNNN` は 1 から始まる 6 桁の十進数（ゼロ埋め）です。

---

### 1.2 ID の特徴

- 接頭辞は常に `record`
- 数字部分は **6 桁固定**
  - `000001`, `000002`, …, `000212`
- 末尾にコロン `:` が付く
- 数字はレコードの出現順と一致している
  - `record000001` が 1 行目
  - `record000212` が 212 行目

このため、ID は「連番＋固定幅」になっており、**文字列として並べ替えても数値順と同じ** という重要な性質があります。

例：

```
record000009 < record000010 < record000100 < record000212
```

これは辞書順でも数値順でも同じです。
