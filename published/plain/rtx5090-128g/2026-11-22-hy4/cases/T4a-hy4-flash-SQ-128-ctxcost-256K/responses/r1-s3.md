## 1. レコードの構造

### 1.1 全体フォーマット

各レコードは 1 行で表され、以下の形をしています。

```
record<6桁の連番>: <8個のギリシャ文字トークン>.
```

例：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

### 1.2 構成要素の分解

| 要素 | 内容 | 例 | 説明 |
|---|---|---|---|
| ID プレフィックス | `record` | `record` | 固定文字列。レコード識別子であることを示す |
| 連番 | 6 桁の十進数 | `000001` | 1 から始まる連続番号。ゼロ埋め |
| 区切り | `:` + 半角スペース 1 つ | `: ` | ID と本文を分離 |
| 本文 | 8 個の単語 | `alpha beta gamma delta epsilon zeta eta theta` | すべて小文字のギリシャ文字名 |
| 終端 | `.` | `.` | 行末のピリオド |

### 1.3 本文のトークン一覧（共通）

全レコードで本文は完全に同一です。

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |

つまり、実質的に変化しているのは **ID の連番だけ** です。

### 1.4 観測される範囲

提示されたデータは以下の通りです。

- 開始：`record000001`
- 終了：`record000212`
- 件数：**212 件**
- 連番に欠番なし
- 重複なし
- 本文は全件同一

### 1.5 正規表現で表すと

```regex
^record(\d{6}): alpha beta gamma delta epsilon zeta eta theta\.$
```
