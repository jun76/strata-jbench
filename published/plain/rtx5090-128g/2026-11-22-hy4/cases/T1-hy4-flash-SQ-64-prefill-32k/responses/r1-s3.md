The dataset is a numbered list of records. Each line has the same structure:

`recordID: content`

- **ID format:** `record` followed by a 6-digit zero-padded number, e.g. `record000001`, `record001721`.
- **ID range:** `record000001` through `record001721`, so there are **1,721 records**.
- **Content:** every record contains the same eight Greek-letter tokens:  
  `alpha beta gamma delta epsilon zeta eta theta.`
