The dataset is a numbered list of records.

Structure:

- Each line has the form:

  `recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta`

- The ID is a zero-padded 6-digit number after `record`.
  - Examples: `record000001`, `record000500`, `record001721`.
- The IDs run consecutively from `record000001` through `record001721`.
- Every record has the same payload: the eight Greek-letter placeholder tokens:
  `alpha beta gamma delta epsilon zeta eta theta`
