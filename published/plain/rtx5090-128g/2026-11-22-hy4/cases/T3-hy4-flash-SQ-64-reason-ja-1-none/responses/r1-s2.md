条件を整理すると：

1. ハルト < ミズキ（着いた順が前）
2. ユイは1位でも5位でもない → 2位、3位、4位
3. ソウタ = アオイのすぐ後（連続）
4. ミズキは3位ではない
5. アオイ > ユイ（アオイはユイより後）
6. ハルトは2位ではない
7. ミズキは5位ではない → ミズキは2位か4位

ミズキは2位または4位。

場合①：ミズキが2位  
ハルトはミズキより前なので1位。  
ユイは2・3・4位だが2位はミズキなので3位か4位。  
アオイはユイより後。ソウタはアオイのすぐ後。  
- ユイ3位ならアオイ4位、ソウタ5位 → 成立。順番：1ハルト、2ミズキ、3ユイ、4アオイ、5ソウタ。  
- ユイ4位ならアオイ5位だがソウタがその後（6位）は不可能。  
→ この場合、3位はユイ。

場合②：ミズキが4位  
ハルトは1位か3位（2位不可、4位より前）。  
ユイは2位か3位。アオイはユイより後で、ソウタがそのすぐ後。  
- ユイ2位 → アオイ3位、ソウタ4位だが4位はミズキで冲突。アオイ5位ならソウタ6位不可。  
- ユイ3位 → アオイは4位か5位。4位はミズキなのでアオイ5位、ソウタ6位不可。  
→ 場合②は不可能。

したがって唯一の順番は  
1位：ハルト、2位：ミズキ、3位：ユイ、4位：アオイ、5位：ソウタ。
