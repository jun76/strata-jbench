The dataset is a sequence of numbered records with a uniform structure:

- Each line begins with a record ID in the form `recordNNNNNN`, where `NNNNNN` is a six-digit zero-padded number.
- The IDs run consecutively from `record000001` through `record006733`.
- Every record has the same content:  
  `alpha beta gamma delta epsilon zeta eta theta.`

So each record can be represented as:

`record<ID>: alpha beta gamma delta epsilon zeta eta theta.`
