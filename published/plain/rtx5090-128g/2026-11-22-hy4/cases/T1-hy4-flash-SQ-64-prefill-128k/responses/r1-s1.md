The dataset is a simple numbered record list.

## Structure

Each line has the form:

```text
recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.
```

- **ID prefix:** `record`
- **Six-digit numeric ID:** from `000001` through `006733`
- **Separator:** colon `:` followed by a space
- **Payload:** the same fixed token sequence on every record:
  ```text
  alpha beta gamma delta epsilon zeta eta theta.
  ```

So a representative record is:

```text
record000001: alpha beta gamma delta epsilon zeta eta theta.
```
