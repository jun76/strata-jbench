The input is a long, sequential list of records. Each record has the same structure:

- **ID format:** `record` followed by a 6-digit zero-padded number  
  Example: `record000001`, `record000002`, …, `record006733`
- **Content format:** the same fixed token sequence  
  `alpha beta gamma delta epsilon zeta eta theta.`

So every line follows this pattern:

```text
recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.
```

where `NNNNNN` is the record number.
