The dataset is a simple, highly regular list of records.

## Structure

Each line has this format:

```text
recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.
```

Where:

- `recordNNNNNN` is the record ID
  - It starts with the literal prefix `record`
  - Followed by a 6-digit zero-padded number
  - The IDs shown run from `record000001` through `record006733`
- After the colon and space, every record contains the same fixed text:

```text
alpha beta gamma delta epsilon zeta eta theta.
```
