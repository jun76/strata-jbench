- Each line has the form:

  `recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.`

- The ID is a 6-digit zero-padded number after `record`, e.g.:
  - `record000001`
  - `record000096`
  - `record002048`
  - `record006733`

- The IDs shown run consecutively from `record000001` through `record006733`.

- Every record has the same payload/content:
