The records form a simple, uniformly structured list:

- Each line is one record.
- Every record has an ID of the form `recordNNNNNN`, where `NNNNNN` is a 6-digit zero-padded number.
- The IDs run consecutively from `record000001` through `record006733`.
- After the colon, every record contains the exact same fixed text:

```text
alpha beta gamma delta epsilon zeta eta theta.
```

So the general format is:

```text
record<6-digit ID>: alpha beta gamma delta epsilon zeta eta theta.
```
