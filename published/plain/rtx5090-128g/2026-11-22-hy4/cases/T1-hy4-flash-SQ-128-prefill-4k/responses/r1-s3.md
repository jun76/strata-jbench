The records form a simple, uniform list:

- Each line is one record.
- Every record has the same structure:

```text
record<ID>: alpha beta gamma delta epsilon zeta eta theta.
```

- The ID is a 6-digit zero-padded number, starting at `000001` and increasing by 1 on each line.
- The records shown run from:

```text
record000001
```

through:

```text
record000212
```

- After the colon and space, every record contains the same eight Greek-letter tokens:

```text
alpha beta gamma delta epsilon zeta eta theta.
```
