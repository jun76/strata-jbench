以下、ご提示のデータ（record000001〜record000212）の構造、IDからレコードを探す手順、そして件数が増えたときに高速に探すための工夫を、できるだけ詳しく説明します。

---

## 1. レコードの構造の説明

### 1.1 全体の形式

各レコードは、以下のような**1行のテキスト**で表されています。

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

この行は、以下の3つの部分に分解できます。

| 部分 | 内容 | 役割 |
|---|---|---|
| ① ID部分 | `record000001` | レコードを一意に識別する識別子 |
| ② 区切り | `:`（コロン） | IDと本文を区切る |
| ③ 本文部分 | `alpha beta gamma delta epsilon zeta eta theta.` | 実際のデータ内容 |

---

### 1.2 ID部分の構造

IDは次のような形式です。

```
record + 6桁の数字
```

具体的には：

```
record000001
record000002
...
record000212
```

#### 特徴

- 接頭辞：`record`
- 数字部分：**6桁のゼロ埋め（zero-padding）**
  - `000001` → 1
  - `000212` → 212
- ゼロ埋めにより、辞書順（文字列順）で並べ替えても数値順と一致する

例：

| ID | 数値 |
|---|---|
| record000001 | 1 |
| record000009 | 9 |
| record000010 | 10 |
| record000100 | 100 |
| record000212 | 212 |

👉 これは「ソート順＝数値順」になるよう設計されている点が重要です。

---

### 1.3 本文部分の構造

本文は常に同じです。

```
alpha beta gamma delta epsilon zeta eta theta.
```

#### トークン分解

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |
