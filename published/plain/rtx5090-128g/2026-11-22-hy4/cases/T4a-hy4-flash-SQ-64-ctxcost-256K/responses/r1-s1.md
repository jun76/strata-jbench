以下、ご提示のデータ（record000001〜record000212）の構造、ID からレコードを探す手順、件数が増えたときの高速検索の工夫を、できるだけ詳しく説明します。

---

## 1. レコードの構造

### 1.1 全体形式

各レコードは次の形をしています：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると：

| 要素 | 内容 | 説明 |
|---|---|---|
| ID 部分 | `record000001` | レコードidentifier。固定長 6 桁の番号付き |
| 区切り | `:`（コロン） | ID と本文を分離 |
| 本文 | `alpha beta gamma delta epsilon zeta eta theta.` | 8 つのトークン + 末尾ピリオド |
| 改行 | `\n` | 1 レコード = 1 行 |

### 1.2 ID の構造

`record000001` は以下のように分解できます：

```
record + 000001
        └── 6 桁のゼロ埋め整数
```

- `record` … 接頭辞（固定文字列）
- `000001` … 6 桁の decimal、leading zero 埋め
- したがって：
  - `record000001` → 1
  - `record000212` → 212
  - 常に **6 桁** なので、辞書順 = 数値順になります（重要）

例：

| ID | 数値 |
|---|---|
| record000001 | 1 |
| record000009 | 9 |
| record000010 | 10 |
| record000099 | 99 |
| record000100 | 100 |
| record000212 | 212 |

### 1.3 本文の構造

本文は常に同じ 8 語です：

```
alpha beta gamma delta epsilon zeta eta theta.
```

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta. |
