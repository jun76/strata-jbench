The dataset is a simple, uniform list of records:

- There are **212 records**, labeled `record000001` through `record000212`.
- Each record has the same structure:
  - A fixed-width ID of the form `record` + 6 digits, e.g. `record000001`.
  - A fixed text payload: `alpha beta gamma delta epsilon zeta eta theta.`
- Every record contains exactly the same eight Greek-letter tokens in the same order:
  1. alpha
  2. beta
  3. gamma
  4. delta
  5. epsilon
  6. zeta
