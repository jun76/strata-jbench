## 1. レコードの構造（全体像）

### 1.1 1行の形式

各行は次の形をしています：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると：

| 要素 | 内容 | 説明 |
|---|---|---|
| ID部分 | `record000001` | レコード識別子（接頭辞 `record` + 6桁のゼロ埋め番号） |
| 区切り | `:`（コロン） | IDと本文を区切る |
| 本文 | `alpha beta gamma delta epsilon zeta eta theta.` | 8つのギリシャ文字名が半角スペースで区切られ、末尾にピリオド |
| 行末 | 改行 | 1レコード = 1行 |

### 1.2 IDの特徴

- `record` + **6桁のゼロ埋め十进制**  
  - `record000001` → 1
  - `record000212` → 212
- ゼロ埋め（zero-padding）により、辞書順 = 数値順になる  
  → これは後述の「高速検索」に非常に重要です。
- 今回のデータは **1番から212番まで連続** しています（欠番なし）。

### 1.3 本文の構造

本文は常に同じトークン列です：

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |

- 末尾の `.` は文末記号であり、トークンではない（検索時に除去可能）
- 8トークン × 212レコード = **1,696トークン**
- すべてのレコードで本文は **完全に同一**
