## 1. レコードの構造（全体像）

### 1.1 各行のフォーマット

各レコードは以下の形をしています：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると：

| 要素 | 内容 | 説明 |
|---|---|---|
| ID 部分 | `record000001` | レコードの識別子（固定長 6 桁の番号付き） |
| 区切り | `:`（コロン） | ID と本文を分離 |
| 本文 | `alpha beta gamma delta epsilon zeta eta theta.` | 8 個のトークン＋末尾ピリオド |
| トークン数 | 8 | `alpha`, `beta`, `gamma`, `delta`, `epsilon`, `zeta`, `eta`, `theta` |
| 末尾 | `.` | 文末のピリオド（全行共通） |

つまり、1 行の構造は：

```
<ID>: <word1> <word2> <word3> <word4> <word5> <word6> <word7> <word8>.
```

### 1.2 ID の特徴

- `record` + **6 桁のゼロ埋め整数**
- 000001 から 000212 まで連続
- ゼロ埋めにより、辞書順＝数値順になる
  - `record000009` < `record000010` < `record000100` の順になる
- 固定長なので、文字列比較でも安全に並べ替えられる

### 1.3 本文の特徴

- 全レコードで **まったく同じ内容**
- 語順も同じ：  
  `alpha → beta → gamma → delta → epsilon → zeta → eta → theta`
- 語の間は **半角スペース 1 個**
- 最後の語 `theta` の直後に `.` が付く
