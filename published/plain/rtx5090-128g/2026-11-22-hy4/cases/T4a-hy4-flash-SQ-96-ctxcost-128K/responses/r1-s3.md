## 1. レコードの構造の説明

### 1.1 全体形式

各レコードは次のような固定形式のテキスト行です：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると：

| 要素 | 内容 | 説明 |
|---|---|---|
| レコードID | `record000001` | `record` + 6桁のゼロ埋め整数 |
| 区切り | `:`（コロン） | IDと本文を分離 |
| 本文 | `alpha beta gamma delta epsilon zeta eta theta.` | 8つのギリシャ文字名が半角スペースで並び、末尾にピリオド |

### 1.2 IDの特徴

- 形式：`record` + 6桁数字（例：`record000212`）
- 連番：000001 から 000212 まで（このデータでは212件）
- ゼロ埋め（zero-padding）されているため、**辞書順＝数値順**になります。

例：

```
record000009 < record000010 < record000100 < record000212
```

これは非常に重要で、文字列ソートでも正しい順序が保たれます。

### 1.3 本文の特徴

本文は全レコードで完全に同一です：

```
alpha beta gamma delta epsilon zeta eta theta.
```

- トークン数：8語
- 区切り：半角スペース
- 末尾：`.`（ピリオド）
- 内容に個体差はない（＝「同一ペイロード」）

つまり、このデータセットは「**IDだけが異なる、本体は一定のレコード集合**」です。

### 1.4 構造の定式化

形式上は次のように書けます：

```
record_i = "record" + zero_pad(i, 6) + ": " + PAYLOAD
PAYLOAD  = "alpha beta gamma delta epsilon zeta eta theta."
i ∈ [1, 212]
```
