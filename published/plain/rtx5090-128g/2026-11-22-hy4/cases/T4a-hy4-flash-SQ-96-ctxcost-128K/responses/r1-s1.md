## 1. レコードの構造の説明

### 1.1 全体形式

各レコードは以下のような固定形式のテキスト行です：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると：

| 要素 | 内容 | 説明 |
|---|---|---|
| ID 部分 | `record000001` | レコードを一意に識別する ID |
| 区切り | `:`（コロン＋半角スペース） | ID と本文を分離 |
| 本文 | `alpha beta gamma delta epsilon zeta eta theta.` | 8 個のギリシャ文字アルファベットが半角スペースで並び、末尾にピリオド |

### 1.2 ID の構造

- 接頭辞：`record`
- 数字部分：6 桁のゼロ埋め整数（例：`000001`, `000212`）
- 現在の範囲：`record000001` 〜 `record000212`（212 件）

つまり ID は以下のように解釈できます：

```
record + zero-padded 6-digit integer
```

数値に変換すると：

```
record000212 → 212
```

ゼロ埋めのおかげで、**辞書順（文字列順）がそのまま数値順**になっています。  
これは後述する探索・ソートで非常に重要です。

### 1.3 本文の構造

本文は常に同じです：

```
alpha beta gamma delta epsilon zeta eta theta.
```

- トークン数：8
- トークン一覧（順番固定）：

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |

- 末尾に `.`（ピリオド）が付与
- スペース区切り（タブやカンマではない）
