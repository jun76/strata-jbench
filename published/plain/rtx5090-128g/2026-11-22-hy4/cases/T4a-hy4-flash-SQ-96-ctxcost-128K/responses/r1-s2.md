## 1. レコードの構造の説明

### 1.1 各行のフォーマット

すべての行は以下の完全に同一の構造をしています：

```
record<6桁の数字>: alpha beta gamma delta epsilon zeta eta theta.
```

具体的には：

| 要素 | 内容 | 例 |
|---|---|---|
| レコード ID | `record` + 6桁のゼロ埋め整数 | `record000001` |
| 区切り | コロン `:` の直後に半角スペース 1 個 | `: ` |
| 本文 | 8 個のギリシャ文字（ラテン転写）が半角スペースで区切られた列 | `alpha beta gamma delta epsilon zeta eta theta` |
| 終端 | ピリオド `.` | `.` |

### 1.2 構造の特徴

- **ID は連番**  
  `record000001` から `record000212` まで、1 ずつ増加しています（この例では 212 件）。
- **ゼロ埋め（zero-padding）**  
  6 桁で固定されているため、辞書順（文字列順）と数値順が一致します。  
  例：`record000009 < record000010`（文字列比較でも正しい）
- **本文は完全に一定**  
  全レコードで本文は変化しません。  
  つまり「ID だけが情報を持つ」構造です。
- **1 行 = 1 レコード**  
  改行で区切られたフラットなテキスト（行指向データ）です。

### 1.3 データとしての捉え方

このデータは以下のようにモデル化できます：

```text
Record := {
  id   : string,   // "recordNNNNNN"
  body : string    // 固定文字列 "alpha beta ... theta."
}
```

または、本文が定数であることを明示すると：

```text
Record(id) → CONST_BODY
```
