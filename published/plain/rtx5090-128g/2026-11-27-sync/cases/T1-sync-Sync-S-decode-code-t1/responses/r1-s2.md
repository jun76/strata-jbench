# 単語出現頻度を上位 N 件で表示する CLI ツール

以下に、要求に従って **argparse・型ヒント・docstring** を備えたコマンドラインツール本体と、**pytest** による単体テストを提供します。

## 前提・設計方針

- 単語の区切りは「英数字以外の文字」で分割（正規表現 `\w+` を利用）。
- 大文字/小文字は無視して集計します（`--case-sensitive` で区別可能）。
- 同数出現時は辞書順（アルファベット順）で安定ソートします。
- 出力は表形式（ヘッダ行 + 行幅を揃えた簡易テーブル）です。
- ファイル不存在などのエラーは終了コード非ゼロで返します。
