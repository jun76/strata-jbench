与えられた条件をもとに、5人の到着順位を論理的に絞り込んでいきます。

まず、人之间的关系と制約を整理します。
1. **ハルト < ミズキ** （ハルトが先）
2. **ユイ ≠ 1, ユイ ≠ 5** （ユイは2, 3, 4のいずれか）
3. **アオイ, ソウタ** （アオイの直後にソウタ。つまり「アオイ→ソウタ」のブロックを形成する）
4. **ミズキ ≠ 3**
5. **ユイ < アオイ** （ユイが先）
6. **ハルト ≠ 2**
7. **ミズキ ≠ 5**

これらを組み合わせるために、「アオイ→ソウタ」のブロックと、ユイ・ハルト・ミズキの相対関係から候補を絞ります。

**ステップ1: アオイ・ソウタの位置の候補**
「アオイ→ソウタ」は連続した順位になります。
アオイはユイより後にいるため、アオイが1位になることはありません。
アオイが1位の場合：(1位アオイ, 2位ソウタ) -> ユイはアオイより後にいる必要があり矛盾（ユイは最低3位になるが、ユイは5位不可。かつハルト・ミズキとの関係も見る必要あり）。実際、ユイ < アオイ なので、アオイが1位ならユイは0位のようなものなので不可能。
したがって、アオイ・ソウタの組み合わせ可能な位置は：
- (2, 3)
- (3, 4)
- (4, 5)
のいずれかです。（※1, 2は不可。なぜならアオイ>ユイであり、ユイは最低でも1位から始まるため、もしアオイ=1ならユイはそれより前、つまり存在し得ない。もしアオイ=2, ソウタ=3の場合、ユイは1位か? 可能性を見ていく。）

**ステップ2: 各パターンの検証**

**パターンA: アオイ=2, ソウタ=3**
この場合、残る順位は1, 4, 5にハルト、ミズキ、ユイが入ります。
条件：
- ハルト < ミズキ
- ミズキ ≠ 3（ソウタが3なのでOK）
- ミズキ ≠ 5
- ハルト ≠ 2（アオイが2なのでOK）
- ユイ ≠ 1, ≠ 5
- ユイ < アオイ (=2)
  → ユイは1位でなければならない（ユイ≠1という条件と衝突）。
  **矛盾**: ユイは1位になれないため、このパターンは不可能です。

**パターンB: アオイ=4, ソウタ=5**
この場合、残る順位は1, 2, 3にハルト、ミズキ、ユイが入ります。
条件：
- ユイ < アオイ (=4) → 成立
- ユイ ≠ 1, ≠ 5 → ユイは2または3
- ハルト < ミズキ
- ミズキ ≠ 3
- ミズキ ≠ 5
- ハルト ≠ 2

ユイが2位の場合：
残り1, 3位にハルト、ミズキ。
ハルト < ミズキなので、ハルト=1, ミズキ=3。
しかし、条件「ミズキは3位ではない」に反するため、不可。

ユイが3位の場合：
残り1, 2位にハルト、ミズキ。
ハルト < ミズキなので、ハルト=1, ミズキ=2。
条件確認：
- ハルト(1) < ミズキ(2)：OK
- ハルト(1) ≠ 2：OK
- ミズキ(2) ≠ 3：OK
- ミズキ(2) ≠ 5：OK
- ユイ(3) ≠ 1, ≠ 5：OK
- ユイ(3) < アオイ(4)：OK
- アオイ(4) の直後 ソウタ(5)：OK

この配置はすべての条件を満たします。
順位は以下の通りです：
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

**パターンC: アオイ=3, ソウタ=4**
この場合、残る順位は1, 2, 5にハルト、ミズキ、ユイが入ります。
条件：
- ユイ < アオイ (=3) → ユイは1または2
- ユイ ≠ 1 → ユイは2位
- 残り1, 5位にハルト、ミズキ
- ハルト < ミズキ → ハルト=1, ミズキ=5
- 条件「ミズキは最後ではない」に反するため、不可。

したがって、唯一成立するパターンはパターンBのみです。

**結論:**
到着順は、
1. ハルト
2. ミズキ
3. ユイ
4. アオイ
5. ソウタ

3位に到着したのはユイです。
