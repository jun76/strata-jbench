# 単語出現頻度集計ツール

以下は、テキストファイルから単語の出現頻度を数え、上位 N 件を表形式で表示する CLI ツールです。

## `word_freq.py`

```python
#!/usr/bin/env python3
"""
テキストファイルから単語の出現頻度を集計し、上位 N 件を表形式で表示する CLI ツール。

使い方:
    python word_freq.py input.txt
    python word_freq.py input.txt -n 10 --sort-by count
    python word_freq.py input.txt -n 5 --output-format csv
"""

from __future__ import annotations

import argparse

from dataclasses import dataclass, field

# ---------------------------------------------------------------------------
# データモデル

@dataclass(frozen=True)
class WordRecord:
    """単語とその出現回数・割合を保持する不変レコード。"""
    word: str
    count: int
    percentage: float  # 全語彙数に対する割合 (%)


@dataclass
class FrequencyTable:
    """集計結果全体を保持するコンテナ。"""
    records: list[WordRecord] = field(default_factory=list)
    total_words: int = 0

    def top_n(self, n: int) -> list[WordRecord]:
        """出現回数順に上位 N 件のレコードを返す。"""
        return self.records[:n]
