以下は、1ファイル（HTML）で動く **マインクラフト風の3D箱庭ゲーム** です。

- **ブロックを置く・壊す**（左クリック=破壊 / 右クリック=設置）、**スロットでブロック選択**
- **マウスポインターロック**による一人称視点、WASDで移動・ジャンプ
- **日没→夜→夜明けのサイクル**、夜はモブ（クリーパー/ゾンビ/スライム）が湧いて襲撃、**ブロックを積んで防衛**
- 距離減衰の**環境音**、**3D定位音**、**スクリーンシェイク**、HUD、タイトル／終了画面

function hash(x,y){let n=(x*374761393+y*668265263)|0;n=(n^(n>>13))*1274126177;n=(n^(n>>16))>>>0;return n/4294967295;}
function smooth(t){return t*t*(3-2*t);}
function vnoise(x,y){const xi=Math.floor(x),yi=Math.floor(y),xf=x-xi,yf=y-yi;
  const a=hash(xi,yi),b=hash(xi+1,yi),c=hash(xi,yi+1),d=hash(xi+1,yi+1);

  for(const [a,b] of s){if(a>=0&&b>=0&&a<WORLD/CHUNK&&b<WORLD/CHUNK)dirty.add(a*1000+b);}}

/* ---------- voxel raycast ---------- */
function raycast(){
  const o=camera.position.clone();const dir=new THREE.Vector3();camera.getWorldDirection(dir);
  let x=Math.floor(o.x),y=Math.floor(o.y),z=Math.floor(o.z);
  const sx=dir.x>0?1:-1,sy=dir.y>0?1:-1,sz=dir.z>0?1:-1;
  const ddx=Math.abs(1/dir.x),ddy=Math.abs(1/dir.y),ddz=Math.abs(1/dir.z);
  let tmx=dir.x!==0?((sx>0?x+1-o.x:o.x-x)*ddx):Infinity;
  let tmy=dir.y!==0?((sy>0?y+1-o.y:o.y-y)*ddy):Infinity;
  let tmz=dir.z!==0?((sz>0?z+1-o.z:o.z-z)*ddz):Infinity;
  let axis=0;
  for(let i=0;i<100;i++){
    if(getBlock(x,y,z)!==AIR)return{x,y,z,axis};
    if(tmx<tmy&&tmz<tmz){}
    if(tmx<tmy&&tmx<tmz){x+=sx;tmx+=ddx;axis=0;}
    else if(tmy<tmz){y+=sy;tmy+=ddy;axis=1;}
    else{z+=sz;tmz+=ddz;axis=2;}
    const dist=Math.sqrt((x+0.5-o.x)**2+(y+0.5-o.y)**2+(z+0.5-o.z)**2);
    if(dist>REACH)return null;
  }
  return null;
}

## 遊び方

1. **冒険を開始** → 画面クリックで視点ロック（ESC で一時停止）
2. **WASD** で移動、**SPACE** ジャンプ、**Shift** スプリント
3. **左クリック**でブロック破壊、**右クリック**で設置。`1〜4`／ホイール／スロットクリックで草・土・石・木材を切り替え
4. 時間経過で**昼→夜**に。夜はクリーパー（近寄ると爆発）／ゾンビ／スライムが湧くので、**土や石で壁・屋根を積んで防衛**
5. 倒すとスコア加算。HP が尽きたら GAME OVER（生存時間・スコア・日数を記録）

## 実装のポイント

- **チャンクベースのボクセルエンジン**：面カリング付きメッシュで、置くと隣接チャンクだけ再構築
- **体積ボクセルレイトキャスト（DDA）**で正確なブロック選択と破壊／設置判定
- **プロシージャル生成**：fBm ノイズの地形＋木、ブロックと草面のテクスチャもすべて canvas 生成（画像ファイル不要）
- **環境演出**：シェーダ空の昼→夕→夜→夜明けグラデーション、太陽／月、距離減衰の環境音＋3D 定位音、スクリーンシェイク、被弾フラッシュ、破壊パーティクル
- **HUD**は紙＋ピクセルフォント（Press Start 2P / VT323）で、ブロックタイルのスロット・HP／生存時間バー・時間時計を配置

`WORLD`（地形サイズ）や `DAY_LEN`（1日の長さ）、`MOBD`（モブの強さ）をいじると難易度や世界規模を調整できます。
