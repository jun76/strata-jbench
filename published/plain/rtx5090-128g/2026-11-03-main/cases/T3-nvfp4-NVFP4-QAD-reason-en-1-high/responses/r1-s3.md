If the prize were in box A, then labels A and B would both be true, which is not allowed.

If the prize were in box C, then labels B and C would both be true, which is not allowed.

If the prize were in box B, then:
- A is false: the prize is not in A.
- B is false: the prize is in B.
- C is true: the prize is not in A.

Exactly one label is true, so the prize is in box B.

Answer: B
