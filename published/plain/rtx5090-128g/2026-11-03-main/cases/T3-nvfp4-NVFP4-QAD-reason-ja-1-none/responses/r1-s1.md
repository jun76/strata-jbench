アオイ、ハルト、ミズキ、ソウタ、ユイの5人が駅に到着した順番（1位〜5位）を決定します。

与えられた条件を整理します。
1. ハルト < ミズキ（ハルトがミズキより前）
2. ユイ ≠ 1位、ユイ ≠ 5位
3. アオイ + 1 = ソウタ（ソウタはアオイのすぐ後、つまり連続した順位）
4. ミズキ ≠ 3位
5. ユイ < アオイ（アオイがユイより後）
6. ハルト ≠ 2位
7. ミズキ ≠ 5位（最後ではない）

**ステップ1: 「アオイ・ソウタ」のペアの位置を絞り込む**
条件3より、アオイとソウタは連続した順位です。可能なペアの順位（アオイ, ソウタ）は以下の通りです。
- (1, 2)
- (2, 3)
- (3, 4)
- (4, 5)

**ステップ2: 各ケースを検証する**

**ケースA: アオイが1位、ソウタが2位の場合**
- この時、残りの人はハルト、ミズキ、ユイで、順位は3, 4, 5です。
- 条件5より「ユイ < アオイ」ですが、アオイが1位なので、ユイが1位より前になることはできません。
- よって、このケースは**不適**です。

**ケースB: アオイが2位、ソウタが3位の場合**
- 残りの順位は1, 4, 5で、残りの人はハルト、ミズキ、ユイです。
- 条件2より「ユイは1位でも5位でもない」ため、ユイは3位以外で1位でも5位でもありません。しかし3位はソウタです。残りの順位は1, 4, 5なので、ユイが入れるのは**4位**です（1位と5位は不可）。
  - ユイ = 4位
- 残りの順位は1位と5位で、残りの人はハルトとミズキです。
- 条件1より「ハルト < ミズキ」。
- 条件4より「ミズキは3位ではない」（ソウタなのでOK）。
- 条件7より「ミズキは最後（5位）ではない」。
  - もしミズキが5位だと条件7に違反するので、ミズキは5位になれません。
  - 残りの順位は1位と5位なので、ミズキは1位にならざるを得ません。
  - するとハルトは5位になります。
  - この時、ハルト(5) < ミズキ(1) となり、条件1「ハルトはミズキより前」に**違反**します。
- よって、このケースは**不適**です。

**ケースC: アオイが3位、ソウタが4位の場合**
- 残りの順位は1, 2, 5で、残りの人はハルト、ミズキ、ユイです。
- 条件2より「ユイは1位でも5位でもない」ため、ユイは**2位**です。
  - ユイ = 2位
- 残りの順位は1位と5位で、残りの人はハルトとミズキです。
- 条件1より「ハルト < ミズキ」。
  - 順位は1位と5位だけなので、ハルトが1位、ミズキが5位になります。
- しかし、条件7より「ミズキは最後（5位）ではない」。
  - ミズキが5位になるのは**不適**です。
- よって、このケースは**不適**です。

**ケースD: アオイが4位、ソウタが5位の場合**
- 残りの順位は1, 2, 3で、残りの人はハルト、ミズキ、ユイです。
- 条件2より「ユイは1位でも5位でもない」。5位はソウタなので、ユイは1位になれません。
  - 残りの順位1, 2, 3のうち、ユイは**2位**または**3位**です。
- 条件5より「ユイ < アオイ」。アオイは4位なので、ユイは1, 2, 3位のいずれかであればOKです。
- ここからハルトとミズキの配置を考えます。残りの順位は2人分です。
- 条件1より「ハルト < ミズキ」。
- 条件6より「ハルトは2位ではない」。
- 条件4より「ミズキは3位ではない」。

ユイの順位候補について検討します。

*   **もしユイが3位の場合:**
    - 残りの順位は1位と2位で、ハルトとミズキです。
    - ハルト < ミズキ かつ ハルトは2位ではない。
    - ハルトが2位ではないなら、ハルトは1位、ミズキは2位になります。
    - この場合、ミズキは2位（3位ではない条件OK）、ハルトは1位（2位ではない条件OK）。
    - ユイは3位（1位でも5位でもない条件OK）。
    - アオイ4位、ソウタ5位。
    - 全体の順位:
        1. ハルト
        2. ミズキ
        3. ユイ
        4. アオイ
        5. ソウタ
    - すべての条件をチェック:
        - ハルト(1) < ミズキ(2): OK
        - ユイ(3) は1位でも5位でもない: OK
        - ソウタ(5) はアオイ(4) のすぐ後: OK
        - ミズキ(2) は3位ではない: OK
        - アオイ(4) はユイ(3) より後: OK
        - ハルト(1) は2位ではない: OK
        - ミズキ(2) は最後(5位)ではない: OK
    - このケースは成立します。この場合、**3位はユイ**です。

*   **もしユイが2位の場合:**
    - 残りの順位は1位と3位で、ハルトとミズキです。
    - ハルト < ミズキ なので、ハルトは1位、ミズキは3位になります。
    - しかし、条件4で「ミズキは3位ではない」とあります。
    - よって、このサブケースは**不適**です。

したがって、唯一成立するパターンはケースDの「ユイが3位」の場合です。

3位に到着したのはユイです。

答え: ユイ
