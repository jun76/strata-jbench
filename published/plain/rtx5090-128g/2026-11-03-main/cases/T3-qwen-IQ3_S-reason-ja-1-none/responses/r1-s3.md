与えられた条件から、5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の到着順を論理的に推导していきましょう。

まず、条件を整理します。
1. ハルト < ミズキ（ハルトはミズキより前）
2. ユイ $\neq$ 1位、$\neq$ 5位（ユイは2〜4位のいずれか）
3. アオイ -> ソウタ（アオイの直後にソウタ。つまり、アオイとソウタは隣接し、アオイが先に到着）
   - 可能な組み合わせ: (1,2), (2,3), (3,4), (4,5)
4. ミズキ $\neq$ 3位
5. ユイ < アオイ（ユイはアオイより前）
   - 3.と組み合わせると: ユイ < アオイ -> ソウタ
6. ハルト $\neq$ 2位
7. ミズキ $\neq$ 5位

### ステップ1: アオイとソウタの位置候補を絞る

条件5より、ユイはアオイより前にいます。
条件3より、ソウタはアオイの直後です。
したがって、「ユイ ... アオイ、ソウタ」という並びが存在します。
これは、アオイとソウタが1,2位に並ぶことはできないことを意味します（もし1,2位なら、ユイはそれより前にいる必要があるため0位になるからです）。
また、ユイは4位までしかいけない（条件2）ので、アオイが4位の場合、ユイは1,2,3位のいずれか、ソウタは5位になります。
アオイが3位の場合、ユイは1,2位、ソウタは4位。
アオイが2位の場合、ユイは1位、ソウタは3位。

アオイの順位候補は **2, 3, 4** です。（1位は不可、5位は不可（ソウタが6位になるため））

### ステップ2: ハルトとミズキの位置を考慮する

条件1より、ハルト < ミズキ。
条件4より、ミズキ $\neq$ 3位。
条件7より、ミズキ $\neq$ 5位。
よって、ミズキは **1, 2, 4位** のいずれかです。

条件6より、ハルト $\neq$ 2位。

### ステップ3: 具体的なケース分け

アオイとソウタの並び（セット）の位置を候補ごとに検討します。

#### ケースA: アオイ=2, ソウタ=3
この場合、残り1, 4, 5位にハルト、ミズキ、ユイが入ります。
条件5より、ユイ < アオイ(2位)。よって **ユイ=1位**。
しかし条件2より「ユイは1位ではない」なので、このケースは **矛盾** して成立しません。
よって、アオイは2位ではありません。

#### ケースB: アオイ=3, ソウタ=4
この場合、残り1, 2, 5位にハルト、ミズキ、ユイが入ります。
条件5より、ユイ < アオイ(3位)。よって **ユイは1位または2位**。
条件2より、ユイ $\neq$ 1位。よって **ユイ=2位**。

残った順位は1位と5位、残った人はハルトとミズキです。
条件1より、ハルト < ミズキ。
もしハルト=5位、ミズキ=1位なら、ハルト(5) < ミズキ(1) は偽。
よって **ハルト=1位、ミズキ=5位** でなければなりません。
しかし、条件7より「ミズキは最後（5位）ではない」とあります。
よって、このケースも **矛盾** して成立しません。
よって、アオイは3位ではありません。

#### ケースC: アオイ=4, ソウタ=5
この場合、残り1, 2, 3位にハルト、ミズキ、ユイが入ります。
条件5より、ユイ < アオイ(4位)。これは1,2,3位すべてで満たされます。
条件2より、ユイ $\neq$ 1位。よって **ユイは2位または3位**。

ここで、ミズキの位置を考えます。
残り順位は1, 2, 3。
条件4より、ミズキ $\neq$ 3位。
条件7より、ミズキ $\neq$ 5位（すでに満たされている）。
よってミズキは **1位または2位** です。

条件1より、ハルト < ミズキ。

**サブケース C-1: ミズキ=1位の場合**
ハルト < ミズキ(1位) となる人物はいないため、これは不可能です。
よって、ミズキは1位ではありません。

**サブケース C-2: ミズキ=2位の場合**
この時、残り順位は1位と3位、残った人はハルトとユイです。
条件1より、ハルト < ミズキ(2位)。
よって **ハルト=1位** でなければなりません。
すると、残りの **ユイ=3位** となります。

この配置が他の条件と矛盾していないか確認します。
1. ハルト(1) < ミズキ(2) -> OK
2. ユイ(3) は1位でも5位でもない -> OK
3. アオイ(4) のすぐ後にソウタ(5) -> OK
4. ミズキ(2) は3位ではない -> OK
5. ユイ(3) < アオイ(4) -> OK
6. ハルト(1) は2位ではない -> OK
7. ミズキ(2) は最後ではない -> OK

すべての条件を満たしました。

したがって、順位は以下の通りです。
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

3位に到着したのは **ユイ** です。

答え: ユイ
