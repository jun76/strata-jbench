与えられた条件から、5人の到着順（1位～5位）を論理的に絞り込んでいきます。

まず、人物間の前後関係と「すぐ後」の条件から、ブロック（固まり）と順序を作ります。

1.  **条件：「ソウタはアオイのすぐ後に着いた」**
    *   この2人は **[アオイ, ソウタ]** という順で隣接しているブロックを作ります。

2.  **条件：「アオイはユイより後に着いた」**
    *   上記のブロックにさらにユイを前置きすると、**[ユイ, アオイ, ソウタ]** という順序（間に他の人が入る可能性あり）または **[ユイ, ..., アオイ, ソウタ]** という関係になります。
    *   より厳密には、「ユイ < アオイ < ソウタ」かつ「アオイとソウタは隣接」となります。

3.  **条件：「ハルトはミズキより前に着いた」**
    *   **ハルト < ミズキ** です。

4.  **条件：「ミズキは3位ではない」「ミズキは最後ではない」**
    *   ミズキの順位候補は **2位, 4位** です。（1位はハルトより前、5位は条件により不可、3位は条件により不可）
        *   もしミズキが1位なら、ハルトより前になるため「ハルト < ミズキ」に反します。
        *   したがってミズキは **2位 または 4位** です。

5.  **条件：「ユイは1位でも5位でもない」**
    *   ユイの順位候補は **2位, 3位, 4位** です。

6.  **条件：「ハルトは2位ではない」**

ここで、ハルトとミズキの位置を確定するためにケース分けします。

---

**ケースA：ミズキが2位の場合**

*   ミズキ = 2位。
*   「ハルト < ミズキ」なので、ハルトは2位より前、つまり **1位** にならなければなりません。
    *   ハルト = 1位。
*   残りの順位は 3, 4, 5位。
*   残りの人物は ユイ, アオイ, ソウタ。
*   関係: [ユイ, ..., アオイ, ソウタ] (アオイとソウタは隣接)
*   ユイは1位でも5位でもないので、ユイは **3位 または 4位**。
    *   **サブケースA1: ユイが3位の場合**
        *   残りは4, 5位にアオイとソウタ。
        *   アオイとソウタは隣接で、アオイ < ソウタ なので、アオイ=4, ソウタ=5。
        *   順序: 1:ハルト, 2:ミズキ, 3:ユイ, 4:アオイ, 5:ソウタ。
        *   この場合、3位は **ユイ** です。
        *   矛盾の確認:
            *   ハルト(1) < ミズキ(2) -> OK
            *   ユイ(3) -> 1位でも5位でもない -> OK
            *   ソウタ(5) は アオイ(4) のすぐ後 -> OK
            *   ミズキ(2) は 3位ではない -> OK
            *   アオイ(4) は ユイ(3) より後 -> OK
            *   ハルト(1) は 2位ではない -> OK
            *   ミズキ(2) は 最後(5位) ではない -> OK
            *   この組み合わせは有効です。
    *   **サブケースA2: ユイが4位の場合**
        *   残りは3, 5位？ いいえ、アオイとソウタは隣接しているので、残りの順位 3, 5 にアオイとソウタを入れることはできません（3と5は隣接していない）。
        *   もしアオイ=3, ソウタ=4なら、ユイ(4)と衝突。
        *   もしアオイ=4, ソウタ=5なら、ユイ(4)と衝突。
        *   したがって、ユイが4位の場合、アオイ・ソウタブロックを配置できません。（ユイが4位のとき、空いているのは3位と5位だが、これらは隣接していないため [アオイ, ソウタ] が入らない）
        *   よって、ミズキが2位のとき、ユイは3位のみ可能。

**ケースB：ミズキが4位の場合**

*   ミズキ = 4位。
*   「ハルト < ミズキ」なので、ハルトは **1位, 2位, 3位** のいずれか。
*   「ハルトは2位ではない」なので、ハルトは **1位 または 3位**。
*   残りの順位: 1, 2, 3, 5位から3人分。
*   人物: ハルト, ユイ, アオイ, ソウタ のうち、ミズキ(4)を除く。
*   関係: [ユイ, ..., アオイ, ソウタ] (アオイとソウタは隣接)

    *   **サブケースB1: ハルトが1位の場合**
        *   残りの順位: 2, 3, 5位。人物: ユイ, アオイ, ソウタ。
        *   アオイとソウタは隣接。
            *   2,3位にアオイ,ソウタを入れる? -> アオイ=2, ソウタ=3。
                *   残りはユイ=5位。
                *   しかし「ユイは5位ではない」なので不適。
            *   3,4位? -> 4位はミズキなので不適。
            *   4,5位? -> 4位はミズキなので不適。
            *   したがって、ハルト=1のとき、アオイ・ソウタの隣接ブロックは 2-3 しかあり得ず、その場合ユイは5位になり矛盾。

    *   **サブケースB2: ハルトが3位の場合**
        *   残りの順位: 1, 2, 5位。人物: ユイ, アオイ, ソウタ。
        *   アオイとソウタは隣接。
            *   利用可能な隣接ペアは (1,2) のみ（5位は孤立）。
            *   よって、アオイ=1, ソウタ=2。
            *   残りのユイは5位。
            *   しかし「ユイは5位ではない」なので不適。

    *   **サブケースB3: ハルトが2位の場合**
        *   「ハルトは2位ではない」なので不適。

    *   **サブケースB4: ハルトが3位以外で1位でもない場合**
        *   ハルトが2位でない、1位でもない、3位でもないなら、ミズキ(4)より前であるため、ハルトは存在できません（1,2,3のいずれかになるため）。

    *   待って、ハルトが3位のケースを再検討。
        *   ミズキ=4, ハルト=3.
        *   残り: 1, 2, 5. 人物: ユイ, アオイ, ソウタ.
        *   アオイ<ソウタ (隣接).
        *   隣接ペアは (1,2) のみ.
        *   アオイ=1, ソウタ=2.
        *   残り ユイ=5.
        *   ユイ=5 は条件「ユイは5位でもない」に反する。
        
    *   ハルトが1位のケースを再検討。
        *   ミズキ=4, ハルト=1.
        *   残り: 2, 3, 5. 人物: ユイ, アオイ, ソウタ.
        *   アオイ<ソウタ (隣接).
        *   隣接ペアは (2,3) のみ.
        *   アオイ=2, ソウタ=3.
        *   残り ユイ=5.
        *   ユイ=5 は条件「ユイは5位でもない」に反する。

    *   したがって、**ミズキが4位のケースはすべて矛盾します。**

---

以上より、唯一成立するのは **ケースA1** です。

到着順:
1. ハルト
2. ミズキ
3. **ユイ**
4. アオイ
5. ソウタ

この順序で条件を最終確認します。
- ハルト(1) < ミズキ(2) → OK
- ユイ(3) は1位でも5位でもない → OK
- ソウタ(5) は アオイ(4) のすぐ後 → OK
- ミズキ(2) は3位ではない → OK
- アオイ(4) は ユイ(3) より後 → OK
- ハルト(1) は2位ではない → OK
- ミズキ(2) は最後(5位)ではない → OK

3位に到着したのはユイです。
