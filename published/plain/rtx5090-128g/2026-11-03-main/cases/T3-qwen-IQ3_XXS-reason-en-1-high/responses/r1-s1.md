Let the prize be in one of A, B, or C and check the number of true labels.

- If the prize is in A:  
  - A’s label is true.  
  - B’s label is true because the prize is not in B.  
  - C’s label is false because the prize is in A.  
  That gives two true labels, so it is not valid.

- If the prize is in B:  
  - A’s label is false.  
  - B’s label is false because the prize is in B.  
  - C’s label is true because the prize is not in A.  
  That gives exactly one true label, so this is valid.

- If the prize is in C:  
  - A’s label is false.  
  - B’s label is true.  
  - C’s label is true.  
  That gives two true labels, so it is not valid.

Answer: B
