以下に、要件を満たすコマンドラインツールと、対応する `pytest` テストケースを提供します。

### 1. メインスクリプト: `word_counter.py`

```python
#!/usr/bin/env python3
"""
word_counter.py

テキストファイルを読み込み、単語の出現頻度をカウントし、
上位 N 件の単語とその頻度を表形式で表示するコマンドラインツール。

Usage:
    python word_counter.py <input_file> [--top N] [--case-sensitive]
"""

import argparse
import sys
from collections import Counter
from typing import List, Tuple, Dict, Optional

def parse_arguments(argv: Optional[List[str]] = None) -> argparse.Namespace:
    """
    コマンドライン引数を解析します。

    Args:
        argv (Optional[List[str]]): 引数のリスト。Noneの場合はsys.argvを使用。

    Returns:
        argparse.Namespace: 解析された引数オブジェクト。
    """
    parser = argparse.ArgumentParser(
        description="テキストファイル内の単語出現頻度をカウントし、上位N件を表示します。"
    )
    parser.add_argument(
        "input_file",
        type=str,
        help="読み込むテキストファイルのパス"
    )
    parser.add_argument(
        "--top",
        type=int,
        default=10,
        help="表示する上位単語の数 (デフォルト: 10)"
    )
    parser.add_argument(
        "--case-sensitive",
        action="store_true",
        help="大文字と小文字を区別する (デフォルト: 区別しない)"
    )
    return parser.parse_args(argv)

def read_file(file_path: str) -> str:
    """
    指定されたファイルを読み込み、内容を文字列として返します。

    Args:
        file_path (str): ファイルパス。

    Returns:
        str: ファイルの内容。

    Raises:
        FileNotFoundError: ファイルが存在しない場合。
        IOError: 読み取りエラーが発生した場合。
    """
    try:
        with open(file_path, 'r', encoding='utf-8') as f:
            return f.read()
    except FileNotFoundError:
        raise FileNotFoundError(f"ファイルが見つかりません: {file_path}")
    except IOError as e:
        raise
