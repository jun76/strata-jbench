この問題は論理推演（Logical Deduction）による排列問題です。5人の到着順を、与された条件に基づいて決定します。

### 1. 条件整理
5人：アオイ (A), ハルト (H), ミズキ (M), ソウタ (S), ユイ (Y)
順位：1位から5位

条件：
1. **H < M**（ハルトはミズキより前）
2. **Y ≠ 1, Y ≠ 5**（ユイは1位或5位ではない → 2, 3, 4位）
3. **S = A + 1**（ソウタはアオイのすぐ後 → AとSは隣接且Aが前）
4. **M ≠ 3**（ミズキは3位ではない）
5. **A > Y**（アオイはユイより後 → Y < A）
6. **H ≠ 2**（ハルトは2位ではない）
7. **M ≠ 5**（ミズキは最後ではない）

### 2. 推演過程

**ステップ1: ミズキ (M) の位置候補**
条件1 (H < M), 条件4 (M ≠ 3), 条件7 (M ≠ 5) により、Mの位置は1, 2, 4位の可能性しか考えられない。
- Mが1位なら、H < M (H < 1) 是不可能的（順位は1以上）。
- Mが2位なら、H < M → Hは1位。
- Mが4位なら、Hは1位, 2位, 3位のいずれか。
- Mが3位或5位は条件で排除。

**ステップ2: M = 2位の場合**
- M = 2 → H = 1（H < M且H≠2, 順位1-2のみ）
- Y ≠ 1, Y ≠ 5 → Y ∈ {3, 4}
- A < S (AとS隣接)
- A > Y
- 残る人物: A, S, Y. 残る順位: 3, 4, 5.
  - Y ∈ {3, 4}
  - If Y = 3: A > 3 → A ∈ {4, 5}. But S = A + 1.
    - If A = 4, S = 5. Order: H(1), M(2), Y(3), A(4), S(5). Check conditions: All satisfied?
      - H<M (1<2) OK
      - Y≠1,5 (3) OK
      - S=A+1 (5=4+1) OK
      - M≠3 (2) OK
      - A>Y (4>3) OK
      - H≠2 (1) OK
      - M≠5 (2) OK
    - If A = 5, S = 6 (Impossible).
  - If Y = 4: A > 4 → A = 5. Then S = 6 (Impossible).
- So, M=2 leads to a valid arrangement: **1:H, 2:M, 3:Y, 4:A, 5:S**.

**ステップ3: M = 4位の場合**
- M = 4.
- H < M → H ∈ {1, 2, 3}. But H ≠ 2 (Condition 6). So H ∈ {1, 3}.
- Y ∈ {2, 3} (Since Y≠1,5 and M=4 occupies 4).
- Let's analyze subcases.

**Case 3a: H = 1**
- Order so far: H(1), ..., M(4), ...
- Y ∈ {2, 3}.
- Remaining positions for A, S: they must be adjacent and A < S. Available slots for A,S depend on Y.
- Slots remaining: {2, 3, 5} if Y not placed, but let's fix Y.
  - If Y = 2: Remaining slots for A,S are {3, 5}. Not adjacent (gap at 4 is M). Impossible for S = A+1.
  - If Y = 3: Remaining slots for A,S are {2, 5}. Not adjacent. Impossible.
  Wait, if H=1, M=4, then occupied are 1, 4. Remaining 2, 3, 5. Y is 2 or 3.
  - If Y=2, remaining for A,S: 3,5. Not adjacent.
  - If Y=3, remaining for A,S: 2,5. Not adjacent.
  - What if Y takes a spot and A,S take the other two adjacent ones?
    The only adjacent pair available in {2,3,5} is (2,3). So A=2, S=3. Then Y must be 5? But Y≠5. Contradiction.
    Or A=3, S=4? No, M is 4.
    Or A=4, S=5? No, M is 4.
    So H=1 seems impossible because A and S need adjacent slots, and the remaining slots 2,3,5 do not contain an adjacent pair except (2,3). If A=2,S=3, then Y must be 5, which is forbidden.
    Therefore, **H ≠ 1**.

**Case 3b: H = 3**
- M = 4, H = 3.
- Y ∈ {2} (since Y≠1,5 and 3,4 are taken). So **Y = 2**.
- Current: ?, Y(2), H(3), M(4), ?
- Remaining slots: 1, 5.
- Remaining persons: A, S.
- A and S must be adjacent. Slots 1 and 5 are not adjacent.
- Contradiction.
- Therefore, **M ≠ 4**.

**Conclusion:**
Only M = 2 works.

### 3. 最終確認
The only valid arrangement found was:
1. ハルト
2. ミズキ
3. ユイ
4. アオイ
5. ソウタ

Let's double-check the conditions for this arrangement:
1. H(1) < M(2): Yes.
2. Y(3) ≠ 1, 5: Yes.
3. S(5) = A(4) + 1: Yes.
4. M(2) ≠ 3: Yes.
5. A(4) > Y(3): Yes.
6. H(1) ≠ 2: Yes.
7. M(2) ≠ 5: Yes.

すべての条件を満たす唯一の解です。

3位に到着した人は **ユイ**です。

答え: ユイ
