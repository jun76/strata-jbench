この論理パズルを解くために、5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の到着順位を1位から5位まで決定していきましょう。

与えられた条件は以下の7つです。
1. ハルト < ミズキ（ハルトがミズキより前）
2. ユイ $\neq$ 1位 かつ ユイ $\neq$ 5位
3. ソウタ = アオイ + 1（アオイのすぐ後）
4. ミズキ $\neq$ 3位
5. ユイ < アオイ（ユイがアオイより前）
6. ハルト $\neq$ 2位
7. ミズキ $\neq$ 5位

### 手順1: アオイとソウタのペアを固定する

条件3より、「アオイ、ソウタ」の順で隣接しています。
可能なポジションの組み合わせは、以下の4パターンです。
- (アオイ, ソウタ) = (1, 2)
- (アオイ, ソウタ) = (2, 3)
- (アオイ, ソウタ) = (3, 4)
- (アオイ, ソウタ) = (4, 5)

### 手順2: ユイの位置を絞る

条件5より、ユイはアオイより前に着いているため、ユイの順位 < アオイの順位です。
また、条件2より、ユイは1位でも5位でもありません。つまりユイは {2, 3, 4} のいずれかです。

各パターンでアオイの順位と、それに伴うユイの可能な順位を確認します。

**ケースA: アオイ=1, ソウタ=2**
- アオイが1位なので、ユイはアオイより前にいる必要がありますが、1位より前はありません。
- **不成立**

**ケースB: アオイ=2, ソウタ=3**
- ユイ < アオイ(2) なので、ユイは1位である必要があります。
- しかし条件2で「ユイは1位ではない」とあります。
- **不成立**

**ケースC: アオイ=3, ソウタ=4**
- ユイ < アオイ(3) なので、ユイは1位または2位です。
- 条件2よりユイは1位ではないので、**ユイ=2位** となります。
- この時点で、確定した順位は以下です。
  - 2位: ユイ
  - 3位: アオイ
  - 4位: ソウタ
- 残りの順位は 1位 と 5位 です。
- 残りの人は ハルト と ミズキ です。
- 条件1: ハルト < ミズキ
- 条件6: ハルト $\neq$ 2位 (すでに2位はユイなのでOK)
- 条件4: ミズキ $\neq$ 3位 (3位はアオイなのでOK)
- 条件7: ミズキ $\neq$ 5位
  - ミズキが5位になれないため、ミズキは1位にならなければなりません。
  - もし ミズキ=1位 なら、ハルトは5位になります。
  - この時、ハルト(5) < ミズキ(1) となりますが、条件1「ハルトはミズキより前に着いた」に反します（5位は1位より後）。
  - **不成立**
  - ※確認: ハルトとミズキの残り枠は1位と5位。
    - パターン1: ハルト=1, ミズキ=5 → 条件7「ミズキは最後ではない」に反する。
    - パターン2: ハルト=5, ミズキ=1 → 条件1「ハルト<ミズキ」に反する（5>1）。
  - よって、このケースも成立しません。

**ケースD: アオイ=4, ソウタ=5**
- この時点で確定した順位は以下です。
  - 4位: アオイ
  - 5位: ソウタ
- 残りの順位は 1位, 2位, 3位 です。
- 残りの人は ハルト, ミズキ, ユイ です。
- 条件5: ユイ < アオイ(4) → ユイは1,2,3位のいずれか。（条件2でユイ≠1,5なので、ユイは2位または3位）
- 条件1: ハルト < ミズキ
- 条件6: ハルト $\neq$ 2位
- 条件4: ミズキ $\neq$ 3位
- 条件7: ミズキ $\neq$ 5位 (5位はソウタなのでOK)

ここで、残りの3名（ハルト、ミズキ、ユイ）を1,2,3位に配置します。

**ユイの位置を決定します:**
ユイは1位ではない（条件2）。
ユイは2位か3位です。

**仮定D-1: ユイ=2位**
- 残り: ハルト、ミズキ。残り順位: 1位、3位。
- 条件6: ハルト $\neq$ 2位 (OK, 2位はユイ)
- 条件1: ハルト < ミズキ
- 残りの順位は1位と3位なので、ハルトが1位、ミズキが3位であれば条件を満たします（1<3）。
- この配置:
  - 1位: ハルト
  - 2位: ユイ
  - 3位: ミズキ
  - 4位: アオイ
  - 5位: ソウタ
- チェック:
  - 条件1: ハルト(1) < ミズキ(3) → OK
  - 条件2: ユイ(2) ≠1,5 → OK
  - 条件3: ソウタ(5) = アオイ(4)+1 → OK
  - 条件4: ミズキ(3) ≠ 3位? → **NG! ミズキは3位であってはいけません。**
- **不成立**

**仮定D-2: ユイ=3位**
- 残り: ハルト、ミズキ。残り順位: 1位、2位。
- 条件1: ハルト < ミズキ
- 1位と2位にハルトとミズキを配置。
- ハルト < ミズキ なので、**ハルト=1位**、**ミズキ=2位** となります。
- この配置:
  - 1位: ハルト
  - 2位: ミズキ
  - 3位: ユイ
  - 4位: アオイ
  - 5位: ソウタ
- チェック:
  - 条件1: ハルト(1) < ミズキ(2) → OK
  - 条件2: ユイ(3) ≠1,5 → OK
  - 条件3: ソウタ(5) = アオイ(4)+1 → OK
  - 条件4: ミズキ(2) ≠ 3位 → OK
  - 条件5: ユイ(3) < アオイ(4) → OK
  - 条件6: ハルト(1) ≠ 2位 → OK
  - 条件7: ミズキ(2) ≠ 5位 → OK

すべての条件を満たす唯一の解が得られました。

到着順:
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

3位に到着したのはユイです。

答え: ユイ
