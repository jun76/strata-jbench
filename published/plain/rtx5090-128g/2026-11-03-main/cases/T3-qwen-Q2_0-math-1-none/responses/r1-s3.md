1から2026までの整数のうち、3でも5でも割り切れない数を数えるには、 inclusion-exclusion principle ( inclusion-exclusion principle /  inclusion-exclusion principle) 用いて、3の倍数、5の倍数、および15の倍数（3と5の両方の公倍数）の個数を計算し、全体からそれらを除去する方法が有効です。

**手順:**

1. **全体の数:**
   $N = 2026$

2. **3の倍数の個数:**
   $\lfloor \frac{2026}{3} \rfloor = 675$

3. **5の倍数の個数:**
   $\lfloor \frac{2026}{5} \rfloor = 405$

4. **15の倍数（3と5の両方の公倍数）の個数:**
   $\lfloor \frac{2026}{15} \rfloor = 135$
   （3の倍数かつ5の倍数は15の倍数である）

5. **3でも5でも割り切れる数（3の倍数または5の倍数）の個数:**
   Inclusion-Exclusion principle によれば:
   $|A \cup B| = |A| + |B| - |A \cap B|$
   $|A \cup B| = 675 + 405 - 135 = 945$

   つまり、3でも5でも割り切れる数（少なくとも一方に割り切れる数）は 945 個です。

6. **3でも5でも割り切れない数:**
   $2026 - 945 = 1081$

答え: 1081
