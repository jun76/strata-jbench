Based on the provided data, here is a summary of the structure and instructions for looking up records.

### Structure of the Records

1.  **Format**: Each record is a single line of text following a strict key-value pair format:
    `record[7-digit ID]: [Content]`
2.  **ID Field**:
    *   The ID is always the string `record` followed immediately by a **7-digit integer** (zero-padded).
    *   The IDs in this dataset range sequentially from `record000001` to `record001721`.
