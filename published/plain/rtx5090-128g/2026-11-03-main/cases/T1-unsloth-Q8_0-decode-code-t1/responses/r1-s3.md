以下、要件を満たす実装例です。  
`wordfreq` は標準ライブラリのみを使い、**正規表現で英数文字・日本語（ひらがな・カタカナ・漢字）を含む単語を抽出**し、大文字小文字を無視して頻度を数えます。  
コマンドラインツール（`argparse`）とライブラリ関数を分離し、pytest で単体テストします。
