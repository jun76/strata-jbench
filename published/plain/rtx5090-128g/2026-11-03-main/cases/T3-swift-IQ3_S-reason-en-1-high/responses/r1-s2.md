If the prize were in box A, labels A and B would both be true, which is not allowed.

If the prize were in box B, then:
- A’s label is false
- B’s label is false
- C’s label is true

Exactly one label is true, so this works.

If the prize were in box C, then labels B and C would both be true.

Therefore, the prize is in box B.
