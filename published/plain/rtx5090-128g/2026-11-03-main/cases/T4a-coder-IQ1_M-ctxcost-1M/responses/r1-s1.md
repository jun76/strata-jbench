### 2. Procedure to Search for a Record by ID

Since the records are listed sequentially in a text format, the basic search procedure is a **Linear Search**.

**Algorithm:**
1.  Define the target ID string (e.g., `record000150`).
2.  Start from the first line (`record000001`).
3.  Read the line and extract the ID part (before the colon).
4.  Compare the extracted ID with the target ID.
5.  If they match, return the data payload.
6.  If they do not match, move to the next line.
7.  Repeat until the match is found or the end of the file is reached.

**Time Complexity:** $O(N)$, where $N$ is the number of records. On average, you check $N/2$ records.
