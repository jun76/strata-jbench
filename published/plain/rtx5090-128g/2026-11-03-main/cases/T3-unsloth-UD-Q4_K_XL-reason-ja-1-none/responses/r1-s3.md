5人の到着順序（1位〜5位）を特定するために、与えられた条件を論理的に整理し、候補を絞り込みます。

**登場人物:** アオイ、ハルト、ミズキ、ソウタ、ユイ

**条件:**
1. ハルト < ミズキ （ハルトの方が早い）
2. ユイ $\neq$ 1位, 5位 （ユイは2, 3, 4位のいずれか）
3. アオイ + 1 = ソウタ （アオイの直後がソウタ。つまり [アオイ, ソウタ] のセットが存在する）
4. ミズキ $\neq$ 3位
5. ユイ < アオイ （ユイの方がアオイより早い）
6. ハルト $\neq$ 2位
7. ミズキ $\neq$ 5位 （ミズキは1, 2, 3, 4位のいずれか。ただし条件4より3位でもないので、ミズキは1, 2, 4位のいずれか）

---

### ステップ1: [アオイ, ソウタ] のペアの位置を考える

条件3より、アオイとソウタは連続しています。
また、条件5より「ユイ < アオイ」です。
したがって、アオイが1位であることはあり得ません（誰よりも早いため）。
アオイの位置を可能性のあるものから検討します。

アオイが取り得る位置は、2位、3位、4位です。
（アオイが1位ならソウタは2位ですが、ユイ<アオイを満たす人物が残らず、また5人全員が配置されるため不可。実際にはユイが1位になり得ますが、後ほど矛盾を検証します。）

ケース分けをして検討します。

#### ケースA: アオイが2位、ソウタが3位の場合
*   順位: ?, **アオイ**, **ソウタ**, ?, ?
*   条件5「ユイ < アオイ」より、ユイは1位でなければなりません。（ユイは1位かそれ以上だが、1位しか空きがないため）
    *   1位: ユイ
    *   2位: アオイ
    *   3位: ソウタ
*   残りの順位: 4位, 5位
*   残りの人物: ハルト, ミズキ
*   条件1「ハルト < ミズキ」より、ハルトが4位、ミズキが5位となるか、他の組み合わせか。
*   条件7「ミズキは最後（5位）ではない」に反します。
    *   したがって、このケースは成り立ちません。

#### ケースB: アオイが3位、ソウタが4位の場合
*   順位: ?, ?, **アオイ**, **ソウタ**, ?
*   条件5「ユイ < アオイ」より、ユイは1位または2位です。
*   条件2「ユイは1位でも5位でもない」より、ユイは**2位**でなければなりません。
    *   2位: ユイ
*   1位には誰かが入ります。残りの人物はハルト、ミズキ。
*   5位にも誰かが入ります。
*   現在の状態: [?, ユイ, アオイ, ソウタ, ?]
*   残りの人物: ハルト, ミズキ
*   残りの順位: 1位, 5位
*   条件1「ハルト < ミズキ」より、ハルトが1位、ミズキが5位でなければなりません。
    *   1位: ハルト
    *   5位: ミズキ
*   確認:
    *   条件6「ハルトは2位ではない」→ ハルトは1位なのでOK。
    *   条件7「ミズキは最後ではない」→ ミズキは5位なので**NG**。
    *   したがって、このケースも成り立ちません。

#### ケースC: アオイが4位、ソウタが5位の場合
*   順位: ?, ?, ?, **アオイ**, **ソウタ**
*   条件5「ユイ < アオイ」より、ユイは1位、2位、3位のいずれか。
*   条件2「ユイは1位でも5位でもない」より、ユイは**2位**または**3位**。
*   残りの人物: ハルト, ミズキ, ユイ
*   残りの順位: 1位, 2位, 3位

ここで、残りの順位（1, 2, 3位）にハルト、ミズキ、ユイを配置します。

条件1「ハルト < ミズキ」
条件4「ミズキは3位ではない」
条件6「ハルトは2位ではない」

ユイの位置（2位または3位）について考えます。

**サブケース C1: ユイが2位の場合**
*   順位: ?, **ユイ**, ?, アオイ, ソウタ
*   残りの順位: 1位, 3位
*   残りの人物: ハルト, ミズキ
*   条件1「ハルト < ミズキ」より、ハルトが1位、ミズキが3位となる。
    *   1位: ハルト
    *   3位: ミズキ
*   条件4「ミズキは3位ではない」に**反する**。
*   したがって、このサブケースは不可。

**サブケース C2: ユイが3位の場合**
*   順位: ?, ?, **ユイ**, アオイ, ソウタ
*   残りの順位: 1位, 2位
*   残りの人物: ハルト, ミズキ
*   条件1「ハルト < ミズキ」より、ハルトが1位、ミズキが2位でなければならない。
    *   1位: ハルト
    *   2位: ミズキ
*   各条件を検証する:
    *   1位: ハルト
    *   2位: ミズキ
    *   3位: ユイ
    *   4位: アオイ
    *   5位: ソウタ

    *   ハルトはミズキより前（1 < 2）: OK
    *   ユイは1位でも5位でもない（3位）: OK
    *   ソウタはアオイのすぐ後（4→5）: OK
    *   ミズキは3位ではない（2位）: OK
    *   アオイはユイより後（3→4）: OK
    *   ハルトは2位ではない（1位）: OK
    *   ミズキは最後ではない（2位）: OK

すべての条件を満たす唯一の順序が決定しました。

**到着順:**
1. ハルト
2. ミズキ
3. **ユイ**
4. アオイ
5. ソウタ

3位に到着したのはユイです。
