アオイ、ハルト、ミズキ、ソウタ、ユイの5人の到着順を決定するために、与えられた条件を論理的に整理していきましょう。

**1. 固定された組み合わせの特定**
*   「ソウタはアオイのすぐ後に着いた」
    *   これは `[アオイ, ソウタ]` という連続したブロックを作ります。
    *   位置の候補は、(1位, 2位), (2位, 3位), (3位, 4位), (4位, 5位) です。

**2. 他の条件の整理**
*   **条件A:** ハルト < ミズキ （ハルトがミズキより前）
*   **条件B:** ユイ $\neq$ 1位, ユイ $\neq$ 5位
*   **条件C:** ミズキ $\neq$ 3位
*   **条件D:** アオイ > ユイ （アオイがユイより後）
*   **条件E:** ハルト $\neq$ 2位
*   **条件F:** ミズキ $\neq$ 5位

**3. `[アオイ, ソウタ]` ブロックの位置を検討**

**ケース1：アオイ=1位, ソウタ=2位**
*   アオイ(1)なので、条件D「アオイはユイより後」より、ユイはアオイより前にいなければなりません。しかしアオイは1位なので、ユイがその前（0位以下）にいることは不可能です。
*   **よって、アオイは1位ではありません。**

**ケース2：アオイ=2位, ソウタ=3位**
*   アオイ(2)なので、条件Dよりユイは1位です。
*   しかし、条件B「ユイは1位ではない」に反します。
*   **よって、アオイは2位ではありません。**

**ケース3：アオイ=3位, ソウタ=4位**
*   アオイ(3)なので、条件D「アオイはユイより後」より、ユイは1位または2位です。
*   条件B「ユイは1位ではない」より、**ユイは2位**です。
*   残りの空き枠は1位と5位。残りの人物はハルトとミズキです。
*   条件A「ハルトはミズキより前」より、ハルト=1位、ミズキ=5位でなければなりません。
*   しかし、条件F「ミズキは最後（5位）ではない」に反します。
*   **よって、アオイは3位ではありません。**

**ケース4：アオイ=4位, ソウタ=5位**
*   アオイ(4)なので、条件D「アオイはユイより後」より、ユイは1位、2位、3位のいずれかです。
*   条件B「ユイは1位ではない」より、**ユイは2位または3位**です。
*   残りの人物：ハルト、ミズキ、ユイ
*   残りの枠：1位、2位、3位
*   この中に `[アオイ, ソウタ]` は存在しないので、ハルト、ミズキ、ユイが1〜3位に配置されます。

    *   **ユイの位置について検討:**
        *   仮に **ユイ=3位** だとします。
            *   残りの枠は1位、2位。残りの人はハルト、ミズキ。
            *   条件A「ハルト < ミズキ」より、ハルト=1位、ミズキ=2位。
            *   条件E「ハルトは2位ではない」→ ハルト=1位なのでOK。
            *   条件C「ミズキは3位ではない」→ ミズキ=2位なのでOK。
            *   条件F「ミズキは最後ではない」→ ミズキ=2位なのでOK。
            *   この組み合わせ：1位:ハルト, 2位:ミズキ, 3位:ユイ, 4位:アオイ, 5位:ソウタ
            *   すべての条件を満たすか確認：
                1. ハルト(1) < ミズキ(2) → OK
                2. ユイ(3)は1,5位ではない → OK
                3. ソウタ(5)はアオイ(4)のすぐ後 → OK
                4. ミズキ(2)は3位ではない → OK
                5. アオイ(4) > ユイ(3) → OK
                6. ハルト(1)は2位ではない → OK
                7. ミズキ(2)は最後ではない → OK
            *   **この解は成立します。**

        *   仮に **ユイ=2位** だとします。
            *   残りの枠は1位、3位。残りの人はハルト、ミズキ。
            *   条件A「ハルト < ミズキ」より、ハルト=1位、ミズキ=3位。
            *   条件C「ミズキは3位ではない」→ ミズキ=3位なので**NG**。
            *   よって、ユイは2位にはなれません。

    *   したがって、このケースで唯一成立するのは「ユイ=3位」の場合です。

**結論の確認**
確定した順序：
1. ハルト
2. ミズキ
3. ユイ
4. アオイ
5. ソウタ
