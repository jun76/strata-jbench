# レコードデータと検索方法

## 1. レコード構造説明

### 基本構造

| Field | Type | Description | Example |
|---|---|---|---|
| **ID** | String | 8-digit zero-padded unique identifier | `record000001` |
| **Payload** | Fixed-length String | 8 Greek lowercase Greek letters separated by single space | `alpha beta gamma delta epsilon zeta eta theta` |

### Structure Format

```
record{ID_8digits}: {payload_8words}
```

- **ID**: `record` + 8-digit zero-padded number
- **Payload**: Exactly 8 Greek letters (`alpha`, `beta`, `gamma`, `delta`, `epsilon`, `zeta`, `eta`, `theta`) in fixed order, separated by single space, ending with period

### Important Observation
In this dataset, **all records have identical payload**:
```
alpha beta gamma delta epsilon zeta eta theta
```

This means:
- Payload content does NOT vary across records
- The ONLY distinguishing feature between records is the **ID field**
- Searching by payload content is meaningless (all match)
- Searching by ID is the primary mechanism
