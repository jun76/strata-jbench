    python word_freq.py sample.txt --top 10

    """テキストファイルを読み込み、その内容を文字列として返す。

        filepath: 読み込むテキストファイルのパス。

    Returns:
        ファイルの内容を表す文字列。

    Raises:
        FileNotFoundError: ファイルが存在しない場合。
        PermissionError: ファイルの読み取り権限がない場合。
        UnicodeDecodeError: UTF-8 でデコードできない場合。
    """
    return filepath.read_text(encoding="utf-8")
