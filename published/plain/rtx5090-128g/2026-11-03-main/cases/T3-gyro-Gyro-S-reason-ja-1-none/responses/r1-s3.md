5人の到着順序を $1$（最初）から $5$（最後）まで決めていきます。

**条件の整理：**
1. ハルト < ミズキ （ハルトはミズキより前に着いた）
2. ユイ $\neq 1$ かつ ユイ $\neq 5$ （ユイは1位でも5位でもない $\rightarrow$ ユイは2, 3, 4のどれか）
3. ソウタ = アオイ + 1 （ソウタはアオイのすぐ後に着いた）
4. ミズキ $\neq 3$
5. アオイ > ユイ （アオイはユイより後に着いた）
6. ハルト $\neq 2$
7. ミズキ $\neq 5$ （ミズキは最後ではない）

**推理：**

まず、条件3「ソウタはアオイのすぐ後に着いた」より、アオイとソウタのペアは $(1,2), (2,3), (3,4), (4,5)$ のいずれかです。

条件5「アオイはユイより後に着いた」より、ユイ < アオイ です。
条件2「ユイは1位でも5位でもない」より、ユイは2, 3, 4です。
また、アオイがユイより後なので、アオイもユイより大きい順位になります。
ユイが4位の場合、アオイは5位しかあり得ません。その場合ソウタは6位となり不可能です。
ユイが3位の場合、アオイは4位か5位です。
ユイが2位の場合、アオイは3位, 4位, 5位です。

さらに、ハルト < ミズキ かつ ミズキ $\neq 5$ かつ ハルト $\neq 2$ を考慮します。

**ケース分析：**

**アオイとソウタのペアについて考えます。**

*   **ケースA: アオイ1位、ソウタ2位**
    *   アオイ=1, ソウタ=2
    *   アオイ(1) > ユイ より、ユイ < 1。これは不可能です（ユイは2,3,4しか取り得ないため、アオイが1位だとアオイより前着いた人は1位以下しかないが、1位はアオイだから不可能）。
    *   よって、アオイは1位ではありません。

*   **ケースB: アオイ2位、ソウタ3位**
    *   アオイ=2, ソウタ=3
    *   ユイ < アオイ(2) より、ユイ=1。しかし条件2でユイ$\neq 1$なので、このケースは不可能です。

*   **ケースC: アオイ3位、ソウタ4位**
    *   アオイ=3, ソウタ=4
    *   ユイ < アオイ(3) より、ユイ=1または2。条件2でユイ$\neq 1$なので、**ユイ=2**。
    *   残りの順位は1位と5位。残りの人はハルトとミズキです。
    *   条件1: ハルト < ミズキ
    *   残りの空き枠は1位と5位です。ハルトがミズキより前に着くので、ハルト=1, ミズキ=5になります。
    *   しかし条件7: ミズキ$\neq 5$。矛盾します。
    *   よって、アオイは3位ではありません。

*   **ケースD: アオイ4位、ソウタ5位**
    *   アオイ=4, ソウタ=5
    *   ユイ < アオイ(4) より、ユイは1,2,3のどれか。条件2でユイ$\neq 1$なので、ユイ=2または3。
    *   残りの順位は1, 2, 3のうちユイが使わないもの。残りの人はハルトとミズキです。
    *   条件1: ハルト < ミズキ
    *   条件6: ハルト $\neq 2$
    *   条件4: ミズキ $\neq 3$
    *   条件7: ミズキ $\neq 5$ (ソウタが5位なので自然に満たされる)

    ユイの候補を2または3で試します。

    **サブケースD-1: ユイ=2**
    *   残りの空きは1位と3位。人はハルトとミズキ。
    *   ハルト < ミズキ なので、ハルト=1, ミズキ=3。
    *   しかし条件4: ミズキ $\neq 3$。矛盾します。

    **サブケースD-2: ユイ=3**
    *   残りの空きは1位と2位。人はハルトとミズキ。
    *   ハルト < ミズキ なので、ハルト=1, ミズキ=2。
    *   条件6: ハルト $\neq 2$ (ハルトは1位なのでOK)
    *   条件4: ミズキ $\neq 3$ (ミズキは2位なのでOK)
    *   条件7: ミズキ $\neq 5$ (ミズキは2位なのでOK)
    *   条件2: ユイ $\neq 1,5$ (ユイは3位なのでOK)
    *   条件5: アオイ(4) > ユイ(3) (OK)

    この順序は以下の通りです：
    1位: ハルト
    2位: ミズキ
    3位: ユイ
    4位: アオイ
    5位: ソウタ

    すべての条件を満たしています。

**結論：**
3位に到着した人は **ユイ** です。
