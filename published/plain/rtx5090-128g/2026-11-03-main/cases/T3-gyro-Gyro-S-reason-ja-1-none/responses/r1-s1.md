まず、与えられた情報を整理して、5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の到着順を推理します。順位は1位（最も早く）から5位（最も遅く）です。

**条件まとめ：**
1. ハルト < ミズキ （ハルトはミズキより前に着いた）
2. ユイ $\neq$ 1位, ユイ $\neq$ 5位
3. ソウタ = アオイ + 1 （ソウタはアオイのすぐ後に着いた）
4. ミズキ $\neq$ 3位
5. アオイ > ユイ （アオイはユイより後に着いた）
6. ハルト $\neq$ 2位
7. ミズキ $\neq$ 5位 （ミズキは最後ではない）

**推理過程：**

**ステップ1: ハルトの順位を特定する**
条件1より、ハルトはミズキより前に着きます。
条件6より、ハルトは2位ではありません。
条件4と7より、ミズキは3位でも5位でもありません。ミズキは1位にもなれません（ハルトがミズキより前にいるため）。したがって、ミズキの順位は **2位** または **4位** のいずれかです。

*   **ケースA: ミズキが2位の場合**
    *   ハルト < ミズキ(2位) なので、ハルトは **1位** です。
    *   この時点で、1位=ハルト、2位=ミズキ。
    *   残りの順位は3位, 4位, 5位で、残りの人はアオイ, ソウタ, ユイです。
    *   条件3より、ソウタはアオイのすぐ後なので、アオイとソウタは連続した順位で、アオイ < ソウタ。
    *   残りの空き枠は3,4,5です。
        *   アオイ=3, ソウタ=4 の組み合わせ、または アオイ=4, ソウタ=5 の組み合わせが考えられます。
    *   条件2より、ユイは1位でも5位でもありません。残りの枠からユイの位置を決めます。
    *   **パターン1: アオイ=3, ソウタ=4**
        *   残り枠は5位。ユイは5位でなければならないが、条件2でユイは5位ではない。→ **不可能**。
    *   **パターン2: アオイ=4, ソウタ=5**
        *   残り枠は3位。ユイは3位となる。
        *   ユイ=3位は条件2（1位でも5位でもない）を満たします。
        *   条件5（アオイ > ユイ）を確認：アオイ(4位) > ユイ(3位) → **成立**。
        *   このケースで、順位は **1位:ハルト, 2位:ミズキ, 3位:ユイ, 4位:アオイ, 5位:ソウタ** となります。
        *   このパターンはすべての条件を満たします。

*   **ケースB: ミズキが4位の場合**
    *   ハルト < ミズキ(4位)。ハルトは2位ではないので、ハルトは **1位** または **3位**。
    *   **パターン1: ハルト=1位**
        *   1位=ハルト, 4位=ミズキ。残りの枠は2位, 3位, 5位。残りの人はアオイ, ソウタ, ユイ。
        *   アオイとソウタは連続でアオイ < ソウタ。
        *   アオイとソウタが連続する位置としては、2-3または4-5（ミズキが4位なので不可）または3-4（ミズキが4位なので不可）... 残りの枠は2,3,5です。
        *   アオイ=2, ソウタ=3 の場合：残りの5位にユイ。ユイ=5位は条件2でNG。
        *   アオイ=3, ソウタ=4 は不可（ミズキが4位）。
        *   アオイ=5は不可（ソウタは6位が必要）。
        *   他の組み合わせも検討しますが、ユイが1位/5位でないという制約と、アオイ/ソウタの連続性から、このケースではユイの位置が矛盾しやすい。具体的には、残りの枠2,3,5でアオイ/ソウタペアを入れると、ユイは必ず5位または1位（既にある）になる、あるいはユイが2位でアオイ/ソウタが3/4（4位はミズキなので不可）など。詳しく確認すると、アオイ=2,ソウタ=3ならユイ=5(NG)。アオイ=3,ソウタ=4ならミズキと衝突(NG)。アオイ=4はミズキと衝突。したがって、ハルト=1位のケースは成立しないか、他のパターンで矛盾が生じます。
    *   **パターン2: ハルト=3位**
        *   3位=ハルト, 4位=ミズキ。残りの枠は1位, 2位, 5位。残りの人はアオイ, ソウタ, ユイ。
        *   ユイは1位でも5位でもないため、ユイは **2位** である必要が残りの枠から導かれます（1,2,5の中でユイが1,5不可なので2位必須）。
        *   したがって、ユイ=2位。
        *   残りの枠は1位と5位で、残りの人はアオイとソウタ。
        *   アオイとソウタはアオイ < ソウタで連続する必要がある。1位と5位は連続しない。→ **不可能**。

したがって、唯一の解はケースAです。

**最終的な順位：**
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

条件確認：
- ハルト(1) < ミズキ(2) OK
- ユイ(3)は1位でも5位でもない OK
- ソウタ(5)はアオイ(4)のすぐ後 OK
- ミズキ(2)は3位ではない OK
- アオイ(4) > ユイ(3) OK
- ハルト(1)は2位ではない OK
- ミズキ(2)は最後ではない OK

3位に到着したのはユイです。
