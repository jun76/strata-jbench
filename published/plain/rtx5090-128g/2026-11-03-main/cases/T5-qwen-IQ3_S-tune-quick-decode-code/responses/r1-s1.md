### 1. メインスクリプト: `word_count.py`

このスクリプトは、指定されたテキストファイルを読み込み、単語の出現頻度を計算し、上位N件を整形して出力します。

"""
word_count.py

テキストファイルから単語の出現頻度をカウントし、
上位N件の単語とその回数を表示するコマンドラインツール。

Usage:
    python word_count.py <file_path> [-n <int>] [--case-sensitive]
"""

def tokenize(text: str, case_sensitive: bool = False) -> List[str]:
    """
    テキストを単語リストに分割する。
    
    Args:
        text (str): 入力テキスト。
        case_sensitive (bool): 大文字小文字を区別するかどうか。
                                Falseの場合、すべて小文字に変換する。
    
    Returns:
        List[str]: 単語のリスト。
    """
    if not case_sensitive:
        text = text.lower()
    
    # 単語を抽出する正規表現: 英数字とハイフンを含む連続文字列
    # 例: "don't" -> "don", "t" (シンプルな分割) または "don't" (より複雑な分割)
    # ここでは一般的な単語分割として \w+ を使用
    words = re.findall(r'\w+', text)
    return words


def count_words(words: List[str]) -> Counter:
    """
    単語リストから頻度カウンタを作成する。
    
    Args:
        words (List[str]): 単語のリスト。
        
    Returns:
        Counter: 単語と出現回数のマッピング。
    """
    return Counter(words)
