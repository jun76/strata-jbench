# 単語頻度集計ツール

以下に、テキストファイルを読み込んで単語出現頻度を集計し、上位N件を表形式で表示するコマンドラインツールと、対応するpytest単体テストを提供します。

## メインモジュール: `wordfreq.py`

```python
#!/usr/bin/env python3
"""
wordfreq.py - テキストファイルの単語出現頻度を集計し、上位N件を表形式で表示するツール。

Usage:
    python wordfreq.py <input_file> [-n N] [--sort-by {count,word}] [--width WIDTH]
"""

from __future__ import annotations

import argparse
import re
import sys
from collections import Counter
from pathlib import Path
from typing import TextIO


def tokenize(text: str) -> list[str]:
    """
    テキストを単語に分割する。

    単語は英数字の連続として定義され、すべて小文字に変換される。
    句読点、空白、特殊文字は区切りとして扱われる。

    Args:
        text: 入力テキスト文字列。

    Returns:
        小文字化された単語のリスト。
    """
    return re.findall(r"[a-z0-9]+", text.lower())


def count_words(text: str) -> Counter[str]:
    """
    テキスト内の単語出現頻度をカウントする。

    Args:
        text: 入力テキスト文字列。

    Returns:
        単語をキー、出現回数を値とする Counter オブジェクト。
    """
    return Counter(tokenize(text))


def get_top_words(
    counter: Counter[str],
    n: int = 10,
    sort_by: str = "count",
) -> list[tuple[str, int]]:
    """
    頻度が高い上位N件の単語を返す。

    Args:
        counter: 単語頻度の Counter オブジェクト。
        n: 取得する上位単語の数。
        sort_by: ソート基準。"count" で頻度順、"word" でアルファベット順。
                 sort_by="count" の場合、頻度が同じならアルファベット順にソートされる。

    Returns:
        (単語, 出現回数) のタプルのリスト。

    Raises:
        ValueError
