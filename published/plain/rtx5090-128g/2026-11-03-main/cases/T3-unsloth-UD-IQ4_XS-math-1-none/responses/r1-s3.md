1 から 2026 までの整数のうち、3 でも 5 でも割り切れない数の個数を求めるには、全体の個数から「3 または 5 のいずれかで割り切れる数」の個数を引く方法（包除原理）を用います。

手順は以下の通りです。

1.  **全体の個数**:
    1 から 2026 までの整数の総数は $2026$ 個です。

2.  **「3 または 5 で割り切れる数」の個数**:
    集合 $A = \{ n \mid 1 \le n \le 2026, n \text{ は 3 で割り切れる} \}$
    集合 $B = \{ n \mid 1 \le n \le 2026, n \text{ は 5 で割り切れる} \}$
    求めたいのは、$|A \cup B|$ です。
    包除原理より、$|A \cup B| = |A| + |B| - |A \cap B|$ です。

    *   **$|A|$ の計算**:
        $1$ から $2026$ の間で $3$ の倍数である数は、
        $\lfloor \frac{2026}{3} \rfloor = 675$ 個です。
        （$675 \times 3 = 2025$ なので、ちょうど $2025$ まで含まれます）

    *   **$|B|$ の計算**:
        $1$ から $2026$ の間で $5$ の倍数である数は、
        $\lfloor \frac{2026}{5} \rfloor = 405$ 個です。
        （$405 \times 5 = 2025$ なので、ちょうど $2025$ まで含まれます）

    *   **$|A \cap B|$ の計算**:
        $3$ でも $5$ でも割り切れる数は、$15$ の倍数です。
        $\lfloor \frac{2026}{15} \rfloor$ を計算します。
        $2026 \div 15 = 135.066\dots$
        したがって、$\lfloor \frac{2026}{15} \rfloor = 135$ 個です。
        （$135 \times 15 = 2025$ なので、ちょうど $2025$ まで含まれます）

    *   **$|A \cup B|$ の計算**:
        $|A \cup B| = 675 + 405 - 135 = 1080 - 135 = 945$ 個です。

3.  **「3 でも 5 でも割り切れない数」の個数**:
    全体の個数から「3 または 5 で割り切れる数」を引きます。
    $2026 - 945 = 1081$

答え: 1081
