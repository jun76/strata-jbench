5人の到着順（1位〜5位）を論理的に推導します。

条件を整理します。
1. ハルト < ミズキ （ハルトがミズキより前）
2. ユイ ≠ 1位, 5位 （ユイは2, 3, 4位）
3. ソウタ = アオイ + 1 （アオイの直後にソウタ）
4. ミズキ ≠ 3位
5. アオイ > ユイ （アオイがユイより後）
6. ハルト ≠ 2位
7. ミズキ ≠ 5位 （ミズキは最後ではない）

**ステップ1：アオイとソウタの位置を考える**
条件3より、「アオイ、ソウタ」は連続した2つの順位を占めます。
考えられる組み合わせは (1,2), (2,3), (3,4), (4,5) です。

**ステップ2：ユイの位置とアオイの関係を考慮する**
条件5より、アオイはユイより後です。つまり、ユイ < アオイ です。
また、条件2よりユイは1位か5位にはなりません。

*   **ケースA: アオイ=1, ソウタ=2**
    ユイ < アオイ(1) はあり得ないため、このケースは不成立。

*   **ケースB: アオイ=2, ソウタ=3**
    ユイ < アオイ(2) なので、ユイは1位のみ可能。
    しかし条件2でユイは1位不可。したがって、このケースは不成立。

*   **ケースC: アオイ=3, ソウタ=4**
    ユイ < アオイ(3) なので、ユイは1位または2位。
    条件2よりユイは1位不可なので、**ユイは2位**確定。
    残り順位は1位と5位、残り人物はハルト、ミズキ。
    条件1より ハルト < ミズキ。
    残っている順位(1, 5)でこの関係を満たすのは、**ハルト=1, ミズキ=5**。
    しかし条件7で「ミズキは最後(5位)ではない」とあります。矛盾。
    したがって、このケースは不成立。

*   **ケースD: アオイ=4, ソウタ=5**
    ユイ < アオイ(4) なので、ユイは1, 2, 3位。
    条件2よりユイは1位不可なので、ユイは2位または3位。
    
    残り順位は1, 2, 3位で、ユイが2または3。
    残り人物はハルト、ミズキ、ユイ。
    
    *   **D-1: ユイ=2位の場合**
        残り順位: 1, 3位。残り人物: ハルト, ミズキ。
        条件1: ハルト < ミズキ。
        残り順位(1, 3)でこの関係を満たすのは、**ハルト=1, ミズキ=3**。
        条件4: ミズキは3位ではない。→ 矛盾。
        
    *   **D-2: ユイ=3位の場合**
        残り順位: 1, 2位。残り人物: ハルト, ミズキ。
        条件1: ハルト < ミズキ。
        残り順位(1, 2)でこの関係を満たすのは、**ハルト=1, ミズキ=2**。
        
        この場合の並びは:
        1位: ハルト
        2位: ミズキ
        3位: ユイ
        4位: アオイ
        5位: ソウタ
        
        すべての条件を確認します。
        1. ハルト(1) < ミズキ(2) → OK
        2. ユイ(3)は1位でも5位でもない → OK
        3. ソウタ(5)はアオイ(4)のすぐ後 → OK
        4. ミズキ(2)は3位ではない → OK
        5. アオイ(4)はユイ(3)より後 → OK
        6. ハルト(1)は2位ではない → OK
        7. ミズキ(2)は最後(5位)ではない → OK

すべての条件を満たす唯一の解は、上記の並びです。

3位に到着したのはユイです。
