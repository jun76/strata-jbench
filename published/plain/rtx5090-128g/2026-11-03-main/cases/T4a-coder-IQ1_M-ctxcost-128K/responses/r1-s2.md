# レコードの構造、IDからレコードの查找手順、および件数増时的加速查找 Method

## 1. レコードの構造を説明 (Record Structure)

### 1.1. 基本结构 (Basic Structure)

```
record[ID]: [field1] [field2] [field3] [field4] [field5] [field6] [field7] [field8]
```

### 1.2. 詳細分解 (Detailed Breakdown)

| 成分 | 説明 | 例 |
|------|------|------|
| `record` | 固定 prefix (record keyword) | `record` |
| `[ID]` | 7-digit zero-padded identifier | `0000001` |
| `:` | 固定 separator | `:` |
| `[field1]` | Field 1 | `alpha` |
| `[field2]` | Field 2 | `beta` |
| `[field3]` | Field 3 | `gamma` |
| `[field4]` | Field 4 | `delta` |
| `[field5]` | Field 5 | `epsilon` |
| `[field6]` | Field 6 | `zeta` |
| `[field7]` | Field 7 | `eta` |
| `[field8]` | Field 8 | `theta` |

### 1.3. 格式 Specification (Format Specification)

```
recordNNNNNNN: α β γ δ ε ζ η θ
```

- **ID format**: 7-digit zero-padded decimal number (`0000001` to `9999999`)
- **Separator**: Single space after `:`, single space between fields
- **Field count**: Exactly 8 fields per record
- **Field values**: Greek letter names (lowercase)

### 1.4. 例を (Examples)

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
record000002: alpha beta gamma delta epsilon zeta eta theta.
...
record000212: alpha beta gamma delta epsilon zeta eta theta.
```
