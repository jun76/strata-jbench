+--------------------------------------------------+
|  Record ID (Key)  |  Data Value (Payload)        |

|  record000001     |  alpha beta gamma ... theta  |
|  record000002     |  alpha beta gamma ... theta  |

### 1.2 IDの構成
- **Format**: `record` + 6-digit zero-padded number
- **Range**: 000001 to 000212 (current max)
- **Type**: Sequential integer encoded as string
- **Total Records**: 212

### 1.3 Dataの構成
- **Structure**: Fixed-length sequence of 8 Greek letters
- **Content**: `alpha beta gamma delta epsilon zeta eta theta`
- **Note**: All records have identical data payload

## 2. 現在のSearch Method

### 2.1 Naive Linear Search
```python
def linear_search(target_id, records):
    for record in records:
        if record.id == target_id:
            return record.data
    return None
```

**Time Complexity**: O(n)  
**n = 212** in current dataset

### 2.2 Problem with Linear Search
- As n increases, search time grows linearly
- At n = 100,000: ~100,000 comparisons worst case
- At n = 1,000,000: ~1,000,000 comparisons worst case
- **Not scalable for large datasets**

---

## 3. 高速Search Strategy for Growing Data

### 3.1 Strategy A: Hash Table (Dictionary)
```python
# Build hash table once
hash_table = {}
for record in records:
    hash_table[record.id] = record.data

# Search in O(1) average
result = hash_table[target_id]
```

**Time Complexity**: O(1) average, O(n) worst case
