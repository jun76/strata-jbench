If the prize were in Box A, then Box A's label ("The prize is in this box") would be true, and Box B's label ("The prize is not in this box") would also be true. That gives two true labels, which is not allowed.

If the prize were in Box C, then Box B's label ("The prize is not in this box") would be true, and Box C's label ("The prize is not in box A") would also be true. That also gives two true labels.

If the prize were in Box B, then:
- Box A's label is false.
- Box B's label is false.
- Box C's label is true.

That gives exactly one true label.

Answer: B
