駅に到着した5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の順番を、与えられた条件から論理的に導き出します。

順位を1位から5位とします。

**ステップ1：制約条件の整理**
1. ハルト < ミズキ（ハルトがミズキより前）
2. ユイ ≠ 1位, ユイ ≠ 5位
3. ソウタ = アオイ + 1（ソウタはアオイのすぐ後）
4. ミズキ ≠ 3位
5. アオイ > ユイ（アオイがユイより後）
6. ハルト ≠ 2位
7. ミズキ ≠ 5位

**ステップ2：アオイとソウタのペアの位置を検討する**
ソウタはアオイのすぐ後にいるため、(アオイ, ソウタ) の組み合わせで考えられる位置は以下の3通りです。
- ケースA: (1, 2)
- ケースB: (2, 3)
- ケースC: (3, 4)
- ケースD: (4, 5)

条件5より「アオイ > ユイ」なので、アオイは1位になることはできません（ユイは最低でも1位である必要がなく、ユイが1位ならアオイは2位以降だが、ユイ≠1位の条件がある）。
さらに条件2より「ユイ ≠ 1位」です。
もしアオイが2位なら、ユイは1位である必要がありますが、ユイは1位になれません。
したがって、アオイは2位になれません。
-> ケースA (アオイ1, ソウタ2) は不可。
-> ケースB (アオイ2, ソウタ3) は不可。

残る可能性は、ケースC (アオイ3, ソウタ4) または ケースD (アオイ4, ソウタ5) です。

**ステップ3：ケースC (アオイ3, ソウタ4) の検証**
このとき、残りの位置は 1, 2, 5 です。残りの人は ハルト, ミズキ, ユイ です。
条件5より「アオイ(3) > ユイ」なので、ユイは1位か2位でなければなりません。
条件2より「ユイ ≠ 1位」なので、ユイは **2位** になります。
残った位置は 1位 と 5位。残った人は ハルト と ミズキ です。
条件1より「ハルト < ミズキ」なので、ハルトが1位、ミズキが5位になります。
しかし、条件7より「ミズキ ≠ 5位」です。
これは矛盾するため、**ケースCは不可能**です。

**ステップ4：ケースD (アオイ4, ソウタ5) の検証**
このとき、残りの位置は 1, 2, 3 です。残りの人は ハルト, ミズキ, ユイ です。
条件5より「アオイ(4) > ユイ」なので、ユイは1, 2, 3位のいずれかです。
条件2より「ユイ ≠ 1位, ≠ 5位」なので、ユイは **2位** または **3位** です。

ここで、ハルトとミズキの関係を考えます。
条件1より「ハルト < ミズキ」。
条件4より「ミズキ ≠ 3位」。
条件6より「ハルト ≠ 2位」。

残りの位置 {1, 2, 3} に {ハルト, ミズキ, ユイ} を配置します。

*   **もしユイが2位の場合:**
    残りの位置は 1, 3。残りの人は ハルト, ミズキ。
    ハルト < ミズキ なので、ハルト=1, ミズキ=3 となります。
    しかし条件4で「ミズキ ≠ 3位」なので、これは不可です。
    よって、ユイは2位ではありません。

*   **もしユイが3位の場合:**
    残りの位置は 1, 2。残りの人は ハルト, ミズキ。
    ハルト < ミズキ なので、ハルト=1, ミズキ=2 となるしかありません。
    
    この配置を検証します。
    1. ハルト
    2. ミズキ
    3. ユイ
    4. アオイ
    5. ソウタ
    
    条件チェック:
    - ハルト(1) < ミズキ(2): OK
    - ユイ(3)は1位でも5位でもない: OK
    - ソウタ(5)はアオイ(4)のすぐ後: OK
    - ミズキ(2)は3位ではない: OK
    - アオイ(4)はユイ(3)より後: OK
    - ハルト(1)は2位ではない: OK
    - ミズキ(2)は最後(5位)ではない: OK

    すべての条件を満たします。

**結論：**
到着順は以下の通りです。
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

3位に到着したのはユイです。

答え: ユイ
