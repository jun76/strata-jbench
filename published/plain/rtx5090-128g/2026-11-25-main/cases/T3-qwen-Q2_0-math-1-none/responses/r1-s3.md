1から2026までの整数のうち、3でも5でも割り切れない数を求めるには、 inclusion-exclusion principle ( inclusion-exclusion principle) 原理を使うのが有効です。

まず、1から2026までの整数の総数を $N$ として、$N = 2026$ です。

3で割り切れる数の個数：
$\lfloor \frac{2026}{3} \rfloor = 675$

5で割り切れる数の個数：
$\lfloor \frac{2026}{5} \rfloor = 405$

3と5両方で割り切れる数（即ち、15で割り切れる数）の個数：
$\lfloor \frac{2026}{15} \rfloor = 135$

3で**または**5で割り切れる数の個数（少なくともどちらかで割り切れる数）は：
$675 + 405 - 135 = 945$

したがって、3でも5でも割り切れない数の個数は：
$2026 - 945 = 1081$

答え: 1081
