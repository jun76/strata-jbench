論理推論により、5人の到着順序を決定します。

1.  **条件の整理**
    *   (1) ハルト < ミズキ
    *   (2) ユイ $\neq$ 1位, 5位 （2, 3, 4位）
    *   (3) ソウタ = アオイ + 1 （アオイの直後）
    *   (4) ミズキ $\neq$ 3位
    *   (5) ユイ < アオイ （アオイはユイより後）
    *   (6) ハルト $\neq$ 2位
    *   (7) ミズキ $\neq$ 5位

2.  **推理プロセス**

    *   **アオイとソウタの位置を考える**
        条件(3)より、アオイとソウタは隣接しており、アオイが前、ソウタが後です。
        可能なペアは (1,2), (2,3), (3,4), (4,5) です。

    *   **ユイの位置を絞り込む**
        条件(2)より、ユイは1位か5位にはいません。
        条件(5)より、アオイはユイより後です。つまり、アオイがユイより後ろにある必要があります。
        
        *   もし **アオイが1位** なら、ユイより後になれないので不可能。
        *   もし **アオイが2位**（ソウタが3位）なら、ユイは1位でなければなりませんが、ユイは1位ではないため不可能。
        *   もし **アオイが3位**（ソウタが4位）なら、ユイは1位か2位です。ユイは1位ではないので、**ユイは2位**になります。
        *   もし **アオイが4位**（ソウタが5位）なら、ユイは1, 2, 3位のいずれかです。
        *   もし **アオイが5位**（ソウタなし？）→ 不可、5人は全員いるのでソウタは存在し、アオイは5位にはなれない（ソウタが6位にはなれない）。つまりアオイの最大は4位です。

        以上より、アオイは**3位または4位**しか可能性があります。

    *   **ケース1：アオイが3位、ソウタが4位の場合**
        このとき、ユイは1位または2位です。
        ユイは1位ではないので、**ユイは2位**です。
        残りの順位は1位と5位で、残りの人はハルトとミズキです。
        条件(1)より、ハルト < ミズキ です。
        残りの1位と5位において、ハルトがミズキより前なら、**ハルト=1位、ミズキ=5位**になります。
        しかし、条件(7)で「ミズキは最後（5位）ではない」とあります。
        よって、このケースは矛盾します。

    *   **ケース2：アオイが4位、ソウタが5位の場合**
        このとき、ユイは1位、2位、3位のいずれかです。
        残りの人はハルトとミズキです。
        
        *   条件(1) ハルト < ミズキ
        *   条件(4) ミズキ $\neq$ 3位
        *   条件(6) ハルト $\neq$ 2位

        ユイが3位の場合：
        残りの1, 2, 4, 5位のうち、アオイ(4), ソウタ(5)が固定されているので、残る枠は1位と2位で、人はハルトとミズキ。
        ハルト < ミズキ なら、ハルト=1位、ミズキ=2位。
        これなら、ハルト(1) < ミズキ(2) 成立、ミズキ(2) $\neq$ 3 成立、ハルト(1) $\neq$ 2 成立。
        ユイ(3) $\neq$ 1,5 成立。
        アオイ(4) > ユイ(3) 成立。
        
        しかし、他の可能性も確認しましょう。
        
        ユイが1位の場合：
        残る枠は2, 3位で、人はハルトとミズキ。
        ハルト < ミズキ なので、ハルト=2, ミズキ=3。
        しかし、条件(4)でミズキは3位ではないため矛盾。
        またはハルト=1? いや、ユイが1位なのでハルトは1位になれない。
        
        ユイが2位の場合：
        残る枠は1, 3位で、人はハルトとミズキ。
        ハルト < ミズキ なので、ハルト=1, ミズキ=3。
        しかし、条件(4)でミズキは3位ではないため矛盾。

        したがって、ユイが3位であり、ハルト=1位、ミズキ=2位という組み合わせのみが成立します。

3.  **検証**
    1位: ハルト
    2位: ミズキ
    3位: ユイ
    4位: アオイ
    5位: ソウタ

    *   ハルト(1) < ミズキ(2) ... OK
    *   ユイ(3) は1位でも5位でもない ... OK
    *   ソウタ(5) はアオイ(4)のすぐ後 ... OK
    *   ミズキ(2) は3位ではない ... OK
    *   アオイ(4) はユイ(3)より後 ... OK
    *   ハルト(1) は2位ではない ... OK
    *   ミズキ(2) は最後(5位)ではない ... OK

    全ての条件を満たします。

    よって、3位に到着したのはユイです。

答え: ユイ
