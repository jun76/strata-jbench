与えられた条件をもとに、5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の到着順を推理します。

**1. アオイとソウタの位置関係**
「ソウタはアオイのすぐ後に着いた」ことから、アオイとソウタは隣接しており、アオイが先に着いています。
考えられるペア（アオイ, ソウタ）の位置は以下の通りです。
*   (1, 2), (2, 3), (3, 4), (4, 5)

**2. ユイの位置の特定**
*   「ユイは1位でも5位でもない」→ ユイは2, 3, 4位のいずれか。
*   「アオイはユイより後に着いた」→ アオイの順位 > ユイの順位。

ユイが4位の場合：
アオイはユイより後なので、アオイは5位。するとソウタは6位になるため不可能。
よって、ユイは4位ではありません。

ユイが3位の場合：
アオイはユイより後なので、アオイは4位。するとソウタは5位。
この場合の配列候補：(?, ?, ユイ, アオイ, ソウタ)
残りハルトとミズキが1, 2位。
「ハルトはミズキより前に着いた」→ ハルト1, ミズキ2。
このとき、「ハルトは2位ではない」に矛盾なし。「ミズキは3位ではない」に矛盾なし。「ミズキは最後ではない」に矛盾なし。
しかし、ここで別の条件を再確認します。「ミズキは3位ではない」はOKです。
いったん、このパターンも可能性として残しますが、他のユイの位置も検討します。

ユイが2位の場合：
アオイはユイより後なので、アオイは3, 4, 5位。
*   **パターンA**: アオイ3, ソウタ4
    *   配列：(?, ユイ, アオイ, ソウタ, ?)
    *   残り：ハルト, ミズキが1, 5位。
    *   「ハルトはミズキより前」→ ハルト1, ミズキ5。
    *   「ミズキは最後ではない」→ **矛盾**（ミズキが5位になってしまうため）。
*   **パターンB**: アオイ4, ソウタ5
    *   配列：(?, ユイ, ?, アオイ, ソウタ)
    *   残り：ハルト, ミズキが1, 3位。
    *   「ハルトはミズキより前」→ ハルト1, ミズキ3。
    *   「ミズキは3位ではない」→ **矛盾**。

したがって、ユイが2位のパターンはすべて除外されました。
先ほど検討した「ユイが3位」のパターンに戻ります。

**ユイが3位の場合の詳細確認:**
配列候補：(?, ?, ユイ, アオイ, ソウタ)
残り：ハルト, ミズキが1, 2位。
「ハルトはミズキより前に着いた」→ ハルトが1位、ミズキが2位。
最終的な順位：
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

すべての条件を検証します。
1. ハルト(1)はミズキ(2)より前に着いた。→ OK
2. ユイ(3)は1位でも5位でもない。→ OK
3. ソウタ(5)はアオイ(4)のすぐ後に着いた。→ OK
4. ミズキ(2)は3位ではない。→ OK
5. アオイ(4)はユイ(3)より後に着いた。→ OK
6. ハルト(1)は2位ではない。→ OK
7. ミズキ(2)は最後ではない。→ OK

すべての条件を満たす唯一の解は以下の通りです。
1位: ハルト
2位: ミズキ
3位: ユイ
