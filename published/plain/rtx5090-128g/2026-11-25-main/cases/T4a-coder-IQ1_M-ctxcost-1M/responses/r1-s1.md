## 2. ID-to-Record Search Procedure (Basic Approach)

Since IDs are sequential and zero-padded, you can map ID directly to index.

### Algorithm: Direct Index Calculation
```python
def find_record_by_id(id_number: int) -> str:
    """
    Returns the record string for a given ID number.
    Assumes records are stored in a list `records` where records[i] corresponds to ID i+1.
    """
    if id_number < 1:
        raise ValueError("ID must be >= 1")
    
    # Convert ID to zero-based index
    index = id_number - 1
    
    # Check bounds
    if index >= len(records):
        raise IndexError("Record not found")
    
    return records[index]
```

### Time Complexity
- **Time**: O(1) — Direct array access.
- **Space**: O(N) — Storing all records in memory.
