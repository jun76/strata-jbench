## 1. レコード構造の説明

### 1.1 全体形式

各レコードは次のような固定形式のテキスト行です：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると：

| 要素 | 内容 | 詳細 |
|---|---|---|
| レコードID | `record000001` | 接頭辞 `record` + 6桁のゼロ埋め整数 |
| 区切り | `:` | ID と本体を分離 |
| 空白 | 1文字 | 可読性のための区切り |
| 本体 | `alpha beta gamma delta epsilon zeta eta theta.` | 8個のギリシャ文字名が半角スペースで連結 |
| 終端 | `.` | 文末記号（全行共通） |

### 1.2 ID の特徴

- 形式：`record` + `%06d`
- 現在の範囲：`record000001` 〜 `record000212`
- 連番で、欠番なし
- ゼロ埋めにより **辞書順 = 数値順** になるのが重要です

例：

```
record000009 < record000010
record000099 < record000100
record000212
```

もしゼロ埋めがなければ `record10 < record9` となり、文字列ソートが壊れます。

### 1.3 本体の特徴

本体は全レコードで完全に同一です：

```
alpha beta gamma delta epsilon zeta eta theta.
```

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |

つまり **データ本体は定数（constant payload）** であり、変化するのは ID だけです。
