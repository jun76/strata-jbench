以下、ご提示いただいたレコード群の構造、ID からレコードを探す基本的な手順、そして件数が増えた場合に高速に検索するための工夫について、できるだけ詳しく説明します。

---

## 1. レコードの構造の説明

### 1.1 全体フォーマット

各レコードは以下のような 1 行のテキストです：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると、以下の 3 つの要素で構成されています：

| 要素 | 内容 | 例 |
|----|----|----|
| ① ID 部分 | `record` + 6 桁のゼロ埋め整数 + `:` | `record000001:` |
| ② 区切り | コロン `:` の直後の半角スペース 1 個 | `: ` |
| ③ 本文 | 8 個のギリシャ文字（英語表記）が半角スペースで区切られ、末尾にピリオド `.` | `alpha beta gamma delta epsilon zeta eta theta.` |

### 1.2 ID の特徴

- 接頭辞：`record`
- 数字部分：**6 桁のゼロ埋め（zero-padded）**
  - `000001` ～ `000212`（このデータでは 212 件）
- 区切り文字：`:`（コロン）
- したがって、ID の文字列長は常に固定：

```
len("record000001") == 12
```

内訳：

```
record (6文字) + 6桁数字 + : (1文字) = 13文字（コロン込み）
```

> ※「ID 本体」をコロンを含めない場合：`record000001`（12 文字）  
> ※「ラベル全体」を含める場合：`record000001:`（13 文字）

### 1.3 本文の特徴

本文は常に同一です：

```
alpha beta gamma delta epsilon zeta eta theta.
```

- トークン数：8
- 区切り：半角スペース
- 末尾：`.`（ピリオド）
- ギリシャ文字の対応（参考）：

| 英語 | ギリシャ文字 |
|----|----|
| alpha | α |
| beta | β |
| gamma
