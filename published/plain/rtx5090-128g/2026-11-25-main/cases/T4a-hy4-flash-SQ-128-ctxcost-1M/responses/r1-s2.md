これらのレコードは、非常に規則的な構造をしたテキストデータです。以下では、**構造の説明**、**ID からレコードを探す基本手順**、そして**件数が増えたときに高速に探すための工夫**を、できるだけ詳しく解説します。

---

## 1. レコードの構造の説明

### 1.1 1行のフォーマット

各レコードは次の形をしています：

```
recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると：

| 要素 | 内容 | 説明 |
|---|---|---|
| レコードID | `record000001` | `record` + 6桁のゼロ埋め整数 |
| 区切り | `:`（コロン） | ID と本体を分離 |
| 空白 | 1つ | コロンの直後 |
| 本体 | `alpha beta gamma delta epsilon zeta eta theta` | 8つのギリシャ文字（ラテン転写）が空白区切り |
| 終端 | `.`（ピリオド） | 文末記号 |

### 1.2 ID の特徴

- 形式：`record` + **6桁の十進数**
- 開始：`record000001`
- 現在の最終：`record000212`
- ゼロ埋め（zero-padding）されているため、**辞書順 = 数値順**になります。

例：

```
record000009
record000010
record000100
record000212
```

これは重要で、文字列比較でも正しい順序が保証されます。

### 1.3 本体の特徴

- 8トークン固定
- すべてのレコードで **完全に同一**
- 順序も固定：

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |

つまり、このデータセットは「**ID だけが異なり、中身は一定**」な構造です。
