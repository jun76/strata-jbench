### 1. Structure of the Records

Each record follows a strict, uniform format consisting of two parts:

*   **The Key (ID):** A string identifier in the format `recordXXXXXX`.
    *   The prefix is always `record`.
    *   The suffix is a 6-digit zero-padded integer (e.g., `000001`, `001204`).
*   **The Value (Payload):** A fixed string of eight Greek letters.
