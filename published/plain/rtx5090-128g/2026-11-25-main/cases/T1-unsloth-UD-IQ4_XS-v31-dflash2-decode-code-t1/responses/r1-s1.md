以下に、要件を満たすコマンドラインツール `wordcount.py` と、対応する単体テスト `test_wordcount.py` を提示します。

## 設計方針

- **純粋関数 + CLI** : 集計ロジックを副作用のない関数に分離し、`main()` は引数解析と出力のみを担うようにして、テストを容易にしています。
- **型ヒント・docstring** : すべての公開関数に付与。
- **argparse** : `positional` でファイル、`--top` / `--ignore-case` / `--min-len` などで挙動を制御。
- **表形式出力** : 追加ライブラリ依存を避けるため `str.format` ベースで整形します。
- **文字列→単語分割** : `str.isalpha()` を用い、ハイフン付き単語や複数語の区切りを自然に扱います。
