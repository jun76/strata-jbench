## 1. 数据结构の分析

### 1.1 基本構造
各レコードは以下の形式で構成されています：
```text

```

### 1.2 構成要素
1. **Key（ID）**: `record000001` 形式。
   - `record` + 6桁の数字（0-padding）。
   - 例: `record000001`, `record000212`.
2. **Separator（区切り）**: `:`（コロン）とスペース。
3. **Value（内容）**: 固定の文字列。
   - 内容: `alpha beta gamma delta epsilon zeta eta theta.`
   - 注意: **すべてのレコードで Value 完全同じ**（Duplicate content）。

### 1.3 特性
- **Uniformity**: 内容が完全に重複。
- **Sequential IDs**: ID は 1 から 212 まで連続。
- **Fixed Format**: 長さや構造が一致。

### 手順
1. **Start**: 最初のレコード `record000001` から開始。
2. **Check**: 現在の ID が目標 ID かどうか比較。
3. **Next**: 不一致なら次のレコードへ移動。
4. **Stop**: 一致または末尾まで検索。

- **Time Complexity**: O(N)
  - N = 212
  - 最悪の場合，212回の比較。
