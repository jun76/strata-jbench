Let P be the box containing the prize.

- If A contains the prize: A's label is true ("prize is in A"). B's label "not in B" is also true (since prize is in A). That gives two true labels, not allowed. C's label "not in A" is false. So A fails.

- If B contains the prize: A's label "prize is in A" is false. B's label "not in B" is false (since prize is in B). C's label "not in A" is true (prize in B, not A). Exactly one true (C). This works.

- If C contains the prize: A's label false. B's label "not in B" is true (prize in C). C's label "not in A" is true (prize in C, not A). Two true labels, not allowed.

Answer: B
