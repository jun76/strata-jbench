## 1. レコードの構造

このデータは、各レコードが次の形をしています。

`recordXXXXXX: alpha beta gamma delta epsilon zeta eta theta.`

ここで、

- `recordXXXXXX` は ID（識別子）
- その後ろの `alpha beta gamma delta epsilon zeta eta theta` は内容（payload）
- 末尾の `.` は文末記号

つまり、レコードは「ID」と「内容」から構成されています。

例えば、

`record000001: alpha beta gamma delta epsilon zeta eta theta.`

は、

- ID: `record000001`
- 内容: `alpha beta gamma delta epsilon zeta eta theta`

という構造になります。

---

## 2. ID からレコードを探す手順

ID からレコードを探す手順は、次のように考えるとわかりやすいです。

### 手順 1: ID を確認する

探したいレコードの ID を確認します。

例：

`record000042`

### 手順 2: ID の形式を確認する

このデータでは、ID は `record` に 6 桁の数字が続く形式です。

例：

- `record000001`
- `record000100`
- `record000212`

### 手順 3: 文字列として照合する

レコードの中から、ID 部分が一致するものを探します。

例えば `record000042` を探す場合、

`record000042: alpha beta gamma delta epsilon zeta eta theta.`

のような行を探せば、そのレコードを見つけられます。

### 手順 4: 内容を取り出す

ID を見つけたら、`:` の後ろの部分を取り出します。

例：

`record000042: alpha beta gamma delta epsilon zeta eta theta.`

の場合、内容は

`alpha beta gamma delta epsilon zeta eta theta`

です。
