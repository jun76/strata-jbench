- If the prize is in **A**:  
  - A’s label is true.  
  - B’s label is true.  
  - C’s label is false.  
  That gives **two true labels**, so impossible.

- If the prize is in **B**:  
  - A’s label is false.  
  - B’s label is false.  
  - C’s label is true.  
  Exactly **one true label**, so this works.

- If the prize is in **C**:  
  - A’s label is false.  
  - B’s label is true.  
  - C’s label is true.  
  That gives **two true labels**, so impossible.

Therefore, the prize is in box B.
