以下、ご提示のデータ（record000001 〜 record000212）の構造、IDから特定レコードを探す手順、そして件数が増えた場合に高速検索するための工夫を、できるだけ詳しく説明します。

---

## 1. レコードの構造の詳細

### 1.1 全体形式

各レコードは以下の形をしています：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると：

| 要素 | 内容 | 説明 |
|---|---|---|
| ID部分 | `record000001` | レコード識別子。接頭辞 `record` + 6桁のゼロ埋め整数 |
| 区切り | `:`（コロン） | IDと本文を分離 |
| 本文 | `alpha beta gamma delta epsilon zeta eta theta.` | 8つのギリシャ文字名が半角スペースで並び、末尾にピリオド |
| 改行 | 各行1レコード | レコード番号順に連続 |

### 1.2 IDの特徴

- `record000001` 〜 `record000212`
- すべて **6桁のゼロ埋め（zero-padding）**
  - 1 → `000001`
  - 212 → `000212`
- そのため、辞書順（文字列順）＝数値順になる
- 接頭辞 `record` が固定なので、検索時に `record` を除外して数値比較できる

### 1.3 本文の特徴

本文は **完全に同一** です：

```
alpha beta gamma delta epsilon zeta eta theta.
```

- トークン数：8語 + 句点
- 語順も固定
- つまり「内容による区別」は一切なく、**IDのみが唯一の識別情報**
- 各語の意味（一般的なギリシャ文字の順序）は以下の通り：

| 位置 | 語 | 対応 |
|---|---|---|
| 1 | alpha | α |
| 2 | beta | β |
| 3 | gamma | γ |
| 4 | delta | δ |
| 5 | epsilon | ε |
| 6 | zeta | ζ |
| 7 | eta | η |
| 8 | theta | θ |
