以下、提示されたデータの構造、ID からレコードを探す手順、件数が増えたときに速く探すための工夫を、できるだけ詳しく説明します。

---

## 1. レコードの構造

### 1.1 全体形式

各レコードは 1 行で表され、次の形をしています。

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

つまり、各レコードは次の 3 つの部分に分かれます。

| 部分 | 内容 | 例 |
|---|---|---|
| ID 部分 | `record` + 6 桁の連番 | `record000001` |
| 区切り | コロン `:` | `:` |
| 本文 | 8 つの単語 + 末尾のピリオド | `alpha beta gamma delta epsilon zeta eta theta.` |

---

### 1.2 ID 部分の構造

ID は次のようになっています。

```
record + 000001
```

- `record` は固定の接頭辞です。
- 後ろの数字は **6 桁のゼロ埋め（zero-padding）** です。
  - `000001` → 1
  - `000212` → 212
  - `000999` → 999

このゼロ埋めにより、ID の文字列長は常に一定です。

```
record000001  (12文字)
record000212  (12文字)
```

文字数が一定なので、辞書順で並べたときに数値順と一致します。

---

### 1.3 本文の構造

本文は常に同じ 8 語です。

```
alpha beta gamma delta epsilon zeta eta theta.
```

| 位置 | 単語 |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |

末尾にピリオド `.` が付きます。

したがって、すべてのレコードの本文は **完全に同一** です。違うのは ID だけです。
