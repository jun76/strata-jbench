Let the prize be in Box A, B, or C, and check how many labels are true in each case.

- If the prize is in **A**:
  - Label A: true
  - Label B: true
  - Label C: false  
  This gives **two true labels**, not allowed.

- If the prize is in **B**:
  - Label A: false
  - Label B: false
  - Label C: true  
  This gives **exactly one true label**, which is allowed.

- If the prize is in **C**:
  - Label A: false
  - Label B: true
  - Label C: true  
  This gives **two true labels**, not allowed.

Therefore, the prize must be in Box B.

Answer: B
