The dataset is a simple, highly regular list of records.

## Structure

Each line has this format:

```text
record<ID>: alpha beta gamma delta epsilon zeta eta theta.
```

- The record ID is a zero-padded 6-digit number.
- IDs run consecutively from `record000001` through `record006733`.
- Every record has the exact same content after the colon:

```text
alpha beta gamma delta epsilon zeta eta theta.
```

So there are **6,733 records**, and they are identical except for their IDs.
