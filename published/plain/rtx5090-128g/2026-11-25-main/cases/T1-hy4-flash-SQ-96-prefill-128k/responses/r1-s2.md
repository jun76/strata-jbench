The dataset is a simple, uniformly structured list of records.

## Structure

Each line has this form:

```text
recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.
```

Where:

- `record` is a fixed prefix.
- `NNNNNN` is a six-digit zero-padded record ID.
- A colon `:` separates the ID from the record content.
- The content is always the same sequence of eight Greek-alphabet labels:

```text
alpha beta gamma delta epsilon zeta eta theta.
```

So every record has identical content; only the ID changes.
