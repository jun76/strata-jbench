The records are a simple, uniform list.

## Structure

Each line has this form:

```text
recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.
```

Where:

- `record` is a fixed label.
- `NNNNNN` is a six-digit zero-padded record ID.
- After the colon and space, every record contains the same text:

```text
alpha beta gamma delta epsilon zeta eta theta.
```

So the dataset is highly repetitive: only the record ID changes.
