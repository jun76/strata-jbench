駅に到着した5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の順番を、与えられた条件から論理的に導き出します。

ポジションを1位（最も早い）から5位（最も遅い）とします。

**1. 条件の整理**
*   (1) ハルト < ミズキ （ハルトがミズキより前）
*   (2) ユイ $\neq$ 1, ユイ $\neq$ 5
*   (3) ソウタ = アオイ + 1 （アオイのすぐ後、つまりアオイが $N$ 位ならソウタは $N+1$ 位）
*   (4) ミズキ $\neq$ 3
*   (5) ユイ < アオイ （アオイより後、つまりユイのポジションはアオイより数字が小さい）
*   (6) ハルト $\neq$ 2
*   (7) ミズキ $\neq$ 5

**2. 論理的推論**

まず、(3)の「アオイとソウタの組み合わせ」に注目します。
アオイとソウタは連続した順位になります。可能な組み合わせは以下の3つです。
*   パターンA: アオイ=1, ソウタ=2
*   パターンB: アオイ=2, ソウタ=3
*   パターンC: アオイ=3, ソウタ=4
*   パターンD: アオイ=4, ソウタ=5

次に、(5)の「ユイ < アオイ」を利用します。ユイはアオイより前にいる必要があるため、アオイが1位であるパターンAは不可能です（1位より前にいる人は存在しないため）。
また、(2)の「ユイは1位でも5位でもない」という条件から、ユイは2位、3位、4位のいずれかです。

ここで、アオイの位置を候補となるB, C, Dで検討します。

**仮定1: アオイ = 4位, ソウタ = 5位 （パターンD）**
*   アオイ=4, ソウタ=5
*   (5)より、ユイ < 4 なので、ユイは2位または3位です（1位不可）。
*   (1)ハルト < ミズキ、(4)ミズキ≠3、(7)ミズキ≠5 より、ミズキは1位、2位、4位のいずれかです。
    *   アオイ=4なので、ミズキは1位か2位です。
    *   もしミズキ=2位なら、ハルト<2なのでハルト=1位。残りはユイ=3位。
        *   この場合：1:ハルト, 2:ミズキ, 3:ユイ, 4:アオイ, 5:ソウタ
        *   条件チェック:
            *   ハルト(1) < ミズキ(2) : OK
            *   ユイ(3) != 1,5 : OK
            *   ソウタ(5) = アオイ(4)+1 : OK
            *   ミズキ(2) != 3 : OK
            *   ユイ(3) < アオイ(4) : OK
            *   ハルト(1) != 2 : OK
            *   ミズキ(2) != 5 : OK
        *   このケースは条件を満たします。このとき3位は**ユイ**です。
    *   もしミズキ=1位なら、ハルト<1は不可能なので除外。
*   よって、このパターンではユイが3位です。

**仮定2: アオイ = 3位, ソウタ = 4位 （パターンC）**
*   アオイ=3, ソウタ=4
*   (5)より、ユイ < 3 なので、ユイは1位または2位です。しかし(2)でユイは1位不可なので、**ユイ=2位**です。
*   残り：1位、5位。人物：ハルト、ミズキ。
*   (1)ハルト < ミズキ より、ハルト=1位、ミズキ=5位となる可能性がありますが、(7)でミズキ≠5なのでこれは不可能です。
*   よって、このパターンは成立しません。

**仮定3: アオイ = 2位, ソウタ = 3位 （パターンB）**
*   アオイ=2, ソウタ=3
*   (5)より、ユイ < 2 なので、**ユイ=1位**です。しかし(2)でユイは1位不可なのでこれは不可能です。
*   よって、このパターンは成立しません。

**確認: 他にパターンはないか？**
上記で「アオイ=4, ソウタ=5」かつ「ユイ=3」の解が見つかりました。
念のため、アオイがそれ以外の位置（1位は不可、2位はユイが1位になり不可、3位はミズキが5位になり不可）を検討しましたが、成立するのはアオイ=4の場合のみでした。

もう一度、最も強力な制約である「ハルト < ミズキ」および「ミズキ ≠ 3, 5」に注目して別角度から検証します。

ミズキの取り得る順位は、(1)ハルトより後、(4)3位以外、(7)5位以外なので、**1位、2位、4位**です。
*   **ミズキ=1位の場合**: ハルト<1は不可能なので除外。
*   **ミズキ=2位の場合**: ハルトは1位。
    *   残りは3,4,5位。人物はアオイ, ソウタ, ユイ。
    *   (3)アオイとソウタは連続。
        *   アオイ=3, ソウタ=4 の場合：残りはユイ=5位。→ (2)ユイは5位不可なので除外。
        *   アオイ=4, ソウタ=5 の場合：残りはユイ=3位。→ (5)ユイ(3) < アオイ(4) でOK。
            *   このケース：1:ハルト, 2:ミズキ, 3:ユイ, 4:アオイ, 5:ソウタ。
            *   条件はすべて満たされます。
    *   このとき3位はユイ。
*   **ミズキ=4位の場合**: ハルトは1位、2位、3位、あるいはそれ以外より後？ -> ハルト < 4 なので、ハルトは1,2,3位のいずれか。
    *   残り：1,2,3,5位から3つ。人物：アオイ, ソウタ, ユイ, ハルト。
    *   (3)アオイとソウタは連続。
        *   アオイ=1, ソウタ=2 の場合：残りは3,5位にハルト,ユイ。
            *   ユイは1,5不可なのでユイ=3位。するとハルト=5位。
            *   ハルト(5) < ミズキ(4) は成立しないので除外。
        *   アオイ=2, ソウタ=3 の場合：残りは1,5位にハルト,ユイ。
            *   ユイは1不可なのでユイ=5位。→ (2)ユイは5位不可なので除外。
        *   アオイ=5, ソウタ=... はありえない（5位のすぐ後に着く人はいない）。
        *   アオイ=3, ソウタ=4? -> ミズキ=4なので衝突。
        *   アオイ=1...は検討済み。
        *   アオイ=5...は不可。
        *   アオイ=2...は検討済み。
        *   アオイ=3...
            *   アオイ=3, ソウタ=4? -> ミズキ=4と衝突。
            *   アオイ=3, ソウタ=...
            *   残る連続ペアの可能性：
                *   アオイ=1, ソウタ=2 （検討済み、ハルトが5位になって矛盾）
                *   アオイ=2, ソウタ=3 （検討済み、ユイが5位になって矛盾）
                *   アオイ=3, ソウタ=4 （ミズキと衝突）
                *   アオイ=4, ソウタ=5 （ミズキと衝突）
                *   アオイ=5...
            *   待った、ミズキ=4の場合、アオイとソウタの連続ペアが置ける場所を探す。
            *   空き枠: 1, 2, 3, 5。
            *   アオイとソウタが連続で入るのは、1-2組か、2-3組だけ（4はミズキ、5は単独枠）。
            *   1-2組の場合: アオイ=1, ソウタ=2。残りは3,5にハルト,ユイ。
                *   ユイ!=1,5 -> ユイ=3。ハルト=5。
                *   ハルト(5) < ミズキ(4) 矛盾。
            *   2-3組の場合: アオイ=2, ソウタ=3。残りは1,5にハルト,ユイ。
                *   ユイ!=1 -> ユイ=5? 不可。ユイ!=5なのでユイは置けない。
                *   もしハルト=1, ユイ=5ならユイが5位で不可。
                *   もしハルト=5, ユイ=1ならユイが1位で不可。
                *   どちらにしても成立しない。
            *   よって、ミズキ=4のケースは成立しない。

したがって、唯一の解は「ハルト=1, ミズキ=2, ユイ=3, アオイ=4, ソウタ=5」です。

このとき、3位に到着したのは**ユイ**です。

答え: ユイ
