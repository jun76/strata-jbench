与えられた条件を整理し、5人の到着順（1位～5位）を論理的に推測します。

**条件の整理：**
1. ハルト < ミズキ (ハルトがミズキより前)
2. ユイ ≠ 1位, ユイ ≠ 5位 (ユイは2,3,4位のいずれか)
3. ソウタはアオイのすぐ後 (アオイの順位 $n$ なら、ソウタは $n+1$)
4. ミズキ ≠ 3位
5. アオイ > ユイ (アオイがユイより後)
6. ハルト ≠ 2位
7. ミズキ ≠ 5位 (ミズキは1,2,3,4位のいずれか)

**推論：**

**ステップ1: アオイとソウタの関係を確定する**
「ソウタはアオイのすぐ後」であるため、(アオイ, ソウタ) の組は以下のいずれかになります：
- (1, 2)
- (2, 3)
- (3, 4)
- (4, 5)

条件5「アオイはユイより後」より、ユイはアオイより前にいる必要があります。
- アオイが1位の場合、アオイより前になる人はいません。よってアオイは1位ではありません。
- したがって、(アオイ, ソウタ) の可能性は (2,3), (3,4), (4,5) のいずれかです。

**ステップ2: ハルトとミズキの関係を確定する**
条件1「ハルト < ミズキ」より、ハルトがミズキより前です。
条件6「ハルト ≠ 2位」です。
条件7「ミズキ ≠ 5位」です。
条件4「ミズキ ≠ 3位」です。

**ステップ3: 候補を絞る**

ユイの順位について考えます。ユイは2,3,4位のいずれかです。

**ケースA: ユイが2位の場合**
- アオイはユイより後なので、アオイは3,4,5位のいずれか。
- (アオイ, ソウタ) は (3,4) または (4,5) となる可能性が高い（アオイが3位ならソウタ4位、アオイ4位ならソウタ5位）。
- 残りの人：ハルト、ミズキ。
- 残り順位：1位、そして (3,4)/(4,5) から除外されたもの。

   - サブケース A1: (アオイ, ソウタ) = (3, 4)
     - 順位: [?, 2, 3, 4, ?]
     - 残る人はハルトとミズキ。残る順位は1位と5位。
     - ハルト < ミズキ。
     - もしハルト1位、ミズキ5位なら、条件7「ミズキは5位ではない」に反する。
     - もしハルト5位、ミズキ1位なら、ハルト < ミズキ に反する。
     - よって、ユイ2位かつ(3,4)は不可能？いや、ハルトとミズキが1,5に入ることは不可能（ミズキ5禁止）。

     - (アオイ, ソウタ) = (4, 5)

**ケースB: ユイが3位の場合**
- アオイはユイより後なので、アオイは4位または5位。
- (アオイ, ソウタ) は (4, 5) となる可能性（アオイ4, ソウタ5）。アオイ5はソウタ6位がありえないので不可。

- 現在の順位: [ ?, ?, 3(ユイ), 4(アオイ), 5(ソウタ) ]
- 残りの人はハルト、ミズキ。残りの順位は1位、2位。
- ハルト < ミズキ。
- 条件6「ハルトは2位ではない」 -> ハルトは1位。
- ならばミズキは2位。
- チェック:
  - ハルト(1) < ミズキ(2) -> OK
  - ハルト(1) != 2位 -> OK
  - ミズキ(2) != 3位 -> OK
  - ミズキ(2) != 5位 -> OK
  - ユイ(3) != 1,5 -> OK
  - ソウタ(5)はアオイ(4)のすぐ後 -> OK
  - アオイ(4)はユイ(3)より後 -> OK
  - ハルト(1)はミズキ(2)より前 -> OK

この順序（1:ハルト, 2:ミズキ, 3:ユイ, 4:アオイ, 5:ソウタ）はすべての条件を満たします。
この場合、3位はユイです。

**ケースC: ユイが4位の場合**
