以下は、テキストファイルから単語出現頻度を上位 N 件で表示する CLI ツール（`wordfreq.py`）と、pytest 単体テスト（`test_wordfreq.py`）です。

## 使い方

```bash
# 表示
python wordfreq.py input.txt --top 10

# 出力をファイルへ
python wordfreq.py input.txt --top 5 --output result.tsv

# 大文字小文字区別 / 最低出現回数 / 最低長
python wordfreq.py input.txt --top 20 --case-sensitive --min-count 2 --min-word-length 3
```
