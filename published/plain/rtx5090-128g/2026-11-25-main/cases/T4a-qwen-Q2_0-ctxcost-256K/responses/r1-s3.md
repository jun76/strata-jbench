#### 1.1. 基本構造
- **ID (Record ID):** `record000001` 形式の7桁数字文字列。

- **区切り:** 空白（Space）で分隔。
- **特徴:** 所有レコードの**内容完全相同**。唯一の差異は **ID** 部分。

#### 1.2. 数学関係式
- **ID 数:** 212 個 (1 から 212)。
- **ID 形式:** `record` + 7桁数字。
- **内容長:** 固定 (39文字 + 8空白 = 47文字? 実際には `alpha`(5)+`beta`(4)+... 詳細は後述）。

### 2. ID からレコードを探す手順（基本）

1. 全てのレコードを読み込み。
2. 検索対象 ID（例: `record000150`）と比較。
3. 一致見つまで繰り返し。

**問題点:**
- 212件なら問題なし。
- 100万件、1億件では **O(N)** 時間复杂度 → 遅い。
