この論理パズルを解くために、5人の到着順（1位～5位）を条件に基づいて決定していきます。

**与えられた条件：**
1. ハルト < ミズキ （ハルトはミズキより前）
2. ユイ ≠ 1位 かつ ユイ ≠ 5位
3. アオイ + 1 = ソウタ （ソウタはアオイのすぐ後。つまり「アオイ, ソウタ」の塊ができる）
4. ミズキ ≠ 3位
5. アオイ > ユイ （アオイはユイより後）
6. ハルト ≠ 2位
7. ミズキ ≠ 5位

**ステップ1：ユイの位置の特定**
条件2より、ユイは1位でも5位でもありません。
また、条件5よりアオイはユイより後ろにいるため、ユイは最大でも4位より前である必要があります（もしユイが5位だとアオイが6位になりありえない。条件2で5位除外済み）。
ユイの候補は **2位, 3位, 4位** です。

**ステップ2：「アオイ, ソウタ」の塊とハルト、ミズキ、ユイの配置を考える**
「アオイ, ソウタ」は連続して並びます。
残りの人は ハルト、ミズキ、ユイ です。

ユイの位置を仮定して、矛盾がないか検証します。

---

**ケースA：ユイが2位のとき**
- ユイ = 2
- 条件5より、アオイ > ユイ なので、アオイは 3, 4, 5 のいずれか。
- 「アオイ, ソウタ」の塊が入る場所を検討します。
  - アオイ=3, ソウタ=4 なら、残りは1, 5位に ハルト, ミズキ が入る。
    - ハルト < ミズキ かつ ハルト ≠ 2 (条件6) かつ ミズキ ≠ 3 (条件4) かつ ミズキ ≠ 5 (条件7)。
    - 残りポジションは1と5。
    - ミズキが5位は不可（条件7）。よって ミズキは1位? -> ハルトは0位? ありえない。
    - ミズキが1位なら ハルト < 1 は不可能。
    - この配置は成立しない。
  - アオイ=4, ソウタ=5 なら、残りは1, 3位に ハルト, ミズキ が入る。
    - ミズキ ≠ 3 (条件4) なので、ミズキは1位、ハルトは3位。
    - ハルト < ミズキ (3 < 1) は偽。成立しない。
  - アオイ=5 は不可（ソウタが6位になるため）。
- よって、**ユイが2位はありえない**。

---

**ケースB：ユイが3位のとき**
- ユイ = 3
- 条件5より、アオイ > 3 なので、アオイは 4 または 5。
- 「アオイ, ソウタ」の塊：
  - アオイ=4, ソウタ=5 なら、残りは1, 2位に ハルト, ミズキ が入る。
    - ハルト < ミズキ。
    - ハルト ≠ 2 (条件6)。よって ハルトは1位、ミズキは2位。
    - チェック：
      - ハルト(1) < ミズキ(2) → OK
      - ユイ(3) → 1,5以外 → OK
      - アオイ(4), ソウタ(5) → アオイのすぐ後 → OK
      - ミズキ(2) ≠ 3 → OK
      - アオイ(4) > ユイ(3) → OK
      - ハルト(1) ≠ 2 → OK
      - ミズキ(2) ≠ 5 → OK
    - **すべての条件を満たします！**
    - この場合、3位は **ユイ** です。

  - アオイ=5 は不可（ソウタが6位）。

---

**ケースC：ユイが4位のとき**
- ユイ = 4
- 条件5より、アオイ > 4 なので、アオイは 5。
- アオイ=5 なら、ソウタは6位になり不可能。
- よって、**ユイが4位はありえない**。

---

**結論の検証：**
唯一の解は以下の通りです。
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

条件の確認：
- ハルト(1) は ミズキ(2) より前 → 符合
- ユイ(3) は 1位でも5位でもない → 符合
- ソウタ(5) は アオイ(4) のすぐ後 → 符合
- ミズキ(2) は 3位ではない → 符合
- アオイ(4) は ユイ(3) より後 → 符合
- ハルト(1) は 2位ではない → 符合
- ミズキ(2) は 最後(5位)ではない → 符合

したがって、3位に到着したのはユイです。

答え: ユイ
