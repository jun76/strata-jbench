与えられた条件から、5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の到着順を推論します。

**1. 条件の整理**
*   C1: ハルト < ミズキ (ハルトはミズキより前)
*   C2: ユイ $\neq$ 1, 5 (ユイは2, 3, 4のいずれか)
*   C3: ソウタ = アオイ + 1 (アオイの直後がソウタ)
    *   つまり、「アオイ、ソウタ」は隣接しており、この順序です。
*   C4: ミズキ $\neq$ 3
*   C5: アオイ > ユイ (アオイはユイより後)
*   C6: ハルト $\neq$ 2
*   C7: ミズキ $\neq$ 5

**2. 「アオイ、ソウタ」のペアの位置を考える**
アオイとソウタは隣接しているため、考えられるペアの位置は以下の4通りです。
*   パターンA: アオイ(1位), ソウタ(2位)
*   パターンB: アオイ(2位), ソウタ(3位)
*   パターンC: アオイ(3位), ソウタ(4位)
*   パターンD: アオイ(4位), ソウタ(5位)

これらに対して、他の条件を検証します。

---

**検証1: パターンA (アオイ1, ソウタ2)**
*   このとき、1位はアオイ。
*   C5「アオイはユイより後」より、ユイは1位よりも後である必要があるが、1位は最小位なので矛盾しません（ユイは2,3,4のいずれか）。しかし、2位はソウタなので、ユイは3位か4位になります。
*   残り人物: ハルト, ミズキ。残り順位: 3, 4 (ユイが3または4なら、ハルト・ミズキは残りの2つ)。
    *   もしユイ=3なら、残り順位は4,5にハルト・ミズキ。
        *   C1「ハルト < ミズキ」なので、ハルト4, ミズキ5。
        *   しかしC7「ミズキは最後(5位)ではない」に矛盾。
    *   もしユイ=4なら、残り順位は3,5にハルト・ミズキ。
        *   C1「ハルト < ミズキ」なので、ハルト3, ミズキ5。
        *   しかしC7「ミズキは最後(5位)ではない」に矛盾。
    *   また、C4「ミズキは3位ではない」も確認が必要ですが、上記でミズキは5位になっており矛盾しています。
*   **結論:** パターンAは不適。

**検証2: パターンB (アオイ2, ソウタ3)**
*   このとき、2位はアオイ、3位はソウタ。
*   C5「アオイ(2位)はユイより後」より、ユイは1位でなければならない。
    *   しかしC2「ユイは1位ではない」に矛盾。
*   **結論:** パターンBは不適。

**検証3: パターンC (アオイ3, ソウタ4)**
*   このとき、3位はアオイ、4位はソウタ。
*   C5「アオイ(3位)はユイより後」より、ユイは1位か2位。
*   C2「ユイは1位ではない」より、**ユイは2位**。
*   残り順位: 1, 5。残り人物: ハルト, ミズキ。
*   C1「ハルト < ミズキ」より、ハルトは1位、ミズキは5位。
    *   このときミズキは5位。
    *   しかしC7「ミズキは最後(5位)ではない」に矛盾。
*   **結論:** パターンCは不適。

**検証4: パターンD (アオイ4, ソウタ5)**
*   このとき、4位はアオイ、5位はソウタ。
*   C5「アオイ(4位)はユイより後」より、ユイは1, 2, 3位のいずれか。
*   C2「ユイは1位ではない」より、ユイは2位か3位。
*   残り順位: 1, 2, 3。残り人物: ハルト, ミズキ, ユイ。
*   C1「ハルト < ミズキ」。
*   C6「ハルトは2位ではない」。
*   C4「ミズキは3位ではない」。
*   C7「ミズキは最後(5位)ではない」→ 既に5位はソウタなのでOK。

ここでユイの位置を決めます。
*   **仮にユイが3位の場合:**
    *   残り順位: 1, 2。残り人物: ハルト, ミズキ。
    *   C1「ハルト < ミズキ」より、ハルト1, ミズキ2。
    *   この配置を確認:
        1. ハルト
        2. ミズキ
        3. ユイ
        4. アオイ
        5. ソウタ
    *   条件チェック:
        *   ハルト(1) < ミズキ(2) → OK (C1)
        *   ユイ(3) は1,5ではない → OK (C2)
        *   アオイ(4)の直後ソウタ(5) → OK (C3)
        *   ミズキ(2) は3位ではない → OK (C4)
        *   アオイ(4) > ユイ(3) → OK (C5)
        *   ハルト(1) は2位ではない → OK (C6)
        *   ミズキ(2) は最後ではない → OK (C7)
    *   **すべての条件を満たす。**
    *   この場合、3位はユイです。

*   **仮にユイが2位の場合:**
    *   残り順位: 1, 3。残り人物: ハルト, ミズキ。
    *   C1「ハルト < ミズキ」より、ハルト1, ミズキ3。
    *   しかしC4「ミズキは3位ではない」に矛盾。
    *   よって、ユイが2位の場合は成立しない。

したがって、唯一成立する順序は以下の通りです。
1. ハルト
2. ミズキ
3. ユイ
4. アオイ
5. ソウタ

3位に到着したのはユイです。

答え: ユイ
