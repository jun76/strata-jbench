### 2. Procedure for Searching a Record by ID

Since the data is presented as a sequence of lines, the search procedure depends on the underlying data structure implementation. Below are the standard algorithms for searching by ID.

#### A. Linear Search (Naïve Approach)
*   **Condition:** Data is stored as a list/array in the order it appears (ID 000001 to 000212).
*   **Procedure:**
    1.  Start from the first record (`record000001`).
    2.  Compare the ID part of each record with the target ID.
    3.  If it matches, return the record.
    4.  If not, move to the next record.
    5.  Repeat until the end of the list.
*   **Time Complexity:** $O(N)$
*   **Use Case:** Only effective for very small datasets or unsorted data.
