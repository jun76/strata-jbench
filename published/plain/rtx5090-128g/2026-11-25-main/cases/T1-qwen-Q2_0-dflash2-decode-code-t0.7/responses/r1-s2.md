## 設計要点

- **正規化**: 大小混在・句読点・Unicode 対応（`str.lower()` + Unicode-aware tokenizer）
- **表形式**: `tabulate` がない環境でも使える手製 ASCII 表（列幅自動調整・右/左对齐）
- **テスト**: 正常系・境界（N=0, N>total, 空ファイル・whitespace-only・BOM・Windows CRLF・Unicode・句読点・数字・hyphen・apostrophe・同頻度安定性・tie-break・`--all`・ファイル不存在・dir・encoding・stdin・`-` stdin・tabulate monkeypatch・CLI end-to-end・repeat）
