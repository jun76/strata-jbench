We need to count the number of integers from 1 to 2026 that are **not divisible by 3 and not divisible by 5**.

In other words, we want to count integers $n$ such that $1 \le n \le 2026$ and $3 \nmid n$ and $5 \nmid n$.

This is equivalent to:
Total numbers - (numbers divisible by 3 or 5)

By the inclusion-exclusion principle:
Number of integers divisible by 3 or 5 = $\lfloor 2026/3 \rfloor + \lfloor 2026/5 \rfloor - \lfloor 2026/15 \rfloor$

Then the answer is $2026 - \text{that value}$.

Let's compute:
$\lfloor 2026/3 \rfloor = 675$ because $3 \times 675 = 2025$.
$\lfloor 2026/5 \rfloor = 405$ because $5 \times 405 = 2025$.
$\lfloor 2026/15 \rfloor = 135$ because $15 \times 135 = 2025$.

So, count of numbers divisible by 3 or 5 = $675 + 405 - 135 = 945$.

Therefore, the number of integers not divisible by 3 or 5 = $2026 - 945 = 1081$.

Alternatively, we can use Euler’s totient-like periodic counting. In every block of 15, there are $\phi(15) = 8$ numbers coprime to 15, i.e., not divisible by 3 or 5.

2026 divided by 15: $2026 = 15 \times 135 + 1$.
So there are 135 full blocks of 15, each contributing 8 numbers: $135 \times 8 = 1080$.

Then we have remaining 1 number: 2026. We check if it is coprime to 15.
$2026 = 15 \times 135 + 1$, so the remainder is 1.
Is 1 divisible by 3 or 5? No. So it counts as 1 more.

Total = $1080 + 1 = 1081$.

The answer is 1081.
