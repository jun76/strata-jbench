The dataset is a simple, uniformly structured list of records.

## Structure

Each line has this format:

```text
recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.
```

Where:

- `recordNNNNNN` is the record ID.
  - It starts with the literal prefix `record`.
  - It is followed by a 6-digit zero-padded number.
  - Example: `record000001`, `record000815`, `record006733`.
- A colon `:` separates the ID from the record content.
- The content is always the same sequence of eight Greek-letter placeholder
