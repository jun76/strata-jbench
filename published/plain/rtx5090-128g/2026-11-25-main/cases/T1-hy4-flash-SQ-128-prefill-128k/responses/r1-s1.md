The records form a simple, uniform log:

- Each line starts with an ID in the form `recordNNNNNN`.
- The ID is a zero-padded six-digit number, e.g. `record000001`, `record000999`, `record006733`.
- After the ID is a colon and one space.
- Every record has the exact same payload:

```text
alpha beta gamma delta epsilon zeta eta theta.
```

So the general structure is:

```text
record<6-digit ID>: alpha beta gamma delta epsilon zeta eta theta.
```
