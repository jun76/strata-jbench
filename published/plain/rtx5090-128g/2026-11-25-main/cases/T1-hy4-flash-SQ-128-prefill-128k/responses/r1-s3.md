The dataset is a simple, uniformly structured list of records.

## Structure

Each line has this format:

```text
record<ID>: alpha beta gamma delta epsilon zeta eta theta.
```

Where:

- `record` is a fixed prefix.
- `<ID>` is a zero-padded 6-digit decimal number, ranging from `000001` to `006733`.
- A colon `:` separates the record ID from the record body.
- The body is always the same eight Greek-alphabet placeholder words:

```text
alpha beta gamma delta epsilon zeta eta theta.
```
