To determine which box contains the prize, we analyze the truth values of the three labels under each possible scenario. We know that **exactly one** label is true, and the other two are false.

- Label A: "The prize is in box A."
- Label B: "The prize is not in box B."
- Label C: "The prize is not in box A."

Let's test each possibility for the location of the prize.

### Scenario 1: The prize is in Box A
- **Label A**: "The prize is in box A." -> **True**
- **Label B**: "The prize is not in box B." -> **True** (Since the prize is in A, it is indeed not in B)
- **Label C**: "The prize is not in box A." -> **False** (Since the prize is in A)

In this scenario, there are **two** true labels (A and B). This contradicts the condition that exactly one label is true. Therefore, the prize is **not** in Box A.

- **Label A**: "The prize is in box A." -> **False** (The prize is in B)
- **Label B**: "The prize is not in box B." -> **False** (The prize is in B, so the statement "not in B" is false)
- **Label C**: "The prize is not in box A." -> **True** (Since the prize is in B, it is not in A)

In this scenario, there is **exactly one** true label (Label C). This satisfies all conditions. Therefore, the prize **is** in Box B.

### Scenario 3: The prize is in Box C
- **Label A**: "The prize is in box A." -> **False** (The prize is in C)
- **Label B**: "The prize is not in box B." -> **True** (Since the prize is in C, it is not in B)
- **Label C**: "The prize is not in box A." -> **True** (Since the prize is in C, it is not in A)

In this scenario, there are **two** true labels (B and C). This contradicts the condition that exactly one label is true. Therefore, the prize is **not** in Box C.

### Conclusion
Only Scenario 2 (The prize is in Box B) results in exactly one true label.
