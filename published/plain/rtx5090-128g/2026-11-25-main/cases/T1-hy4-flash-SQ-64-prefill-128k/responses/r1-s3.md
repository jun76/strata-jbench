The dataset is a numbered list of records. Each record has the same structure:

- **ID format:** `record` followed by a 6-digit zero-padded number  
  Example: `record000001`, `record000872`, `record006733`
- **Content:** each record contains the same eight Greek-letter labels in the same order:  
  `alpha beta gamma delta epsilon zeta eta theta`
- **Range:** records run consecutively from `record000001` through `record006733`.

So the structure is uniform and highly repetitive: every record ID maps to the same payload text.
