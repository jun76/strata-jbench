The dataset is a simple, uniform list of records.

## Structure

Each line has the form:

```text
record<ID>: alpha beta gamma delta epsilon zeta eta theta.
```

- **ID**: a zero-padded 6-digit number, e.g. `000001`, `000733`.
- **Prefix**: the literal word `record` followed by the ID and a colon.
- **Content**: every record has exactly the same eight Greek-letter tokens:
  - `alpha`
  - `beta`
  - `gamma`
  - `delta`
  - `epsilon`
  - `zeta`
