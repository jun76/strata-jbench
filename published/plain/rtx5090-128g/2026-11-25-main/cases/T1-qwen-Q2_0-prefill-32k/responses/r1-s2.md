### Structure of the Records

The dataset consists of a linear sequence of records, each formatted as follows:

1. **Record ID**: Each record begins with the keyword `record` followed by a 6-digit zero-padded number (e.g., `record000001`, `record001721`).
2. **Separator**: A colon (`:`) separates the ID from the content.
3. **Content**: Every record contains the identical string: `alpha beta gamma delta epsilon zeta eta theta`.
