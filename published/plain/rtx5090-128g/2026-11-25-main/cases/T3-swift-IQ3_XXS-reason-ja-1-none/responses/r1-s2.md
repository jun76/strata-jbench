5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の到着順を推理します。

**条件の整理:**
1. ハルト < ミズキ
2. ユイ $\neq$ 1位, ユイ $\neq$ 5位 $\rightarrow$ ユイは 2, 3, 4位のいずれか
3. ソウタはアオイのすぐ後 $\rightarrow$ ソウタ = アオイ + 1 （「アオイ、ソウタ」のブロックが存在）
4. ミズキ $\neq$ 3位
5. アオイ > ユイ
6. ハルト $\neq$ 2位
7. ミズキ $\neq$ 5位

**推理プロセス:**

**ステップ1: ミズキの位置を絞る**
条件4と条件7より、ミズキは3位でも5位でもありません。
よって、ミズキは1位、2位、4位のいずれかです。
条件1（ハルト < ミズキ）より、ミズキは1位にはなれません（ハルトがミズキより前に着く必要があるため、1位はハルトより前に着く人がいられない）。
したがって、**ミズキは2位または4位**です。

**ステップ2: ハルトの位置を検討**
条件6より、ハルトは2位ではありません。

**ケースA: ミズキが2位の場合**
* ミズキ = 2位
* 条件1より、ハルト < ミズキ(2位) $\rightarrow$ ハルトは1位です。（条件6と矛盾なし）
* この時点で1位: ハルト, 2位: ミズキ。残りは3, 4, 5位にアオイ、ソウタ、ユイ。
* 条件3「アオイ、ソウタ」のブロック。
    * アオイが3位 $\rightarrow$ ソウタ4位。残り5位: ユイ。
        * 条件2よりユイは5位不可。$\rightarrow$ 不可
    * アオイが4位 $\rightarrow$ ソウタ5位。残り3位: ユイ。
        * 条件2よりユイは5位不可、1位不可。3位はOK。
        * 条件5より アオイ > ユイ。
        * 順序: 1ハルト, 2ミズキ, 3ユイ, 4アオイ, 5ソウタ。
        * 条件5チェック: アオイ(4) > ユイ(3)。OK。
        * 条件2チェック: ユイ(3)。OK。
        * 条件4チェック: ミズキ(2) $\neq$ 3。OK。
        * 条件7チェック: ミズキ(2) $\neq$ 5。OK。
        * このケースは有効です。この場合、3位は**ユイ**です。
    * アオイが1位など不可能（1位はハルト）。
* よって、ケースAでの解は「1:ハルト, 2:ミズキ, 3:ユイ, 4:アオイ, 5:ソウタ」。

**ケースB: ミズキが4位の場合**
* ミズキ = 4位
* 条件1より、ハルト < ミズキ(4位)。ハルトは1, 2, 3位のいずれか。
* 条件6より、ハルト $\neq$ 2位。よってハルトは1位または3位。

    **サブケースB1: ハルトが1位**
    * 1位: ハルト, 4位: ミズキ。残り2, 3, 5位にアオイ、ソウタ、ユイ。
    * 「アオイ、ソウタ」のブロックは連続している必要がある。
        * 可能な場所: (2,3) または (3,4)?? $\rightarrow$ 4位はミズキなので不可。 (5,?)不可。
        * よって、アオイ=2位, ソウタ=3位 のみ。
        * この場合、残り5位はユイ。
        * 条件2より、ユイは5位不可。$\rightarrow$ 不可

    **サブケースB2: ハルトが3位**
    * 3位: ハルト, 4位: ミズキ。残り1, 2, 5位にアオイ、ソウタ、ユイ。
    * 「アオイ、ソウタ」のブロックは連続している必要がある。
        * 残っている連続する2つの場所はない（1,2は連続だが5は孤立）。
        * アオイ=1位 $\rightarrow$ ソウタ=2位。残り5位: ユイ。
            * 条件2よりユイは5位不可。$\rightarrow$ 不可
        * アオイ=2位 $\rightarrow$ ソウタ=3位。$\rightarrow$ 3位はハルト。矛盾。
        * アオイ=4位? $\rightarrow$ 4位はミズキ。矛盾。
        * アオイ=5位? $\rightarrow$ ソウタ=6位（なし）。
    * よって、サブケースB2は解なし。

以上より、唯一の解はケースAです。

**検証:**
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

条件確認:
- ハルト(1) < ミズキ(2) : OK
- ユイ(3) は1,5位ではない : OK
- ソウタ(5) はアオイ(4)のすぐ後 : OK
- ミズキ(2) は3位ではない : OK
- アオイ(4) > ユイ(3) : OK
- ハルト(1) は2位ではない : OK
- ミズキ(2) は最後(5位)ではない : OK

すべての条件を満たします。

3位に到着したのはユイです。

答え: ユイ
