駅に到着した順番について、与えられた条件を整理して論理的に推导を進めます。

**人物:** アオイ、ハルト、ミズキ、ソウタ、ユイ（5人）
**順位:** 1位, 2位, 3位, 4位, 5位

**条件の整理:**
1. ハルト < ミズキ （ハルトがミズキより前）
2. ユイ ≠ 1位, ユイ ≠ 5位
3. アオイの直後がソウタ （アオイ, ソウタ が連続）
4. ミズキ ≠ 3位
5. ユイ < アオイ （ユイがアオイより前）
6. ハルト ≠ 2位
7. ミズキ ≠ 5位

---

### ステップ1: 連続グループ「(アオイ, ソウタ)」の位置を特定する

条件3より、アオイとソウタは「...アオイ, ソウタ...」という形で連続しています。
また、条件5より「ユイ < アオイ」なので、ユイはアオイより前にいます。
したがって、ユイは「アオイ, ソウタ」ペアの前方に位置しています。

「アオイ, ソウタ」の可能な開始位置（アオイの順位）は、ペア全体で4位まで（ソウタが5位ならアオイは4位）です。
つまり、アオイは1位、2位、3位、4位都有可能ですが、条件により絞り込めます。

*   **アオイが1位の場合:** ソウタは2位。
*   **アオイが2位の場合:** ソウタは3位。
*   **アオイが3位の場合:** ソウタは4位。
*   **アオイが4位の場合:** ソウタは5位。

### ステップ2: ハルト、ミズキ、ユイの位置を考慮する

残りの3人はハルト、ミズキ、ユイです。
条件1: ハルト < ミズキ
条件5: ユイ < アオイ

ここから、アオイの各パターンを検討します。

#### 仮定A: アオイが1位、ソウタが2位の場合
残りの順位は 3, 4, 5 です。
人物は ハルト、ミズキ、ユイ が入ります。
条件より:
- ユイ < アオイ(1位) → ユイは1位より前になれない。
- **矛盾**。アオイが1位なら、ユイはアオイより前に着くことができません。
→ **アオイは1位ではない。**

#### 仮定B: アオイが2位、ソウタが3位の場合
残りの順位は 1, 4, 5 です。
人物は ハルト、ミズキ、ユイ が1位、4位、5位に入ります。
条件:
- ユイ < アオイ(2位) → ユイは1位でなければならない。
  → **ユイ = 1位**
- 残りは ハルト と ミズキ で、4位と5位に入る。
- ハルト < ミズキ → ハルト=4位, ミズキ=5位。
- 条件7: ミズキは5位ではない。
- **矛盾**。
→ **アオイは2位ではない。**

#### 仮定C: アオイが3位、ソウタが4位の場合
残りの順位は 1, 2, 5 です。
人物は ハルト、ミズキ、ユイ が1位、2位、5位に入ります。
条件:
- ユイ < アオイ(3位) → ユイは1位か2位。
- 条件2: ユイ ≠ 1位 → **ユイ = 2位**。
- 残りの順位は 1位 と 5位。人物は ハルト と ミズキ。
- ハルト < ミズキ → ハルト=1位, ミズキ=5位。
- 条件7: ミズキは5位ではない。
- **矛盾**。
→ **アオイは3位ではない。**

#### 仮定D: アオイが4位、ソウタが5位の場合
残りの順位は 1, 2, 3 です。
人物は ハルト、ミズキ、ユイ が1位、2位、3位に入ります。
条件:
- ユイ < アオイ(4位) → ユイは1, 2, 3のいずれか。これは満たされている。
- 条件2: ユイ ≠ 1位, ユイ ≠ 5位。
  → ユイは **2位** または **3位**。
- ハルト < ミズキ
- 条件6: ハルト ≠ 2位
- 条件4: ミズキ ≠ 3位

残りの枠: 1位, 2位, 3位 に ハルト, ミズキ, ユイ を配置する。

ユイの候補: 2位 or 3位

**ケースD-1: ユイが2位の場合**
残りの枠は 1位, 3位。人物は ハルト, ミズキ。
- ハルト < ミズキ → ハルト=1位, ミズキ=3位。
- 条件4: ミズキ ≠ 3位 → **矛盾**。

**ケースD-2: ユイが3位の場合**
残りの枠は 1位, 2位。人物は ハルト, ミズキ。
- ハルト < ミズキ → ハルト=1位, ミズキ=2位。
- 条件6: ハルト ≠ 2位 → ハルト=1位なのでOK。
- 条件4: ミズキ ≠ 3位 → ミズキ=2位なのでOK。
- 条件2: ユイ=3位 → 1位でも5位でもないのでOK。

このケースがすべて条件を満たすか確認します。
- 1位: ハルト
- 2位: ミズキ
- 3位: ユイ
- 4位: アオイ
- 5位: ソウタ

チェック:
1. ハルト(1) < ミズキ(2) → OK
2. ユイ(3) は1位でも5位でもないのでOK
3. アオイ(4) のすぐ後がソウタ(5) → OK
4. ミズキ(2) は3位ではない → OK
5. ユイ(3) < アオイ(4) → OK
6. ハルト(1) は2位ではない → OK
7. ミズキ(2) は最後(5位)ではない → OK

すべての条件を満たす唯一の組み合わせが見つかりました。

### 結論
3位に到着したのは **ユイ** です。

答え: ユイ
