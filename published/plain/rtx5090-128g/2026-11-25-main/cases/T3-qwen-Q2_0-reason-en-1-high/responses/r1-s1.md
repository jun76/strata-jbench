Let the prize be in box A:  
- A’s label is true.  
- B’s label is true.  
- C’s label is false.  
That gives two true labels, not exactly one.

Let the prize be in box B:  
- A’s label is false.  
- B’s label is false.  
- C’s label is true.  
That gives exactly one true label.

Let the prize be in box C:  
- A’s label is false.  
- B’s label is true.  
- C’s label is true.  
That gives two true labels, not exactly one.

Therefore, the prize is in box B.

Answer: B
