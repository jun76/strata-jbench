## レコードの構造

各レコードは、ID とそのレコードに含まれる文字列から構成されています。

- 例: `record000001`
- 内容: `alpha beta gamma delta epsilon zeta eta theta`

つまり、レコードは「識別子（ID）」と「値（この場合は 8 個の単語からなる文字列）」のペアとして扱えます。

構造としては次のように整理できます。

```text
recordID: レコードを一意に識別する番号
content: レコードに格納された文字列
```

今回のケースでは、`record000001` から `record002012` までのレコードがあり、すべてのレコードが同じ文字列 `alpha beta gamma delta epsilon zeta eta theta` を持っています。

## ID からレコードを探す手順

ID からレコードを探す場合、基本的な手順は次の通りです。

1. 探したい ID を確認する  
   例: `record000123`

2. レコード一覧から同じ ID を探す  
   `record000123` に対応する行を探します。

3. 対応するレコードの内容を取得する  
   今回のケースでは、対応する内容は  
   `alpha beta gamma delta epsilon zeta eta theta`  
   です。

4. 見つからなかった場合は「該当レコードなし」と判断する  
   ID が一覧に存在しない場合は、該当レコードは存在しません。

単純な実装では、レコードを順番に見ていき、ID が一致する行を探すことになります。
