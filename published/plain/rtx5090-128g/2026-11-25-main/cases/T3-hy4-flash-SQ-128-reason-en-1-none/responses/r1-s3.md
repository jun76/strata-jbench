Let’s check each possibility.

Labels:  
- A: “Prize is in A”  
- B: “Prize is not in B”  
- C: “Prize is not in A”  

Exactly one label is true.

---

**Case 1: Prize in A**  
- A: “Prize in A” → True  
- B: “Prize not in B” → True (since prize is in A, not in B)  
- C: “Prize not in A” → False  

Two labels true (A and B) → violates condition.

---

**Case 2: Prize in B**  
- A: “Prize in A” → False  
- B: “Prize not in B” → False  
- C: “Prize not in A” → True  

Only C true → satisfies condition.

---

**Case 3: Prize in C**  
- A: “Prize in A” → False  
- B: “Prize not in B” → True (prize in C, not in B)  
- C: “Prize not in A” → True  

Two labels true (B and C) → violates condition.

---

Only Case 2 works.

Answer: B
