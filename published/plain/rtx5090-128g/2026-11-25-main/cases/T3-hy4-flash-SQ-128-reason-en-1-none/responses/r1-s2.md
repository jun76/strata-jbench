Box A’s label says: “The prize is in this box” → prize is in A.  
Box C’s label says: “The prize is not in box A” → prize is not in A.

These two labels are exact opposites, so exactly one of A’s and C’s labels must be true.

Since exactly one of all three labels is true, Box B’s label must be false.

Box B’s label says: “The prize is not in this box.” If that is false, then the prize is in Box B.

Check:  
- A: “prize is in A” → false  
- B: “prize is not in B” → false  
- C: “prize is not in A” → true  

Exactly one label is true.

Answer: B
