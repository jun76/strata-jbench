## 1. レコードの構造の説明

### 1.1 全体フォーマット

各レコードは次のような固定形式のテキスト行です：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると、以下の 3 要素で構成されています。

| 要素 | 内容 | 例 |
|---|---|---|
| ① ID 部分 | `record` + 6桁のゼロ埋め整数 + `:` | `record000001:` |
| ② 区切り | コロン `:` の直後の半角スペース 1 文字 | `: ` |
| ③ データ本体 | 8 個のギリシャ文字名が半角スペースで並び、末尾にピリオド `.` | `alpha beta gamma delta epsilon zeta eta theta.` |

### 1.2 ID の特徴

- 接頭辞：`record`
- 数値部：**6 桁固定・ゼロ埋め（zero-padding）**
  - `000001` 〜 `000212`（ご提示時点）
  - したがって `record1` ではなく `record000001` と表記されます
- 区切り文字：コロン `:`（ID と本体を分離）
- ID は **連番** であり、飛び番号はありません（提示範囲内では）

> 補足：ゼロ埋めにより、文字列としてソートしても数値順と一致するという重要な性質があります。  
> 例：`record000009 < record000010 < record000100`（辞書順＝数値順）

### 1.3 データ本体の特徴

本体は常に同じ 8 トークンです：

```
alpha beta gamma delta epsilon zeta eta theta.
```

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |

- 区切り：半角スペース 1
