以下、要件を満たす「単語出現頻度を集計し、上位 N 件をテーブルで表示する CLI ツール」と、対応する `pytest` テスト、そしてプロジェクト構成の例を示します。

## 1. プロジェクト構成（推奨）

```
word_freq_cli/
├── pyproject.toml
├── src/
│   └── word_freq_cli/
│       ├── __init__.py
│       └── main.py
└── tests/
    ├── __init__.py
    ├── test_main.py
    └── fixtures/
        ├── sample.txt
        └── sample_dupes.txt
```

> 注: `src/` を使ったレイアウトにすると、テスト実行時にパッケージ名が隠れて混乱しにくいです。`tests/` からも `from word_freq_cli.main import ...` で import できます（`pyproject.toml` で `src` をルートに設定するため）。

---

## 2. `pyproject.toml`

```toml
[build-system]
requires = ["setuptools>=68.0"]
build-backend = "setuptools.build_meta"

[project]
name = "word-freq-cli"
version = "0.1.0"
description = "Count word frequencies in text files and show the top N words."
requires-python = ">=3.10"
dependencies = []

[project.scripts]
wordfreq = "word_freq_cli.main:main"

[tool.setuptools.packages.find]
where = ["src"]

[tool.pytest.ini_options]
pythonpath = ["src"]
testpaths = ["tests"]
addopts = "-v --tb=short"
```

## 4. `src/word_freq_cli/main.py`

```python
"""Command-line tool to count word frequencies in a text file.

The tool tokenizes text on word boundaries, optionally lowercases tokens,
excludes tokens that are entirely non-word characters, counts occurrences,
and prints the top N entries in a simple table.

Examples
--------
    wordfreq sample.txt
