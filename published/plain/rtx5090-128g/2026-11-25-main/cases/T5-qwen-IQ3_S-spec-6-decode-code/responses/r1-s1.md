以下に、要件を満たすコマンドラインツール `word_freq.py` と、その単体テスト `test_word_freq.py` を示します。

### 1. `word_freq.py`

```python
#!/usr/bin/env python3
"""
word_freq.py

テキストファイルを読み込み、単語の出現頻度をカウントし、
上位 N 件の単語とその頻度を表形式で出力するコマンドラインツールです。

単語の認識は正規表現 `[a-zA-Z0-9']+` を使用し、大文字・小文字は無視します。
"""

import argparse
import re
import sys
from collections import Counter
from typing import List, Tuple, Dict


def extract_words(text: str) -> List[str]:
    """
    入力テキストから単語を抽出します。

    Args:
        text: 解析対象のテキスト文字列。

    Returns:
        小文字に変換された単語のリスト。
    """
    # 英数字とアポストロフィを含む連続した文字列を単語とみなす
    return [word.lower() for word in re.findall(r"[a-zA-Z0-9']+", text)]


def count_frequencies(words: List[str]) -> Dict[str, int]:
    """
    単語リストから出現頻度をカウントします。

    Args:
        words: 単語のリスト。

    Returns:
        単語をキー、出現回数を値とする辞書。
    """
    return dict(Counter(words))


def get_top_n(
    freq_dict: Dict[str, int], n: int
) -> List[Tuple[str, int]]:
    """
    頻度辞書から上位 n 件の (単語, 頻度) タプルを返します。
    頻度が同じ場合は、単語の辞書順で昇順にソートします。

    Args:
        freq_dict: 単語と頻度の辞書。
        n: 取得する上位件数。

    Returns:
        上位 n 件の (単語, 頻度) のリスト。
    """
    # 頻度の降順、頻度が同数の場合は単語の昇順
    sorted_items = sorted(
        freq_dict.items(),
        key=lambda x: (-x[1], x[0])
    )
    return sorted_items[:n
