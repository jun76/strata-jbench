以下、提示されたレコード群の構造、ID からレコードを探す手順、件数増加時に高速に検索するための工夫を詳しく説明します。

---

## 1. レコードの構造

### 1.1 全体形式

各レコードは 1 行で表され、次の形をしています。

```
record<6桁の連番>: <トークン列>.
```

例：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

### 1.2 構成要素

| 要素 | 内容 | 例 | 特徴 |
|---|---|---|---|
| レコード ID | `record` + 6 桁のゼロ埋め整数 | `record000001` | 一意・連番・昇順 |
| 区切り | コロン `:` と半角スペース 1 個 | `: ` | ID と本体を分離 |
| 本体 | 8 個のギリシャ文字名 | `alpha beta gamma delta epsilon zeta eta theta` | 全レコードで同一 |
| 終端 | ピリオド `.` | `.` | 行末に付与 |

### 1.3 詳細構造（分解例）

`record000212: alpha beta gamma delta epsilon zeta eta theta.` を分解すると：

| 位置 | 文字列 | 意味 |
|---|---|---|
| 1–6 | `record` | 固定プレフィックス |
| 7–12 | `000212` | 6 桁ゼロ埋め連番 |
| 13 | `:` | 区切り記号 |
| 14 | ` ` | 区切りスペース |
| 15–19 | `alpha` | 第 1 トークン |
| 20 | ` ` | 区切り |
| 21–25 | `beta` | 第 2 トークン |
| … | … | … |
| 最後 | `.` | 行末 |

### 1.4 データ上の特徴

- **ID は連続している**：`000001` から `000212` まで欠番なし
- **本体は完全に同一**：全 212 レコードでペイロードは同じ
- **ソート済み**：ID の辞書順 = 数
