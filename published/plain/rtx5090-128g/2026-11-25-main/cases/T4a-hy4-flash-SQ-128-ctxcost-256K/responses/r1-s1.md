## 1. レコード構造の説明

### 1.1 全体形式

各レコードは次のような固定形式のテキスト行です：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると：

| 要素 | 内容 | 説明 |
|---|---|---|
| レコードID | `record000001` | 先頭に付く一意な識別子 |
| 区切り | `:`（コロン） | ID と本文を分離 |
| 本文 | `alpha beta gamma delta epsilon zeta eta theta.` | 8 個のギリシャ文字名が半角スペース区切り |
| 終端 | `.`（ピリオド） | 文末記号（意味上の終端。必須ではないが統一されている） |

### 1.2 ID の構造

- 接頭辞：`record`
- 数字部：6 桁のゼロ埋め十进制（`000001` ～ `000212` まで確認）
- 形式：`record` + `%06d`

例：

| 数値 | ID |
|---|---|
| 1 | `record000001` |
| 9 | `record000009` |
| 10 | `record000010` |
| 99 | `record000099` |
| 100 | `record000100` |
| 212 | `record000212` |

**重要な性質**
- ゼロ埋めにより **辞書順 = 数値順** になる
  - `record000099` < `record000100`
- したがって文字列比較でも正しい順序が保証される

### 1.3 本文の構造

本文は常に同じトークン列です：

```
alpha beta gamma delta epsilon zeta eta theta.
```

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |

- 区切り：半角スペース 1 個
- 末尾：`.` が `theta` に直接付く（`theta.`）
