## 1. レコードの構造

各レコードは次のような形です。

`record000001: alpha beta gamma delta epsilon zeta eta theta.`

つまり、

- 先頭に ID がある
- その後に 8 個の値が並んでいる
- 最後にピリオド `.` が付いている

このデータは「ID と 8 項目の列」として扱えます。

---

## 2. ID からレコードを探す手順

ID からレコードを探す場合、基本は次の手順です。

1. ID を読み取る
2. ID を `record` と数字の部分に分ける
3. 数字を整数として扱う
4. レコード一覧を順に見て、同じ ID の行を探す
5. 見つけた行の 8 項目を取り出す

例えば `record000050` を探すなら、

1. `record000050` を読み取る
2. `record` と `000050` を分ける
3. 数字を 50 として扱う
4. 一覧で `record000050` の行を探す
5. その行の `alpha beta gamma delta epsilon zeta eta theta` を取り出す
