## 1. レコード構造の説明

### 1.1 全体形式

各レコードは次のような固定形式のテキスト行です：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

これを分解すると：

| 要素 | 内容 | 説明 |
|---|---|---|
| レコードID | `record000001` | 先頭に付く識別子。`record` + 6桁のゼロ埋め連番 |
| 区切り | `:` | ID と本文を分離する区切り文字（コロン＋半角スペース） |
| 本文 | `alpha beta gamma delta epsilon zeta eta theta.` | 8 個のギリシャ文字名が半角スペースで並び、末尾にピリオド |

### 1.2 ID の特徴

- 形式：`record` + 6桁の十进制数
- 例：
  - `record000001`
  - `record000096`
  - `record000212`
- ゼロ埋め（zero-padding）されているため、**文字列としてソートしても数値順と一致**します。
  - `record000009 < record000010`
  - `record000099 < record000100`
- 現在の範囲：`record000001` 〜 `record000212`（212 件）

### 1.3 本文の特徴

- トークン数：常に 8 個
- トークン一覧（順序固定）：

| 位置 | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |

- 末尾に `.`（ピリオド）が付く
- すべてのレコードで本文は**完全に同一**
- つまり、実質的に「ID だけが異なる」構造です
