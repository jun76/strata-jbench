以下、要件を満たす完成コード一式です。単一ファイルで動作するCLIツール（`freq.py`）と、それに対応する pytest テスト（`test_freq.py`）を用意しました。

## 設計方針

- **解析**: `unicodedata.normalize('NFC')` で正規化 → 正規表現 `[^\w]+` で区切り、小文字化。トークン化は `[^\w]+` スプリットに依存し、境界を `[A-Za-z0-9_]+` パターンで抽出して「無効な空トークン」が生まれないように防御的に処理します。
- **集計**: `collections.Counter` を使用。タイブレークは「頻度降順 → 辞書順」。
- **表示**: 固定列の ASCII テーブル（ヘッダ＋区切り線＋行）。幅は内容に応じて自動計算。
- **CLI**: `argparse` でファイル（複数可）、`-n/--top`（デフォルト10）、`-o/--output`（省略時 stdout）を扱う。
- **設計**: 入力読込は1行ずつストリーム読み込み（大容量ファイル対応）。ファイル/エンコーディングエラーは `SystemExit` を伴わず返すため、CLI とテストの双方で再利用可能。
