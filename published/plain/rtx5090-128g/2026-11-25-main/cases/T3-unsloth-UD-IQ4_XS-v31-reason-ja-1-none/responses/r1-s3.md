各人の到着順（1位から5位）を決定するための論理推論をステップバイステップで行います。

与えられた条件を整理します。
1. ハルト < ミズキ （ハルトはミズキより前）
2. ユイ ≠ 1, ユイ ≠ 5
3. ソウタ = アオイ + 1 （アオイのすぐ後、つまり2人の位置は連続で、アオイが前）
4. ミズキ ≠ 3
5. ユイ < アオイ （ユイはアオイより前）
6. ハルト ≠ 2
7. ミズキ ≠ 5

**ステップ1: ハルトとミズキの位置の候補を絞り込む**
条件1より、ハルトはミズキより前にいます。
条件6より、ハルトは2位ではありません。
条件4と7より、ミズキは3位でも5位でもありません。
さらに条件1から、ミズキはハルトより後ろなので、ハルトが4位か5位であればミズキはそれより後ろになれません（5位が最大）。
したがって、ハルトの位置候補は1位または3位です。

*   **ケースA: ハルトが3位の場合**
    *   条件1より、ミズキは4位か5位です。
    *   条件4（ミズキ≠3）と条件7（ミズキ≠5）より、ミズキは4位でなければなりません。
    *   この場合、残り位は1, 2, 5です。残りの人はアオイ、ソウタ、ユイです。
    *   条件3より、アオイとソウタは連続しています（アオイ→ソウタ）。
    *   残りの空き位は1, 2, 5です。連続しているのは1と2だけなので、アオイ=1, ソウタ=2となります。
    *   残るユイは5位になります。
    *   しかし、条件2より「ユイは5位ではない」とあります。これは矛盾します。
    *   したがって、**ハルトが3位であるケースは不適**です。

*   **ケースB: ハルトが1位の場合**
    *   残り位は2, 3, 4, 5です。
    *   条件1より、ミズキは2, 3, 4, 5のいずれかより後ろにいます。つまりミズキは2〜5位のどれかです。
    *   条件4（ミズキ≠3）と条件7（ミズキ≠5）より、ミズキの候補は**2位**または**4位**です。

    **サブケースB-1: ミズキが2位の場合**
    *   残り位は3, 4, 5です。残りの人はアオイ、ソウタ、ユイです。
    *   条件3より、アオイとソウタは連続しています。空き位は3, 4, 5なので、連続ペアは(3,4)または(4,5)です。
    *   条件5より、ユイはアオイより前にいます（ユイ < アオイ）。
    *   もしアオイ=4, ソウタ=5の場合、ユイは3位になります。
        *   この場合の並びは：1.ハルト, 2.ミズキ, 3.ユイ, 4.アオイ, 5.ソウタ
        *   条件2チェック：ユイは3位（1でも5でもない）→ OK
        *   条件5チェック：ユイ(3) < アオイ(4) → OK
        *   他の条件もすべて満たしているように見えます。いったん保留します。
    *   もしアオイ=3, ソウタ=4の場合、ユイは5位になります。
        *   条件2よりユイは5位ではないので、これは**不適**です。
    
    よって、ミズキが2位の候補解は「1.ハルト, 2.ミズキ, 3.ユイ, 4.アオイ, 5.ソウタ」です。
    この場合、3位は**ユイ**です。

    **サブケースB-2: ミズキが4位の場合**
    *   残り位は2, 3, 5です。残りの人はアオイ、ソウタ、ユイです。
    *   条件3より、アオイとソウタは連続しています。
    *   残りの空き位2, 3, 5の中で連続しているのは2と3だけです。
    *   したがって、アオイ=2, ソウタ=3となります。
    *   残るユイは5位になります。
    *   しかし、条件2より「ユイは5位ではない」とあります。これは矛盾します。
    *   したがって、**ミズキが4位であるケースは不適**です。

    ※念のため、ハルトが1位でミズキが他の位置の可能性も考えますが、既に「ハルトは2位ではない」「ハルトはミズキより前」なのでハルトは1位のみ確定です。
    ※ハルトが1位の場合、ミズキは2位または4位しかないと前述しましたが、もしミズキが3位や5位ではないため除外済みです。

    唯一残った有効な組み合わせは以下の通りです。
    1. ハルト
    2. ミズキ
    3. ユイ
    4. アオイ
    5. ソウタ

    この並びがすべての条件を満たすか最終確認します。
    - ハルト(1) < ミズキ(2) → OK
    - ユイ(3) は1位でも5位でもない → OK
    - ソウタ(5) はアオイ(4) のすぐ後 → OK
    - ミズキ(2) は3位ではない → OK
    - アオイ(4) はユイ(3) より後 → OK
    - ハルト(1) は2位ではない → OK
    - ミズキ(2) は最後ではない → OK

    よって、3位に到着したのはユイです。

答え: ユイ
