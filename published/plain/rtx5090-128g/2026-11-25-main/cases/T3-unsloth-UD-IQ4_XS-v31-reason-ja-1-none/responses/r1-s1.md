5人の到着順（1位〜5位）を論理的に推理します。

**条件の整理:**
1. ハルト < ミズキ （ハルトがミズキより前）
2. ユイ $\neq$ 1位, ユイ $\neq$ 5位
3. アオイ + 1 = ソウタ （ソウタはアオイのすぐ後、つまり「アオイ、ソウタ」の連続ブロック）
4. ミズキ $\neq$ 3位
5. ユイ < アオイ （ユイがアオイより前）
6. ハルト $\neq$ 2位
7. ミズキ $\neq$ 5位

**推理のステップ:**

**ステップ1: 「アオイ、ソウタ」のペアの位置を特定する**
条件3より、「アオイ、ソウタ」は隣接しています。可能な位置パターンは以下の4つです。
- パターンA: 1位アオイ, 2位ソウタ
- パターンB: 2位アオイ, 3位ソウタ
- パターンC: 3位アオイ, 4位ソウタ
- パターンD: 4位アオイ, 5位ソウタ

条件5より「ユイ < アオイ」です。
- パターンAの場合、アオイが1位なので、ユイは1位より前である必要がありますが、1位より前は存在しません。よって**パターンAは不可能**。

**ステップ2: 残りのパターンを検証する**

**ケース1: パターンB (2位アオイ, 3位ソウタ)**
- アオイが2位なら、条件5（ユイ < アオイ）より、**ユイは1位**でなければなりません。
- しかし条件2より、ユイは1位ではありません。
- よって**パターンBも不可能**。

**ケース2: パターンC (3位アオイ, 4位ソウタ)**
- 残りのポジションは1位、2位、5位です。残りの人物はハルト、ミズキ、ユイです。
- 条件5（ユイ < アオイ=3位）より、ユイは1位か2位です。
- 条件2（ユイ $\neq$ 1位, $\neq$ 5位）より、**ユイは2位**です。
- 残りのポジションは1位と5位。残りの人物はハルトとミズキです。
- 条件1（ハルト < ミズキ）より、**1位はハルト、5位はミズキ**となります。
- ここで他の条件と矛盾がないか確認します。
  - ミズキは5位ですが、条件7「ミズキは最後（5位）ではない」に**矛盾**します。
- よって**パターンCも不可能**。

**ケース3: パターンD (4位アオイ, 5位ソウタ)**
- 残りのポジションは1位、2位、3位です。残りの人物はハルト、ミズキ、ユイです。
- 条件5（ユイ < アオイ=4位）は、ユイが1〜3位であれば常に満たされるので、この条件から直接ユイの位置は決まりません。
- 条件2より、**ユイは1位でも5位でもありません**。残りの1,2,3位の中でユイは1位か2位か3位ですが、5位はソウタなので条件2の5位ではないは自動的に満たされます。重要なのは**ユイ $\neq$ 1位**です。
  - つまり、ユイは2位か3位です。

ここで、ハルトとミズキの位置を考えます。
- 残りの枠は1位、2位、3位です。人物はハルト、ミズキ、ユイ。
- 条件1（ハルト < ミズキ）
- 条件4（ミズキ $\neq$ 3位）
- 条件6（ハルト $\neq$ 2位）

ユイの位置ごとに分けて考えます。

**ケース3-1: ユイが2位の場合**
- 残りの枠は1位と3位。人物はハルトとミズキ。
- 条件1（ハルト < ミズキ）より、**1位はハルト、3位はミズキ**。
- しかし条件4（ミズキ $\neq$ 3位）に**矛盾**します。
- よってユイは2位ではありません。

**ケース3-2: ユイが3位の場合**
- 残りの枠は1位と2位。人物はハルトとミズキ。
- 条件1（ハルト < ミズキ）より、**1位はハルト、2位はミズキ**。
- 他の条件と矛盾がないか確認します。
  - ハルトは1位。条件6（ハルト $\neq$ 2位）→ OK。
  - ミズキは2位。条件4（ミズキ $\neq$ 3位）→ OK。
  - ミズキは2位。条件7（ミズキ $\neq$ 5位）→ OK。
  - ハルト(1) < ミズキ(2) → OK。
  - ユイ(3) < アオイ(4) → OK。
  - ユイは1位でも5位でもない → OK（3位）。
  - ソウタはアオイ(4)のすぐ後(5) → OK。

すべての条件を満たす配置は以下の通りです。
1. ハルト
2. ミズキ
3. **ユイ**
4. アオイ
5. ソウタ

したがって、3位に到着したのはユイです。

答え: ユイ
