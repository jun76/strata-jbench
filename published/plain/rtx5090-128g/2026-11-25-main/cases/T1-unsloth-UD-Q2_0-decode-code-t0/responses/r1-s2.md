以下に、要件を満たす Python コマンドラインツールと、それに対応する pytest 単体テストを提供します。

### 1. メインスクリプト: `word_counter.py`

```python
#!/usr/bin/env python3
"""
word_counter.py

テキストファイルを読み込み、単語の出現頻度を計算し、
上位 N 件の単語とその頻度を表形式で表示するコマンドラインツール。

Usage:
    python word_counter.py <input_file> [-n TOP_N] [--case-sensitive]
"""

import argparse
import sys
from collections import Counter
from typing import List, Tuple, Dict


def read_file_content(filepath: str) -> str:
    """
    指定されたファイルパスからテキストを読み込む。

    Args:
        filepath (str): 読み込むテキストファイルのパス。

    Returns:
        str: ファイルの内容。

    Raises:
        FileNotFoundError: ファイルが存在しない場合。
        IOError: ファイルの読み込み中にエラーが発生した場合。
    """
    try:
        with open(filepath, 'r', encoding='utf-8') as f:
            return f.read()
    except FileNotFoundError:
        raise FileNotFoundError(f"ファイルが見つかりません: {filepath}")
    except IOError as e:
        raise IOError(f"ファイルの読み込み中にエラーが発生しました: {e}")


def tokenize_text(text: str, case_sensitive: bool = False) -> List[str]:
    """
    テキストを単語に分割する。
    句読点や特殊文字を除去し、必要に応じて小文字化する。

    Args:
        text (str): 分割対象のテキスト。
        case_sensitive (bool): 大文字小文字を区別するかどうか。デフォルトは False。

    Returns:
        List[str]: 単語のリスト。
    """
    # 句読点や特殊文字をスペースに置き換えて分割
    # 基本的な句読点と空白類を除去
    import re
    # 単語として扱うのは、アルファベット、数字、ハイフン、アポストロフィなど
    # ここでは簡易的に、非単語文字をスペースに変換して分割
    cleaned_text = re.sub(r'[^\w\s]', ' ', text)
    
    if not case_sensitive:
        cleaned_text = cleaned_text
