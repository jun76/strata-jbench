5人の到着順（1位〜5位）を論理的に推論します。

まず、与えられた条件を整理します。
1. ハルト < ミズキ （ハルトが先）
2. ユイ $\neq$ 1位, ユイ $\neq$ 5位 （ユイは2,3,4位のいずれか）
3. アオイ + 1 = ソウタ （アオイの直後がソウタ）
4. ミズキ $\neq$ 3位
5. ユイ < アオイ （ユイが先）
6. ハルト $\neq$ 2位
7. ミズキ $\neq$ 5位 （ミズキは最後ではない）

**ステップ1: アオイとソウタの位置を特定する**
「アオイのすぐ後にソウタが着いた」ため、二人は $(1,2), (2,3), (3,4), (4,5)$ のいずれかの連続する順位になります。

**ステップ2: ユイ、ハルト、ミズキの位置を考える**
ユイは1位でも5位でもなく、かつ「ユイ < アオイ」です。
ハルトは「ハルト < ミズキ」かつ「ハルト $\neq$ 2位」です。
ミズキは「ミズキ $\neq$ 3位」かつ「ミズキ $\neq$ 5位」です。

これらを組み合わせて、アオイとソウタのペアの位置によって場合分けをしていきます。

---

**ケースA: アオイが1位、ソウタが2位の場合**
- 残り順位: 3, 4, 5位
- 残り人物: ハルト、ミズキ、ユイ
- 「ユイ < アオイ」の条件より、ユイは1位のアオイより先にならなければなりません。しかし、1位はアオイなので、ユイは1位より前に着けません（順位は1が最先着）。つまり、アオイが1位の場合、「ユイがアオイより前」という条件を満たす人がいません。
- よって、**アオイは1位ではありません**。

**ケースB: アオイが2位、ソウタが3位の場合**
- 残り順位: 1, 4, 5位
- 残り人物: ハルト、ミズキ、ユイ
- 「ユイ < アオイ(2位)」より、ユイは1位でなければなりません。
  - ユイ = 1位
- 残り順位: 4, 5位
- 残り人物: ハルト、ミズキ
- 「ハルト < ミズキ」かつ「ミズキ $\neq$ 5位」です。
  - ミズキが5位にはなれないので、ミズキは4位になります。
  - するとハルトは5位になります。
  - しかし、「ハルト < ミズキ」である必要がありますが、この場合 $5 < 4$ は偽です。矛盾します。
  - また、ハルトが2位でない条件は満たしますが、ハルトが5位、ミズキが4位だとハルトの方が遅くなります。
- よって、**アオイは2位ではありません**。

**ケースC: アオイが3位、ソウタが4位の場合**
- 残り順位: 1, 2, 5位
- 残り人物: ハルト、ミズキ、ユイ
- 「ユイ < アオイ(3位)」より、ユイは1位か2位です。
- 「ユイ $\neq$ 5位, ユイ $\neq$ 1位」という条件と矛盾しますか？
  - 条件2: 「ユイは1位でも5位でもない」
  - したがって、ユイは1位になれません。
  - よってユイは2位しか選択肢がありません。
  - ユイ = 2位
- 残り順位: 1, 5位
- 残り人物: ハルト、ミズキ
- 「ハルト < ミズキ」です。
- ミズキは1位か5位です。
  - もしミズキが1位なら、ハルトは5位。$5 < 1$ は偽。矛盾。
  - もしミズキが5位なら、ハルトは1位。$1 < 5$ は真。
  - しかし、「ミズキは最後(5位)ではない」という条件があります。
  - よって、ミズキは5位になれません。
- したがって、このケースも成り立ちません。
- よって、**アオイは3位ではありません**。

**ケースD: アオイが4位、ソウタが5位の場合**
- 残り順位: 1, 2, 3位
- 残り人物: ハルト、ミズキ、ユイ
- 「ユイ < アオイ(4位)」より、ユイは1, 2, 3位のいずれか。これはOK。
- 「ユイ $\neq$ 1位, ユイ $\neq$ 5位」より、ユイは2位または3位です。
- 「ハルト < ミズキ」です。
- 「ミズキ $\neq$ 3位, ミズキ $\neq$ 5位」です。
  - 残り順位は1, 2, 3位なので、ミズキは1位または2位です（3位不可）。
- 「ハルト $\neq$ 2位」です。

ここで、ユイ、ハルト、ミズキの配置を考えます。

**サブケース D-1: ユイが2位の場合**
- 残り順位: 1, 3位
- 残り人物: ハルト、ミズキ
- ミズキは1位か3位ですが、「ミズキ $\neq$ 3位」なので、ミズキは1位。
  - ミズキ = 1位
- するとハルトは3位。
  - ハルト = 3位
- 条件チェック:
  - ハルト(3) < ミズキ(1)? → $3 < 1$ は偽。矛盾。
- よって、ユイは2位ではありません。

**サブケース D-2: ユイが3位の場合**
- 残り順位: 1, 2位
- 残り人物: ハルト、ミズキ
- ミズキは1位または2位（3位不可、5位不可）。
- ハルトは1位または2位（2位不可という条件あり）。
  - ハルトは2位になれないので、ハルトは1位。
    - ハルト = 1位
  - するとミズキは2位。
    - ミズキ = 2位
- 条件チェック:
  - ハルト(1) < ミズキ(2)? → $1 < 2$ は真。OK。
  - ミズキ(2) $\neq$ 3位? → 真。OK。
  - ハルト(1) $\neq$ 2位? → 真。OK。
  - ユイ(3) $\neq$ 1位,5位? → 真。OK。
  - ユイ(3) < アオイ(4)? → 真。OK。
  - アオイ(4) のすぐ後 ソウタ(5)? → 真。OK。
  - ミズキ(2) $\neq$ 5位? → 真。OK。

この配置がすべての条件を満たします。

**最終的な順序:**
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

確認:
- ハルト(1) < ミズキ(2) → OK
- ユイ(3) は1位でも5位でもない → OK
- ソウタ(5) はアオイ(4) のすぐ後 → OK
- ミズキ(2) は3位ではない → OK
- アオイ(4) はユイ(3) より後 → OK
- ハルト(1) は2位ではない → OK
- ミズキ(2) は最後(5位)ではない → OK

したがって、3位に到着したのはユイです。

答え: ユイ
