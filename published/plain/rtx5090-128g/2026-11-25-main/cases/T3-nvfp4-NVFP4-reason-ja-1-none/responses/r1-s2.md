与えられた条件を整理して、5人の到着順（1位〜5位）を特定します。

人物：アオイ、ハルト、ミズキ、ソウタ、ユイ

**条件の整理:**
1. ハルト < ミズキ （ハルトがミズキより前）
2. ユイ $\neq$ 1位, ユイ $\neq$ 5位
3. ソウタ = アオイ + 1 （ソウタはアオイの直後）
   *つまり、アオイ・ソウタのペアは (1,2), (2,3), (3,4), (4,5) のいずれか*
4. ミズキ $\neq$ 3位
5. ユイ < アオイ （ユイがアオイより前）
6. ハルト $\neq$ 2位
7. ミズキ $\neq$ 5位

**推理プロセス:**

**ステップ1: アオイとソウタの位置を決める**
条件3より、アオイとソウタは連続した順で並んでいます。
また、条件5より「ユイ < アオイ」です。
アオイが1位になることはできません（ユイがアオイより前にいる必要があるため、最低でも2位以降）。

アオイ・ソウタのペアの可能性を確認します：
*   **ケースA: アオイ=1位**
    *   不可能（ユイが1位より前にいる必要があるため）。
*   **ケースB: アオイ=2位, ソウタ=3位**
    *   ユイはアオイ（2位）より前なので、ユイ=1位。
    *   しかし条件2で「ユイは1位ではない」とあるため、**不成立**。
*   **ケースC: アオイ=3位, ソウタ=4位**
    *   ユイはアオイ（3位）より前なので、ユイ=1位または2位。
    *   条件2でユイは1位ではないので、**ユイ=2位**。
    *   残りのポジションは1位と5位。残りの人はハルトとミズキ。
    *   条件1「ハルト < ミズキ」より、ハルト=1位、ミズキ=5位となる。
    *   しかし条件7「ミズキは最後（5位）ではない」とあるため、**不成立**。
*   **ケースD: アオイ=4位, ソウタ=5位**
    *   ユイはアオイ（4位）より前なので、ユイ=1位、2位、または3位。
    *   条件2でユイは1位でも5位でもないため、ユイ=2位または3位。
    *   残りのポジションは1位、2位、3位（のうちユイが入る以外）と、残りの2枠。
    *   アオイ=4, ソウタ=5なので、1,2,3位にハルト、ミズキ、ユイが入る。
    *   条件1「ハルト < ミズキ」。
    *   条件6「ハルトは2位ではない」。
    *   条件4「ミズキは3位ではない」。
    *   条件7「ミズキは5位ではない」（既にソウタ=5なので満たされる）。
    
    ユイの位置を2位と3位で考えます。
    
    *   **サブケースD-1: ユイ=2位**
        *   残りの1位と3位にハルトとミズキが入る。
        *   ハルト < ミズキ なので、ハルト=1位、ミズキ=3位。
        *   しかし条件4「ミズキは3位ではない」に違反する。**不成立**。
        
    *   **サブケースD-2: ユイ=3位**
        *   残りの1位と2位にハルトとミズキが入る。
        *   ハルト < ミズキ なので、ハルト=1位、ミズキ=2位。
        *   条件6「ハルトは2位ではない」→ ハルト=1位なのでOK。
        *   条件4「ミズキは3位ではない」→ ミズキ=2位なのでOK。
        *   条件1「ハルト(1) < ミズキ(2)」→ OK。
        *   条件5「ユイ(3) < アオイ(4)」→ OK。
        *   条件2「ユイは1位でも5位でもない」→ ユイ=3位なのでOK。
        *   条件7「ミズキは最後ではない」→ ミズキ=2位なのでOK。
        
        このケースがすべての条件を満たします。

**結果の順位:**
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

**検証:**
- ハルト(1)はミズキ(2)より前 → OK
- ユイ(3)は1位でも5位でもない → OK
- ソウタ(5)はアオイ(4)のすぐ後 → OK
- ミズキ(2)は3位ではない → OK
- アオイ(4)はユイ(3)より後 → OK
- ハルト(1)は2位ではない → OK
- ミズキ(2)は最後ではない → OK

したがって、3位に到着したのはユイです。

答え: ユイ
