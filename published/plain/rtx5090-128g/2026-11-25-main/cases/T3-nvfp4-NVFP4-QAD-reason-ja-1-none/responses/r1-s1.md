まず、与えられた条件を整理して、5人の到着順（1位～5位）を論理的に決定します。

**人物：** アオイ、ハルト、ミズキ、ソウタ、ユイ

**条件：**
1. ハルト < ミズキ （ハルトはミズキより前に着いた）
2. ユイ ≠ 1位 かつ ユイ ≠ 5位
3. ソウタ = アオイ + 1 （ソウタはアオイのすぐ後に着いた）
4. ミズキ ≠ 3位
5. ユイ < アオイ （アオイはユイより後に着いた）
6. ハルト ≠ 2位
7. ミズキ ≠ 5位

**ステップ1: ハルトとミズキの位置の候補を絞り込む**

条件1より、ハルトはミズキより前にいます。
条件7より、ミズキは5位ではありません。
条件4より、ミズキは3位ではありません。
したがって、ミズキになりうる順位は、2位、4位です。

*   **ケースA: ミズキが2位の場合**
    *   ハルトはミズキより前なので、ハルトは1位になります。
    *   このとき、残りの順位は3位、4位、5位で、残りの人物はアオイ、ソウタ、ユイです。
    *   条件3より、ソウタはアオイのすぐ後なので、「アオイ、ソウタ」のブロックは連続した順位に入らなければなりません。
    *   残りの順位は3, 4, 5なので、アオイとソウタが入る可能な位置は「3位と4位」または「4位と5位」です。
    *   条件5より、ユイはアオイより前に着きます。
        *   もしアオイが3位、ソウタが4位の場合、残りのユイは5位になります。しかし条件2により、ユイは5位ではいけないので、この配置は不可能です。
        *   もしアオイが4位、ソウタが5位の場合、残りのユイは3位になります。
            *   この配置を確認します：1位ハルト、2位ミズキ、3位ユイ、4位アオイ、5位ソウタ。
            *   条件チェック：
                *   ハルト(1) < ミズキ(2) → OK
                *   ユイ(3) ≠ 1, 5 → OK
                *   ソウタ(5) = アオイ(4) + 1 → OK
                *   ミズキ(2) ≠ 3 → OK
                *   ユイ(3) < アオイ(4) → OK
                *   ハルト(1) ≠ 2 → OK
                *   ミズキ(2) ≠ 5 → OK
            *   このケースは条件をすべて満たします。
            *   この場合、3位は**ユイ**です。

*   **ケースB: ミズキが4位の場合**
    *   ハルトはミズキより前なので、ハルトは1位、2位、3位のいずれかです。
    *   条件6より、ハルトは2位ではありません。
    *   したがって、ハルトは1位または3位です。

    *   **ケースB-1: ハルトが1位の場合**
        *   残り順位: 2, 3, 5。残人物: アオイ、ソウタ、ユイ。
        *   「アオイ、ソウタ」のブロックは連続していなければなりません。
        *   残り順位2, 3, 5の中で連続しているのは2位と3位だけです。
        *   よって、アオイは2位、ソウタは3位です。
        *   残りのユイは5位になります。
        *   しかし、条件2よりユイは5位ではいけないので、この配置は不可能です。

    *   **ケースB-2: ハルトが3位の場合**
        *   残り順位: 1, 2, 5。残人物: アオイ、ソウタ、ユイ。
        *   「アオイ、ソウタ」のブロックは連続していなければなりません。
        *   残り順位1, 2, 5の中で連続しているのは1位と2位だけです。
        *   よって、アオイは1位、ソウタは2位です。
        *   残りのユイは5位になります。
        *   しかし、条件2よりユイは5位ではいけないので、この配置は不可能です。
        *   また、条件5「ユイ < アオイ」も、ユイ(5) < アオイ(1)は偽なので矛盾します。

**結論**
ケースAのみが有効であり、その場合の到着順は以下の通りです。
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

よって、3位に到着したのはユイです。

答え: ユイ
