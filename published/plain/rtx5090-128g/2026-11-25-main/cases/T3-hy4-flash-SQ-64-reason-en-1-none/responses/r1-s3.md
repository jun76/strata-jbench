- **Prize in B**:  
  - A says “The prize is in this box.” → false

  - C says “The prize is not in box A.” → true  
  → Exactly one true label. ✅

- **Prize in C**:  
  - A says “The prize is in this box.” → false  
  - B says “The prize is not in this box.” → true (since prize is in C, not B)  
  - C says “The prize is not in box A.” → true  
  → Two true labels. ❌
