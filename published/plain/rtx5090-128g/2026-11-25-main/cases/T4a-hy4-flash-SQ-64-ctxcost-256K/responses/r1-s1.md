以下、ご提示のデータ（record000001〜record000212）の構造、IDから該当レコードを探す手順、そして件数が増えた場合に高速に検索するための工夫を、できるだけ詳しく説明します。

---

## 1. レコードの構造の詳細

### 1.1 全体形式

各ラインは以下の形式です：

```
recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.
```

- `record` という固定_prefix
- 続く **6桁の零埋め番号**（例：`000001`, `000212`）
- コロン `:` と半角スペース 1つ
- 本文：8つのギリシャ文字名が半角スペースで区切られた列挙
- 末尾にピリオド `.`

### 1.2 各部分の意味

| 要素 | 内容 | 説明 |
|---|---|---|
| prefix | `record` | レコード種別を示す固定文字列 |
| ID | `000001`〜`000212` | 6桁ゼロ埋めの連番。数値としても文字列としても扱える |
| 区切り | `: ` | IDと本文を分離 |
| 本文 | `alpha beta gamma delta epsilon zeta eta theta` | 8トークンの固定並び |
| 終端 | `.` | 各行の終わり |

### 1.3 本文のトークン構造

本文は常に同じ 8 語です（順序も固定）：

| 位置（1-based） | トークン |
|---|---|
| 1 | alpha |
| 2 | beta |
| 3 | gamma |
| 4 | delta |
| 5 | epsilon |
| 6 | zeta |
| 7 | eta |
| 8 | theta |

つまり、**本文は ID に依存しない一定のテンプレート**です。  
言い換えれば、ID だけが各レコードの「可変情報」であり、他はすべて同一です。
