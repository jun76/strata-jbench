## 1. レコードの構造の説明

### 1.1 全体形式

各レコードは次のような **1行のテキスト** です：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

この行は **3つの部分** に分解できます。

| 部分 | 内容 | 役割 |
|---|---|---|
| ① ID 部 | `record000001` | レコードを一意に識別するラベル |
| ② 区切り | `:`（コロン） | ID と本文を分離するデリミタ |
| ③ 本文部 | `alpha beta gamma delta epsilon zeta eta theta.` | 8つのトークン + 末尾ピリオド |

---

### 1.2 ID 部の詳細

- 接頭辞：`record`
- 続く **6桁のゼロ埋め整数**：`000001` ～ `000212`
- 形式：`record` + `%06d`

例：

| ID | 意味 |
|---|---|
| `record000001` | 1番目のレコード |
| `record000100` | 100番目 |
| `record000212` | 212番目（最後） |

特徴：

- **固定長（6桁）** なので、字典順（文字列順）＝数値順になります。
  - `record000009` < `record000010` < `record000100` < `record000212`
- ゼロ埋めにより、ソートや比較が文字列のまま安全に行える。
- 末尾の番号が **連番で欠けなし**（1～212）。

---

### 1.3 区切り部

- `: `（コロン + 半角スペース）
- コロンの直後に **1つのスペース** がある点に注意
- この区切りにより、ID と本文を確実に分離できる

---
