# レコードデータと検索方法詳細説明

## 1.レコードデータ構造

### 1-1.レコードデータ構造

```
recordXXXXXXXX: alpha beta gamma delta epsilon zeta eta theta.
```

| 項目 | 説明 | 例 |
|------|------|------|
| `record` | 固定 prefix | `record` |
| `XXXXXXXX` | 8-digit zero-padded ID number | `00000001`, `00000100` |
| `:` | IDと内容 separator | `:` |
| `alpha beta gamma delta epsilon zeta eta theta` | 固定 content (8 Greek letter words) | Always the same |
| `.` | End-of-content period | `.` |

### 1-2.レコード ID range
```
record00000001 → record00000212
```
**Total: 212 records** (All records have identical content)

## 2.IDからレコードの検索方法

### 2-1.Naive Linear Search (Brute Force)

```python
def linear_search(records, target_id):
    for record in records:
        if record.startswith(f"record{target_id:08d}"):
            return record
    return None
```

**Time Complexity: O(N)**
- Worst Case: 212 comparisons (searching for record00000212)
- Best Case: 1 comparison (searching for record00000001)
- Average Case: ~106 comparisons

### 2-2.Binary Search (Sorted Array)

Since IDs are **sorted in ascending order**, we can use binary search.

```python
import bisect

def binary_search(records, target_id):
    search_key = f"record{target_id:08d}"
    idx = bisect.bisect_left(records, search_key)
    if idx < len(records) and records[idx].startswith(search_key):
        return records[idx]
    return None
```
