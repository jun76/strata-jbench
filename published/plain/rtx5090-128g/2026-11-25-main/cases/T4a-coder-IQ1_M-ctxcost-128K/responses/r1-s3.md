## 🔍 2. IDからレコードの查找 Procedure (Basic Approach)

### Naive Linear Search (O(n))
If records are stored in an array/list:
1. Start from `record000001`
2. Compare each record's ID with target ID
3. Return when match found

**Time Complexity:** O(n) — worst case scans all records.  
**Example:** Searching for `record000212` requires checking all 212 records.

### Binary Search (O(log n))
If records are **sorted by ID** (which they are here):
1. Define `low = 0`, `high = n-1`
2. Compute `mid = (low + high) / 2`
3. Compare `record[mid].ID` with target
   - If equal → found
