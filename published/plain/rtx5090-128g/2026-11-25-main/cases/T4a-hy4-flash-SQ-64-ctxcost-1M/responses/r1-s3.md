## 1. レコードの構造の説明

### 1.1 全体形式

各レコードは次のような固定形式です：

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
```

つまり、1行は以下の3つの部分に分解できます。

| 部分 | 内容 | 意味 |
|---|---|---|
| ① ID部 | `record000001` | レコードの識別子（6桁のゼロ埋め番号） |
| ② 区切り | `:` + 半角スペース | IDと本文の区切り |
| ③ 本文部 | `alpha beta gamma delta epsilon zeta eta theta.` | 8つの単語 + 末尾ピリオド |

### 1.2 ID部の詳細

- 接頭辞：`record`
- 番号：6桁の十进制数（000001〜000212）
- ゼロ埋め（zero-padding）されている
  - 例：`000001`, `000009`, `000100`, `000212`
- そのため、**文字列としてソートしても数値順と一致する**
  - `"record000009" < "record000010"` は辞書順でも正しい
  - `"record000100" < "record000099"` にならない（ゼロ埋めのおかげ）

### 1.3 本文部の詳細

本文は常に同じトークン列です：

```
alpha beta gamma delta epsilon zeta eta theta.
```

- トークン数：8語
- 区切り：半角スペース（1文字）
- 末尾：`.`（ピリオド）
- 語順は固定（alpha → beta → gamma → delta → epsilon → zeta → eta → theta）
- 各レコードの本文は**完全に同一**（不変）
