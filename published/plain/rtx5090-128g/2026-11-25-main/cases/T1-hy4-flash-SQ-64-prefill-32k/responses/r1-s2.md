The dataset is a sequential list of records with IDs from `record000001` through `record001721`.

Structure of each record:

- ID prefix: `record`
- ID number: 6 digits, zero-padded
- Separator: `: ` after the ID
- Content: the same fixed token sequence in every record  
  `alpha beta gamma delta epsilon zeta eta theta`

So a record has the form:

`recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta`

Examples:

- `record000001: alpha beta gamma delta epsilon zeta eta theta`
- `record000100: alpha beta
