The dataset is a numbered list of records. Each record has:

- **ID format:** `record` followed by a 6-digit zero-padded number  
  - Example: `record000001`, `record001721`
- **Content:** the same fixed text in every record:  
  `alpha beta gamma delta epsilon zeta eta theta`
- **Range:** records run consecutively from `record000001` through `record001721`, with no gaps.
- **Total:** 1,721 records.
