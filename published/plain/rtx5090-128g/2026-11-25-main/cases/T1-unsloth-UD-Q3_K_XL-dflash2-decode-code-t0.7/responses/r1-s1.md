## 概要

`wordfreq` は、テキストファイルを読み込んで単語出現頻度を集計し、上位 N 件を表形式で表示する CLI ツールです。

- **argparse** で CLI 引数を解析（`-n/--top`, `--min-len`, `--case-sensitive`, `--json` など）
- **型ヒント**・**docstring** を全公開関数に付与
- **pytest** で単体テスト（CLI 引数解析、集計ロジック、ソート安定性、境界値など）

_WORD_RE = re.compile(r"\w+", re.UNICODE)


def tokenize(text: str, case_sensitive: bool = False) -> list[str]:
    """Split text into lowercase (or original-case) word tokens.

    Words are defined as sequences of Unicode word characters (letters, digits,
    underscores). Punctuation, whitespace, and other symbols are treated as
    separators.

    Args:
        text: The input text to tokenize.
        case_sensitive: If False (default), tokens are lowercased.

    Returns:
        A list of word tokens in order of appearance.
    """
    tokens = _WORD_RE.findall(text)
    if not case_sensitive:
        tokens = [t.lower() for t in tokens]
    return tokens
