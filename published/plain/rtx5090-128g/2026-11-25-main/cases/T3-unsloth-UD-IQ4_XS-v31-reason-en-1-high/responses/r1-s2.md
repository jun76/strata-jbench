Let the prize be in each possible box and count how many labels are true.

- If the prize is in **A**:  
  A’s label is true, B’s label is true, C’s label is false → 2 true labels. Not allowed.

- If the prize is in **B**:  
  A’s label is false, B’s label is false, C’s label is true → 1 true label. Allowed.

- If the prize is in **C**:  
  A’s label is false, B’s label is true, C’s label is true → 2 true labels. Not allowed.

So the prize is in box B.

Answer: B
