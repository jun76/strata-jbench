The records form a simple, uniform list:

- There are **212 records**, numbered from `record000001` through `record000212`.
- Each record ID uses the format `record` followed by a **6-digit zero-padded number**.
- Every record has the exact same content:  
  `alpha beta gamma delta epsilon zeta eta theta.`
- Each line follows the structure:

```text
recordID: alpha beta gamma delta epsilon zeta eta theta.
```

For example:

```text
record000001: alpha beta gamma delta epsilon zeta eta theta.
```
