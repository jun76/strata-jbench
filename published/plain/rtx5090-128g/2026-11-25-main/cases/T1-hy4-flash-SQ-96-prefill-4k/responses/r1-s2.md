The records form a simple, uniform list:

- Each line is one record.
- Each record has a fixed ID format: `record` followed by a 6-digit zero-padded number, e.g. `record000001`.
- The IDs run consecutively from `record000001` through `record000212`.
- Every record has the same content after the ID:

```text
alpha beta gamma delta epsilon zeta eta theta.
```

So the structure is:

```text
recordID: field1 field2 field3 field4 field5 field6 field7 field8.
```
