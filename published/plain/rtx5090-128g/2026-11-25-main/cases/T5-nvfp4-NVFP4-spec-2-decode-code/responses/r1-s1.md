# 単語頻度集計ツール

以下に、テキストファイルを読み込んで単語出現頻度を集計し、上位N件を表形式で表示するコマンドラインツールと、対応するpytest単体テストを提供します。

## プロジェクト構成

```
wordfreq/
├── wordfreq.py      # メインモジュール
├── test_wordfreq.py # pytest単体テスト
└── sample.txt       # （任意）サンプル入力ファイル
```

wordfreq.py - テキストファイルの単語出現頻度を集計し、上位N件を表形式で表示するCLIツール。

使い方:
    python wordfreq.py <input_file> [-n TOP_N] [--case-sensitive] [--min-length MIN_LEN]

例:
    python wordfreq.py sample.txt -n 10
    python wordfreq.py sample.txt -n 20 --case-sensitive --min-length 3
"""

from __future__ import annotations

def tokenize_text(
    text: str,
    *,
    case_sensitive: bool = False,
    min_length: int = 1,
) -> List[str]:
    """
    テキストから単語をトークナイズする。

    Args:
        text: 入力テキスト文字列。
        case_sensitive: Trueの場合、大文字・小文字を区別する。Falseの場合、すべて小文字に変換する。
        min_length: 単語の最小長。これより短い単語は除外される。

    Returns:
        トークン化された単語のリスト。
    """
    # 英数字とハイフンを含む語を抽出（日本語などの多言語対応は簡易的に英字のみ）
    # 必要に応じて正規表現を調整可能
    pattern = r"[a-zA-Z0-9'-]+"
    words = re.findall(pattern, text)

    if not case_sensitive:
        words = [w.lower() for w in words]

    words = [w for w in words if len(w) >= min_length]

    return words
