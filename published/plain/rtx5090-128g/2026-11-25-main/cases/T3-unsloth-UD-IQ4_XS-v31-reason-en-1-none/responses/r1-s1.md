To determine which box contains the prize, we analyze the three possible scenarios (Prize in A, B, or C) and check which one results in exactly one true label.

Let the statements be:
- $S_A$: "The prize is in this box" (Prize $\in$ A)
- $S_B$: "The prize is not in this box" (Prize $\notin$ B)
- $S_C$: "The prize is not in box A" (Prize $\notin$ A)

We are given that **exactly one** of these statements is true.

### Case 1: The prize is in Box A
- $S_A$ ("Prize is in A") is **True**.
- $S_B$ ("Prize is not in B") is **True** (since the prize is in A, it is not in B).
- $S_C$ ("Prize is not in A") is **False**.
- **Result**: Two statements are true ($S_A$ and $S_B$). This contradicts the condition that exactly one statement is true.

### Case 2: The prize is in Box B
- $S_A$ ("Prize is in A") is **False** (prize is in B).
- $S_B$ ("Prize is not in B") is **False** (prize is in B).
- $S_C$ ("Prize is not in A") is **True** (prize is in B, so it is not in A).
- **Result**: Exactly one statement is true ($S_C$). This satisfies the condition.

### Case 3: The prize is in Box C
- $S_A$ ("Prize is in A") is **False** (prize is in C).
- $S_B$ ("Prize is not in B") is **True** (prize is in C, so it is not in B).
- $S_C$ ("Prize is not in A") is **True** (prize is in C, so it is not in A).
- **Result**: Two statements are true ($S_B$ and $S_C$). This contradicts the condition that exactly one statement is true.

### Conclusion
Only Case 2 satisfies the condition that exactly one label is true. Therefore, the prize is in Box B.

Answer: B
