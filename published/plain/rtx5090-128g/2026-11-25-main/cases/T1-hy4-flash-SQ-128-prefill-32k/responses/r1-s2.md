The records form a simple, highly uniform numbered list.

## Structure

Each line has this format:

```text
record<ID>: <payload>
```

Where:

- `record` is a fixed prefix.
- `<ID>` is a zero-padded 6-digit decimal number.
- `:` separates the identifier from the record content.
- `<payload>` is always the same text:

```text
alpha beta gamma delta epsilon zeta eta theta.
```

Examples:

```text
record000001: alpha beta gamma delta epsilon zeta eta theta.
record000500: alpha beta gamma delta epsilon zeta eta theta.
