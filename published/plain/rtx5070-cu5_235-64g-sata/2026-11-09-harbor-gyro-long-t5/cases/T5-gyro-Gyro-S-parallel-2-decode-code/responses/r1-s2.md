word_count.py - テキストファイルの単語出現頻度を集計し、上位 N 件を表形式で表示する CLI ツール。

    python word_count.py input.txt -n 10

オプション:

    -c, --case-sensitive: 大文字小文字を区別するか (デフォルト: False)

def normalize_word(word: str, case_sensitive: bool) -> str:
    """単語を正規化します。case_sensitive が False の場合は小文字化します。"""
    if not case_sensitive:
        return word.lower()
    return word


def count_words(text: str, case_sensitive: bool = False) -> Counter[str]:
    """テキストから単語の出現頻度をカウントします。

    Args:
        text: 入力テキスト
        case_sensitive: True の場合は大文字小文字を区別します。False の場合は小文字化します。

    Returns:
        単語をキーとする Counter オブジェクト
    """
    # 単語分割: 空白区切りで分割し、句読点などを除去
    words = []
    for raw_word in text.split():
        # 句読点や記号を除去
        cleaned = raw_word.strip(".,!?;:\"'()-")
        if cleaned:
            words.append(normalize_word(cleaned, case_sensitive))
    return Counter(words)
