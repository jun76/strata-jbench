以下は、テキストファイルから単語出現頻度を集計し、上位 N 件を表形式で表示するコマンドラインツールです。

## `word_freq.py`

```python
"""
word_freq.py - テキストファイルから単語出現頻度を集計し、上位N件を表形式で表示するツール。

Usage:
    python word_freq.py <file> [--top N] [--case-insensitive] [--sort]

Example:
    python word_freq.py input.txt --top 10
"""

import argparse
import sys
import re
from collections import Counter
from typing import List, Tuple, Optional


def tokenize(text: str) -> List[str]:
    """
    テキストを単語に分割する。
    
    Args:
        text: 入力テキスト
        
    Returns:
        単語のリスト（小文字化された）
    """
    # 非英数字を区切りとして単語を抽出
    words = re.findall(r'[a-z0-9]+', text.lower())
    return words


def count_words(text: str) -> Counter:
    """
    単語の出現頻度をカウントする。
    
    Args:
        text: 入力テキスト
        
    Returns:
        Counter: 単語 -> 出現回数 のマップ
    """
    words = tokenize(text)
    return Counter(words)


def format_table(entries: List[Tuple[str, int]], top_n: int) -> str:
    """
    表形式で結果をフォーマットする。
    
    Args:
        entries: (word, count) のリスト（降順ソート済み）
        top_n: 表示する件数
        
    Returns:
        表形式の文字列
    """
    if not entries:
        return "No words found."
    
    # ヘッダー行
    header = f"{'Word':<20} {'Count':>10}"
    separator = f"{'-'*20} {'-'*10}"
    
    lines = [header, separator]
    
    for word, count in entries[:top_n]:
        lines.append(f"{word:<20} {count:>10}")
    
    return "\n".join(lines)
