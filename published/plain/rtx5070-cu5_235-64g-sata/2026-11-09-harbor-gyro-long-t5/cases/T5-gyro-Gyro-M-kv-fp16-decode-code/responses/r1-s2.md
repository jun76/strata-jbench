このツールは `argparse` を使用して引数を受け取り、ファイルを読み込み、単語の出現頻度をカウントし、上位 N 件をテーブル形式で出力します。

#!/usr/bin/env python3
"""
Word frequency counter CLI tool.

Reads a text file, counts word occurrences, and displays the top N words
in a tabular format.

Usage:
    python word_counter.py <file_path> [-n TOP_N]
"""

    """Parse command-line arguments.

    Returns:
        argparse.Namespace: Parsed arguments containing 'file' and 'top_n'.

    Raises:
        SystemExit: If arguments are invalid or file does not exist.
    """
    parser = argparse.ArgumentParser(
        description="Count word frequencies in a text file and display top N words."
    )
    parser.add_argument(
        "file",
        type=str,
        help="Path to the text file to analyze."
    )
    parser.add_argument(
        "-n",
        "--top-n",
        type=int,
        default=10,
        help="Number of top words to display (default: 10)."
    )
    return parser.parse_args()

        FileNotFoundError: If the file does not exist.
        IOError: If reading fails.
    """
    with open(file_path, "r", encoding="utf-8") as f:
        return f.read()
