## 📋 レコードの構造

### 1. 基本構造

```
recordNNNNNN: alpha beta gamma delta epsilon zeta eta theta.
```

|  component | description |
|------------|-------------|
| `record` | 固定prefix (prefix) |
| `NNNNNN` | 6-digit zero-padded ID number (000001–000212) |
| `:` | 固定separator |
| `alpha beta gamma delta epsilon zeta eta theta` | 固定8-word payload |

### 2. 字段 Breakdown

```
record000001: alpha beta gamma delta epsilon zeta eta theta.
├── ID field: record000001
├── separator: :
└── payload: alpha beta gamma delta epsilon zeta eta theta.
```

### 3. 固定Length Characteristics

Each record follows a **fixed-length format** (except for the ID number itself, which is zero-padded to 6 digits, making the ID field always 12 characters: `record` + 6 digits).

| Field | Length | Format |
|-------|--------|--------|
| `record` | 6 chars | Fixed string |
| ID number | 6 chars | Zero-padded decimal (000001–000212) |
| `:` | 1 char | Fixed separator |
| Payload | 47 chars | Fixed string `alpha beta gamma delta epsilon zeta eta theta.` |
| **Total per line** | **61 chars** | (excluding newline) |

## 🔍 IDからレコードの查找 Procedure

### 1. 基本查找 (Linear Search)

```python
def find_by_id(records, target_id):
    """
    target_id: e.g., "000001" or 1 (integer)
    """
    # Convert to target ID string format
    id_str = f"record{target_id:06d}"
    
    for record in records:
        if record.startswith(id_str + ":"):
            return record
    return None
