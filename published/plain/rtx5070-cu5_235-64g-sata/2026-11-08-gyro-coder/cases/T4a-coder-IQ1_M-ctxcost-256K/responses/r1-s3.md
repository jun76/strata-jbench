# 1. レコードの構成 (Structure)

提供のデータはテキストデータ。レコードの構成は以下:

```
record{ID}: {field1} {field2} {field3} {field4} {field5} {field6} {field7} {field8}.
```

*   **ID**: `record` + 10-digit number (e.g., `0000000001` to `0000000212`).
*   **Fields**: 8個の固定のGreek letter (alpha, beta, gamma, delta, epsilon, zeta, eta, theta).
*   **Delimiter**: Space (` `) and period (`.`).

Example:
`record000100: alpha beta gamma delta epsilon zeta eta theta.`

---

# 2. IDからレコードの検索の基本手順 (Naive Search)

If you want to find a specific ID (e.g., `record000100`) in a simple way, you can use Linear Search or Binary Search.

## A. Linear Search (Slowest)
Search from `record000001` to `record000212` until you find the target ID.

```python
# Pseudocode
target_id = "record000100"
for record in all_records:
    if record.id == target_id:
        return record
```

*   **Time Complexity**: O(N)
*   **Problem**: When N increases, search time increases linearly. For large data, it is very slow.
