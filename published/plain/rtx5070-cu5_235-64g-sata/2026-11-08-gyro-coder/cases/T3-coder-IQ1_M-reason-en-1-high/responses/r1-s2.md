Let the prize be in A, B, or C and test the number of true labels.

- If the prize is in A:
  - A is true
  - B is true
  - C is false
  - This gives 2 true labels, not allowed.

- If the prize is in B:
  - A is false
  - B is false
  - C is true
  - This gives exactly 1 true label, allowed.

- If the prize is in C:
  - A is false
  - B is true
  - C is true
  - This gives 2 true labels, not allowed.

Therefore, the prize must be in Box B.

Answer: B
