5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の到着順序を論理的に推測して、3位に到着した人を探します。

**1. 条件を整理する**
1. ハルト < ミズキ
2. ユイ ≠ 1位, ユイ ≠ 5位
3. ソウタ = アオイの直後 (アオイの順位 $n$ なら、ソウタの順位は $n+1$)
4. ミズキ ≠ 3位
5. アオイ > ユイ
6. ハルト ≠ 2位
7. ミズキ ≠ 5位 (最後ではない)

**2. ユイの順位を絞り込む**
条件2より、ユイは 2位, 3位, 4位 のどれかです。

**3. アオイとソウタの組み合わせ**
条件3より、アオイとソウタは連続しています。
条件5より、アオイはユイより後（順位が大きい）です。

アオイとソウタの順位ペア $(n, n+1)$ として考えられるのは、1-2, 2-3, 3-4, 4-5 です。
ユイより後であるため、アオイの順位 $n$ はユイの順位より大きい必要があります。

**4. ハルトとミズキの配置**
条件1より、ハルト < ミズキ。
条件6より、ハルト ≠ 2位。
条件4より、ミズキ ≠ 3位。
条件7より、ミズキ ≠ 5位。

ミズキの可能な順位は、3位と5位以外、かつハルトより後です。
ハルトの可能な順位は、2位以外です。

**ケース別検討:**

*   **ユイが2位の場合:**
    *   アオイはユイより後なので、アオイは3, 4, 5位のいずれか。
    *   アオイの直後はソウタなので、アオイは5位不可能（ソウタ6位なし）。
    *   アオイは4位の場合、ソウタは5位。残る順位は1, 3位。ハルトとミズキのペア。
        *   ハルト < ミズキ。残り1, 3位でハルト < ミズキなら、ハルト=1, ミズキ=3。
        *   しかし条件4「ミズキは3位ではない」に違反。
    *   アオイは3位の場合、ソウタは4位。残る順位は1, 5位。ハルトとミズキのペア。
        *   ハルト < ミズキなら、ハルト=1, ミズキ=5。
        *   条件7「ミズキは最後ではない」に違反。
    *   よって、ユイは2位ではない。

*   **ユイが4位の場合:**
    *   アオイはユイより後なので、アオイは5位。ソウタは6位（不存在）。
    *   よって、ユイは4位ではない。

*   **ユイが3位の場合:**
    *   アオイはユイより後なので、アオイは4位 or 5位。
    *   アオイ=5位はソウタ6位で不可。
    *   アオイ=4位の場合、ソウタ=5位。
    *   残る順位は1, 2位。ハルトとミズキ。
    *   ハルト < ミズキなので、ハルト=1, ミズキ=2。
    *   条件確認:
        *   ハルト(1) < ミズキ(2) : OK
        *   ユイ(3) ≠ 1,5 : OK
        *   ソウタ(5)はアオイ(4)の直後 : OK
        *   ミズキ(2) ≠ 3位 : OK
        *   アオイ(4) > ユイ(3) : OK
        *   ハルト(1) ≠ 2位 : OK
        *   ミズキ(2) ≠ 5位 : OK
    *   この配置はすべての条件を満たします。
    *   順位: 1位 ハルト, 2位 ミズキ, 3位 ユイ, 4位 アオイ, 5位 ソウタ。

**結論:**
3位に到着した人は **ユイ** です。
