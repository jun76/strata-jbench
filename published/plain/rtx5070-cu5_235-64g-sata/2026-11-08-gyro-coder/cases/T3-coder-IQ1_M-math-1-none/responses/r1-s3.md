我们要找的是从 1 到 2026 的整数中，那些**不被 divisible by 3 AND不被 divisible by 5**的 numbers.

Let $S$ be the set of integers from 1 to 2026. The size of $S$ is $2026$.
Let $A$ be the set of numbers in $S$ divisible by 3.
Let $B$ be the set of numbers in $S$ divisible by 5.
We want to find the count of numbers that are **not** in $A \cup B$.
According to the principle of inclusion-exclusion, the number of elements in $A \cup B$ is:
$|A \cup B| = |A| + |B| - |A \cap B|$

First, calculate $|A|$ (multiples of 3 up to 2026):
$|A| = \lfloor \frac{2026}{3} \rfloor = 675$
Since $2026 = 3 \times 675 + 1$.

Next, calculate $|B|$ (multiples of 5 up to 2026):
$|B| = \lfloor \frac{2026}{5} \rfloor = 405$
Since $2026 = 5 \times 405 + 1$.

Then, calculate $|A \cap B|$ (multiples of both 3 and 5, which are multiples of $\text{lcm}(3,5)=15$):
$|A \cap B| = \lfloor \frac{2026}{15} \rfloor = 135$
Since $2026 = 15 \times 135 + 1$.

So, the number of integers divisible by 3 or 5 is:
$|A \cup B| = 675 + 405 - 135 = 945$

Finally, the number of integers not divisible by 3 nor 5 is:
$|S| - |A \cup B| = 2026 - 945 = 1081$

Alternatively, we can use Euler's Totient function logic or periodicity modulo 15.
The pattern of numbers not divisible by 3 or 5 repeats every 15 integers.
In each block of 15 integers, there are $\phi(15) = 15 \times (1 - 1/3)(1 - 1/5) = 8$ such numbers.
$2026 = 15 \times 135 + 1$.
Number of full blocks is 135.
Count = $135 \times 8 = 1080$.
Remainder is 1, so we check the range 1 to 1.
The number 1 is not divisible by 3 or 5, so add 1.
Total = $1080 + 1 = 1081$.

The calculation matches.

答え: 1081
