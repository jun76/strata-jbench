**設計の決め手:**
- **開き方**: 地形そのものが主役。マウスで自由に見渡せる"見本市"ではなく、まず**世界そのものを俯瞰できる画面**から始めます。
- **タイポ**: 見出しは `Bungee`（無骨でブロックな文字＝ブロック世界）、本文は `Space Grotesk`、UIは `Space Mono`（HUD＝計器板）。

- **動き**: スキャントーン・スキャンライン・HUDの点滅・ブロックの置換補間・粒子の物理、すべて`prefers-reduced-motion`で停止。

function raycast(){

  const dx=Math.cos(cam.ang+cam.angV)*Math.cos(cam.pitch);

  let mX=dx>0?(vx+1-ex)*ddx:(ex-vx)*ddx;

  let mZ=dz>0?(vz+1-ez)*ddz:(ez-vz)*ddz;
  let face=-1,t=0;

    if(mX<mY&&mX<mZ){vx+=sx;t=mX;mX+=ddx;face=0;}

    if(b>0)return{hit:true,x:vx,y:vy,z:vz,b,face,t};

  return{hit:false};
}

function update(dt){

**実装メモ / 遊び方**

- **操作**: `WASD` 移動、`マウス` 視点、`Space` ジャンプ、`Shift` 走る、`Ctrl` しゃがみ、`左クリック` 破壊、`右クリック` 設置、`1–9`/`ホイール` でブロック選択。
- **エンジン**: 外部ライブラリなしの自作ボクセルエンジン。DDA レイキャストで 1 本ずつ列を描画し、面ノーマル×太陽角度のシェーディング・ブロック境界のダークリング・距離フォグ・夜間の星を再現しています。
- **シード**: 読み込み時に毎回ランダム生成。HUD の SEED 値が世界の特徴（丘・森・砂浜・池）を決めます。
- **反応する世界**: 昼夜サイクルで空のグラデ・ブロックの色・フォグ・HUD が同時に変化し、破壊/設置で粒子が飛び、Web Audio が環境音（昼は鳥・夜は虫・風・破壊音）を合成します。

もし「もっと広い世界」「水に泳ぐ」「クラフト/インベントリ」など追加したい要素があれば、その方針に合わせて拡張します。
