1から2026までの整数のうち、3でも5でも割り切れない数を求める問題です。

**1.  inclusion-exclusion principle (容斥原理) を適用する**
3でも5でも割り切れない数 = 総数 - (3で割り切れる数 + 5で割り切れる数) + (3と5両方に割り切れる数)

**2. 総数**
$N = 2026$

**3. 3で割り切れる数**
$\lfloor \frac{2026}{3} \rfloor = \lfloor 675.33... \rfloor = 675$

**4. 5で割り切れる数**
$\lfloor \frac{2026}{5} \rfloor = \lfloor 405.2 \rfloor = 405$

**5. 3と5両方に割り切れる数 (15で割り切れる数)**
$\lfloor \frac{2026}{15} \rfloor = \lfloor 135.06... \rfloor = 135$

**6. 計算**
3または5で割り切れる数 = $675 + 405 - 135 = 945$

3でも5でも割り切れない数 = $2026 - 945 = 1081$

答え: 1081
