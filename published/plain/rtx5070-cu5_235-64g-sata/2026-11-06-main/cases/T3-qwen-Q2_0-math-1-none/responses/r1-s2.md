1 から 2026 までの整数のうち、3 でも 5 でもない割り切れない整数の個数を計算します。

**手順:**

1. **総数**: 1 から 2026 まで共有 2026 個。

2. **3 或 5 で割れる数（少なくとも 3 或 5 で割れる数）の数を計算する**:
    inclusion-exclusion principle (inclusion-exclusion principle,  inclusion-exclusion principle) を使用します。
   A = 3 で割り切れる数
   B = 5 で割り切れる数
   A ∪ B = 3 或 5 で割り切れる数
   A ∩ B = 3 且 5 で割り切れる数 = 15 で割り切れる数

   * **3 で割り切れる数 (A)**:
     $\lfloor \frac{2026}{3} \rfloor = \lfloor 675.33... \rfloor = 675$

   * **5 で割り切れる数 (B)**:
     $\lfloor \frac{2026}{5} \rfloor = \lfloor 405.2 \rfloor = 405$

   * **15 で割り切れる数 (A ∩ B)**:
     $\lfloor \frac{2026}{15} \rfloor = \lfloor 135.06... \rfloor = 135$

   * **3 或 5 で割り切れる数 (A ∪ B)**:
     $|A \cup B| = |A| + |B| - |A \cap B| = 675 + 405 - 135 = 1245$

3. **3 或 5 で割り切れない数**:
   $Total - |A \cup B| = 2026 - 1245 = 781$

答え: 781
