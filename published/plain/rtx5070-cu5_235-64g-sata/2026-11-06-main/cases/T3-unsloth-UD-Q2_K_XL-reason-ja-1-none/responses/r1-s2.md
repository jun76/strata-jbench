駅に到着した5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の順番を、与えられた条件から論理的に導き出します。

まず、ソウタとアオイの関係を考えます。「ソウタはアオイのすぐ後に着いた」とあるので、二人は [アオイ, ソウタ] というブロックで連続しています。

次に、他の条件を整理します。
1.  **ハルト < ミズキ** （ハルトはミズキより前）
2.  **ミズキ ≠ 3** （ミズキは3位ではない）
3.  **ミズキ ≠ 5** （ミズキは最後ではない）
    *   1と3より、ミズキの順位は 1, 2, 4 のいずれかです。
    *   2と1より、ハルトがミズキより前なので、ミズキが1位であることはできません。
    *   したがって、**ミズキは2位か4位**です。
4.  **ユイ ≠ 1, ユイ ≠ 5** （ユイは1位でも5位でもない）
    *   ユイの順位は 2, 3, 4 のいずれかです。
5.  **アオイ > ユイ** （アオイはユイより後）
6.  **ハルト ≠ 2** （ハルトは2位ではない）

ここで、ミズキの順位について場合分けを行います。

**ケース1：ミズキが2位の場合**
*   ミズキ=2なら、条件「ハルト < ミズキ」より、**ハルト=1**になります。（ハルトは1位のみ可能）
*   残りの順位は 3, 4, 5 で、残りの人はアオイ、ソウタ、ユイです。
*   「アオイ, ソウタ」は連続している必要があります。
    *   [アオイ, ソウタ] が入れられる位置は、(3,4) または (4,5) のみです（1,2は埋まっているため）。
*   また、「アオイ > ユイ」です。
    *   もし [アオイ, ソウタ] が (4,5) なら、アオイ=4 です。
        *   このとき、残りのユイは3位です。
        *   条件「アオイ(4) > ユイ(3)」を満たします。
        *   この場合の並びは：1位:ハルト, 2位:ミズキ, 3位:ユイ, 4位:アオイ, 5位:ソウタ。
        *   すべての条件を確認します。
            *   ハルト(1) < ミズキ(2) : OK
            *   ユイ(3) ≠ 1,5 : OK
            *   ソウタ(5) はアオイ(4)のすぐ後 : OK
            *   ミズキ(2) ≠ 3 : OK
            *   アオイ(4) > ユイ(3) : OK
            *   ハルト(1) ≠ 2 : OK
            *   ミズキ(2) ≠ 5 : OK
        *   このケースは成立します。この場合、**3位はユイ**です。
    *   もし [アオイ, ソウタ] が (3,4) なら、アオイ=3 です。
        *   このとき、残りのユイは5位です。
        *   条件「ユイ ≠ 5」に反するため、この配置は不可能です。

**ケース2：ミズキが4位の場合**
*   ミズキ=4なら、条件「ハルト < ミズキ」より、ハルトは1, 2, 3のいずれかです。
*   また「ハルト ≠ 2」なので、ハルトは1位か3位です。
*   残りの順位と人を考えます。
    *   [アオイ, ソウタ] は連続です。
    *   「アオイ > ユイ」です。
    *   「ユイ ≠ 1, 5」なので、ユイは2位か3位です。
*   ハルトの位置によって分けます。
    *   **ハルト=3** の場合：
        *   ミズキ=4, ハルト=3。残りの順位は1, 2, 5で、人はアオイ, ソウタ, ユイ。
        *   [アオイ, ソウタ] は連続でなければなりません。
        *   空いている連続する枠は (1,2) のみです（4,5はミズキがいるので不可、2,3はハルトがいるので不可）。
        *   よって、アオイ=1, ソウタ=2 です。
        *   残りのユイは5位になります。
        *   しかし条件「ユイ ≠ 5」に反するため、この配置は不可能です。
    *   **ハルト=1** の場合：
        *   ミズキ=4, ハルト=1。残りの順位は2, 3, 5で、人はアオイ, ソウタ, ユイ。
        *   [アオイ, ソウタ] は連続でなければなりません。
        *   空いている連続する枠は (2,3) のみです（4,5はミズキがいるのでアオイ5は不可能、またソウタはアオイの後なので5,6はない）。
        *   よって、アオイ=2, ソウタ=3 です。
        *   残りのユイは5位になります。
        *   しかし条件「ユイ ≠ 5」に反するため、この配置は不可能です。

したがって、ケース2はすべて成立せず、**ケース1のみが解**となります。

ケース1での到着順は以下の通りです。
1. ハルト
2. ミズキ
3. ユイ
4. アオイ
5. ソウタ

3位に到着したのはユイです。

答え: ユイ
