Let the prize be in each possible box:

- If the prize is in **A**, then label A is true, label B is true, and label C is false. That makes two true labels, which is not allowed.
- If the prize is in **B**, then label A is false, label B is false, and label C is true. That makes exactly one true label.
- If the prize is in **C**, then label A is false, label B is true, and label C is true. That makes two true labels.

Therefore, the prize must be in box **B**.

Answer: B
