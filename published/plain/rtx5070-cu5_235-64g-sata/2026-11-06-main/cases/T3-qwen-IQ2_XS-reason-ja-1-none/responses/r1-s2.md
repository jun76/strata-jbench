5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）が駅に到着した順番を、以下の条件から推論します。

**条件整理:**
1. ハルト < ミズキ (ハルトはミズキより前)
2. ユイ ≠ 1位, ユイ ≠ 5位
3. ソウタ = アオイ + 1 (アオイのすぐ後)
4. ミズキ ≠ 3位
5. アオイ > ユイ (ユイより後)
6. ハルト ≠ 2位
7. ミズキ ≠ 5位

**推論過程:**

*   **ハルトの位置:**
    *   ハルトはミズキより前なので、ハルトは1位または2位の可能性がありますが、条件6により「ハルトは2位ではない」とあります。
    *   よって、**ハルトは1位**です。

*   **ミズキの位置:**
    *   ハルト(1位)より後なので、2, 3, 4, 5位候補。
    *   条件4により「ミズキは3位ではない」。
    *   条件7により「ミズキは最後(5位)ではない」。
    *   したがって、ミズキは **2位** または **4位** です。

*   **ユイの位置:**
    *   条件2により「ユイは1位でも5位でもない」。ハルトが1位なので、ユイは2, 3, 4位候補。
    *   条件5により「ユイ < アオイ」。

*   **アオイとソウタの関係:**
    *   ソウタはアオイのすぐ後（アオイ+1）。
    *   ユイ < アオイ であるため、ユイはアオイより前です。

ここで、ユイの位置を特定するために場合分けします。

**ケースA: ミズキが2位の場合**
*   ハルト: 1位
*   ミズキ: 2位
*   残る人物: ユイ, アオイ, ソウタ
*   残る順位: 3位, 4位, 5位
*   ユイは2位ではない（条件2: 1位でも5位でもなし、かつ2位はミズキが占めている）ので、ユイは3位または4位。
*   アオイはユイより後なので、ユイが3位ならアオイは4位、ソウタは5位。
    *   この場合: 1位ハルト, 2位ミズキ, 3位ユイ, 4位アオイ, 5位ソウタ。
    *   条件チェック:
        *   ハルト(1) < ミズキ(2): OK
        *   ユイ(3): 1位でも5位でもなし: OK
        *   ソウタ(5)はアオイ(4)のすぐ後: OK
        *   ミズキ(2)は3位ではない: OK
        *   アオイ(4) > ユイ(3): OK
        *   ハルト(1)は2位ではない: OK
        *   ミズキ(2)は最後ではない: OK
    *   このケースでは3位は**ユイ**です。

**ケースB: ミズキが4位の場合**
*   ハルト: 1位
*   ミズキ: 4位
*   残る人物: ユイ, アオイ, ソウタ
*   残る順位: 2位, 3位, 5位
*   ユイは2, 3, 5位候補ですが、条件2で1位でも5位でもないため、ユイは **2位** または **3位** です。
*   アオイはユイより後。
*   ソウタはアオイ+1。

    *   **B1: ユイが2位の場合**
        *   アオイはユイ(2位)より後なので、アオイは3位または4位(ミズキ)または5位。
        *   アオイが3位なら、ソウタは4位。しかし4位はミズキなので矛盾。
        *   アオイが4位なら、ミズキなので矛盾（アオイは別人物）。
        *   アオイが5位なら、ソウタは6位（不存在）。矛盾。
        *   よって、ユイが2位は不可能。

    *   **B2: ユイが3位の場合**
        *   アオイはユイ(3位)より後なので、アオイは4位または5位。
        *   4位はミズキなので、アオイは5位。
        *   ソウタはアオイ(5位)のすぐ後 → 6位（不存在）。矛盾。

    *   **B3: ユイが5位の場合**
        *   条件2によりユイは5位ではない。矛盾。

    *   **B4: ユイがその他の位置？**
        *   残る順位は2, 3, 5。
        *   ユイが5位は不可。
        *   ユイが2位は不可能（上記B1）。
        *   ユイが3位は不可能（上記B2）。

    *   待って、Bの前提「ミズキが4位」の場合、残る順位は2, 3, 5です。
        *   ハルト(1), ミズキ(4).
        *   ユイは2, 3, 5のどれか。
        *   ユイは5位不可。
        *   ユイが2位なら: アオイは3位以上。ソウタはアオイ+1。
            *   アオイ3位 -> ソウタ4位(ミズキ)。矛盾。
            *   アオイ4位(ミズキ)。矛盾。
            *   アオイ5位 -> ソウタ6位。矛盾。
        *   ユイが3位なら: アオイは4位以上。
            *   アオイ4位(ミズキ)。矛盾。
            *   アオイ5位 -> ソウタ6位。矛盾。

    *   したがって、ミズキが4位である可能性は消去できます。

**結論:**
ケースAが唯一の正しい順序です。

順序:
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

3位に到着したのは **ユイ** です。

答え: ユイ
