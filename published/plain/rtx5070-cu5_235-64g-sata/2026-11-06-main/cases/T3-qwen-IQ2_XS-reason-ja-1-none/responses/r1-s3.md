与えられた条件を整理し、5人の到着順（1位～5位）を論理的に推測します。

**条件の整理**
1. ハルト < ミズキ（ハルトがミズキより前）
2. ユイ ≠ 1位、ユイ ≠ 5位
3. アオイ + 1 = ソウタ（アオイのすぐ後にソウタ）
4. ミズキ ≠ 3位
5. アオイ > ユイ（アオイがユイより後）
6. ハルト ≠ 2位
7. ミズキ ≠ 5位

**推論過程**

まず、ユイ（Y）の位置を考えます。
ユイは1位でも5位でもないので、ユイは2位、3位、または4位です。

また、「アオイ（A）のすぐ後にソウタ（S）」という条件から、(A, S)のペアは隣接している必要があります。考えられるペアの位置は (1,2), (2,3), (3,4), (4,5) です。

「アオイがユイより後」であるため、ユイ < アオイ が必要です。

ケースごとに検討します。

**ケース1：ユイが2位の場合**
- ユイ = 2位
- アオイ > ユイなので、アオイは3位、4位、5位でなければならない。
- (A, S)のペアが成立するため、Aの位置は1, 2, 3, 4のいずれか。
  - Aが1位ならS=2位。しかしユイ=2位なので矛盾。
  - Aが2位ならS=3位。しかしユイ=2位なので矛盾。
  - Aが3位ならS=4位。このとき、残りの位置は1位、5位。
    - 残りの人物：ハルト(H)とミズキ(M)。
    - 条件「ハルト < ミズキ」より、H < M。
    - 1位と5位にH, Mが入る可能性がある。
      - H=1, M=5 → 条件「ミズキは最後ではない(≠5位)」に矛盾。
      - H=1, M=2? No (ユイ=2)
      - 1位と5位だけ空いているなら、H=1, M=5は条件7に矛盾。
      - したがって、この配置は成立しません。
  - Aが4位ならS=5位。
    - 位置: Y(2), A(4), S(5).
    - 空いている位置: 1位, 3位。
    - 残りの人物: H, M。
    - 条件「ハルト < ミズキ」より、H < M。
    - 空いている1位と3位にH, Mを入れる。
      - H=1, M=3 → 条件「ミズキは3位ではない」に矛盾。
      - H=3, M=1 → H<Mではないため矛盾。
    - したがって、この配置も成立しません。

**ケース2：ユイが3位の場合**
- ユイ = 3位
- (A, S)のペアは (1,2), (2,3), (3,4), (4,5)。
  - Aが3位ならS=4位。しかしユイ=3位なので矛盾。
  - Aが1位ならS=2位。この場合、Y=3位。
    - 位置: A(1), S(2), Y(3).
    - 空いている位置: 4位, 5位。
    - 残りの人物: H, M。
    - 条件「ハルト < ミズキ」より、H < M。
    - 空いている4位, 5位にH, Mを入れる。
      - H=4, M=5 → 条件「ミズキは最後ではない(≠5位)」に矛盾。
    - したがって成立しません。
  - Aが2位ならS=3位。しかしユイ=3位なので矛盾。
  - Aが4位ならS=5位。
    - 位置: Y(3), A(4), S(5).
    - 空いている位置: 1位, 2位。
    - 残りの人物: H, M。
    - 条件「ハルト < ミズキ」より、H < M。
    - 空いている1位, 2位にH, Mを入れる。
      - H=1, M=2。
      - 条件「ハルトは2位ではない(H≠2)」→ H=1なのでOK。
      - 条件「ミズキは3位ではない(M≠3)」→ M=2なのでOK。
      - 条件「ユイは1位でも5位でもない」→ Y=3なのでOK。
      - 条件「ミズキは最後ではない」→ M=2なのでOK。
      - 条件「アオイがユイより後」→ A(4) > Y(3) なのでOK。
      - 条件「アオイのすぐ後にソウタ」→ A(4), S(5) でOK。
      - 条件「ハルト < ミズキ」→ H(1) < M(2) でOK。
    - この配置はすべての条件を満たします。
    - 配置: 1位:ハルト, 2位:ミズキ, 3位:ユイ, 4位:アオイ, 5位:ソウタ。
    - 質問「3位に到着したのは誰ですか？」に対する答えは「ユイ」。

**ケース3：ユイが4位の場合**
- ユイ = 4位
- (A, S)のペアは (1,2), (2,3), (3,4), (4,5)。
  - Aが3位ならS=4位。しかしユイ=4位なので矛盾。
  - Aが4位ならS=5位。しかしユイ=4位なので矛盾。
  - Aが1位ならS=2位。

    - 条件「ハルト < ミズキ」より、H < M。

      - H=5, M=3 → H<Mではないため矛盾。

  - Aが2位ならS=3位。
    - 位置: A(2), S(3), Y(4).
    - 空いている位置: 1位, 5位。
    - 残りの人物: H, M。
    - 条件「ハルト < ミズキ」より、H < M。
    - 空いている1位, 5位にH, Mを入れる。

唯一成立する配置はケース2でした。
