与えられた条件を整理して、5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の到着順を決定していきます。

**条件の整理:**
1. ハルト < ミズキ (ハルトはミズキより前)
2. ユイ $\neq$ 1位 かつ ユイ $\neq$ 5位 (ユイは2, 3, 4位)
3. ソウタ = アオイ + 1 (アオイのすぐ後にソウタ)
4. ミズキ $\neq$ 3位
5. アオイ > ユイ (アオイはユイより後)
6. ハルト $\neq$ 2位
7. ミズキ $\neq$ 5位 (最後ではない)

**ステップ1: ソウタとアオイのペアの可能性を考える**
アオイのすぐ後にソウタが来るため、(アオイ, ソウタ)のセットが取り得る順位は以下の組み合わせです。
- パターンA: アオイ1位, ソウタ2位
- パターンB: アオイ2位, ソウタ3位
- パターンC: アオイ3位, ソウタ4位
- パターンD: アオイ4位, ソウタ5位

これらそれぞれの条件を確認しながら進めます。

**ステップ2: 各パターンの検証**

**パターンA: アオイ1位, ソウタ2位**
- 条件5「アオイはユイより後に着いた」より、ユイ < アオイ。
- アオイが1位なので、ユイは1位より前になれず、矛盾します。
- **パターンAは不適。**

**パターンB: アオイ2位, ソウタ3位**
- 残り順位: 1, 4, 5
- 残り人物: ハルト, ミズキ, ユイ
- 条件5「アオイ(2位)はユイより後に着いた」より、ユイ < 2位 $\Rightarrow$ **ユイは1位**。
  - しかし条件2「ユイは1位ではない」に矛盾します。
- **パターンBは不適。**

**パターンC: アオイ3位, ソウタ4位**
- 残り順位: 1, 2, 5
- 残り人物: ハルト, ミズキ, ユイ
- 条件5「アオイ(3位)はユイより後に着いた」より、ユイ < 3位 $\Rightarrow$ ユイは1位または2位。
- 条件2「ユイは1位ではない」より、**ユイは2位**。
- 残り順位: 1, 5
- 残り人物: ハルト, ミズキ
- 条件1「ハルト < ミズキ」より、**ハルトは1位、ミズキは5位**。
  - しかし条件7「ミズキは最後(5位)ではない」に矛盾します。
- **パターンCは不適。**

**パターンD: アオイ4位, ソウタ5位**
- 残り順位: 1, 2, 3
- 残り人物: ハルト, ミズキ, ユイ
- 条件5「アオイ(4位)はユイより後に着いた」より、ユイ < 4位。これはすでに満たされています（ユイは1~3位のいずれか）。
- 条件2「ユイは1位でも5位でもない」より、ユイは2位または3位。
- 残りの順位1, 2, 3にハルト、ミズキ、ユイを配置します。
- 条件1「ハルト < ミズキ」
- 条件4「ミズキは3位ではない」
- 条件6「ハルトは2位ではない」

ここでユイの位置を考えます。
ユイは2位または3位です。

**ケースD-1: ユイが2位の場合**
- 残り順位: 1, 3
- 残り人物: ハルト, ミズキ
- 条件1「ハルト < ミズキ」より、ハルトは1位、ミズキは3位でなければならない。
- しかし条件4「ミズキは3位ではない」に矛盾します。
- **ケースD-1は不適。**

**ケースD-2: ユイが3位の場合**
- 残り順位: 1, 2
- 残り人物: ハルト, ミズキ
- 条件1「ハルト < ミズキ」より、**ハルトは1位、ミズキは2位**でなければならない。
- 条件6「ハルトは2位ではない」→ ハルトが1位なのでOK。
- 条件4「ミズキは3位ではない」→ ミズキが2位なのでOK。
- 条件7「ミズキは最後ではない」→ ミズキが2位なのでOK。
- 条件2「ユイは1位でも5位でもない」→ ユイが3位なのでOK。

この配置で全ての条件を満たすか確認します。
1. ハルト(1) < ミズキ(2) … OK
2. ユイ(3)は1位も5位でもない … OK
3. ソウタ(5)はアオイ(4)のすぐ後 … OK
4. ミズキ(2)は3位ではない … OK
5. アオイ(4)はユイ(3)より後 … OK
6. ハルト(1)は2位ではない … OK
7. ミズキ(2)は最後(5)ではない … OK

**最終的な順序:**
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ
