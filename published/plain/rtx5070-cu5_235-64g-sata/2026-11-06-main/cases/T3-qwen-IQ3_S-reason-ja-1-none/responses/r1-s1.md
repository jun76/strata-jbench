まず、与えられた条件を整理して、5人の到着順（1位から5位）を推論します。

**人物:** アオイ、ハルト、ミズキ、ソウタ、ユイ

**条件:**
1. ハルト < ミズキ （ハルトはミズキより前）
2. ユイ $\neq$ 1位, 5位 （ユイは2, 3, 4位のいずれか）
3. アオイ $\rightarrow$ ソウタ （アオイのすぐ後にソウタ。つまり、(アオイ, ソウタ) のペアが存在し、例えば (1,2) や (2,3) など）
4. ミズキ $\neq$ 3位
5. ユイ < アオイ （ユイはアオイより前）
6. ハルト $\neq$ 2位
7. ミズキ $\neq$ 5位 （ミズキは1, 2, 3, 4位のいずれか）

### 推論ステップ

**ステップ1: 「(アオイ, ソウタ) のペア」の位置候補を絞る**
条件3より、アオイとソウタは連続して並んでいます。
また、条件5よりユイ < アオイです。
したがって、アオイは1位になることはできません（ユイより後ろにいるため）。
また、アオイが1位でない以上、ペア (アオイ, ソウタ) の取り得る位置は以下の通りです。
- ケースA: アオイ=2位, ソウタ=3位
- ケースB: アオイ=3位, ソウタ=4位
- ケースC: アオイ=4位, ソウタ=5位

**ステップ2: ケースごとに他の条件との整合性を確認する**

**ケースA: アオイ=2位, ソウタ=3位**
このとき、残りの席は1位, 4位, 5位です。
残りの人は ハルト, ミズキ, ユイ です。
条件2より、ユイは1位でも5位でもないので、ユイは4位または（2位だが埋まっている）... ユイは2位には入れません。
ユイの候補は4位のみ？ いや、1,4,5が空いているが、ユイは1,5不可。よってユイは**4位**に決まります。
残りは1位, 5位。人はハルト, ミズキ。
条件1: ハルト < ミズキ。
1位, 5位にハルトとミズキを配置する場合、ハルト=1位, ミズキ=5位 となるしかない。
しかし、条件7: ミズキ $\neq$ 5位。
これは矛盾します。
よって、**ケースAは不適切**。

**ケースB: アオイ=3位, ソウタ=4位**
このとき、残りの席は1位, 2位, 5位です。
残りの人は ハルト, ミズキ, ユイ です。
条件2: ユイ $\neq$ 1位, 5位。
空いている席のうち、1位と5位があるので、ユイは2位に入る必要があります。
よって、**ユイ=2位**。
残りの席は1位, 5位。人はハルト, ミズキ。
条件1: ハルト < ミズキ。
1位, 5位に配置する場合、ハルト=1位, ミズキ=5位 となる。
しかし、条件7: ミズキ $\neq$ 5位。
これは矛盾します。
よって、**ケースBは不適切**。

**ケースC: アオイ=4位, ソウタ=5位**
このとき、残りの席は1位, 2位, 3位です。
残りの人は ハルト, ミズキ, ユイ です。
条件2: ユイ $\neq$ 1位, 5位。
空いている席は1, 2, 3位。
ユイは1位には入れないので、ユイは2位または3位です。

ここで、ミズキとハルトの位置を考えます。
条件4: ミズキ $\neq$ 3位。
条件6: ハルト $\neq$ 2位。
条件1: ハルト < ミズキ。

残りの3つの席(1, 2, 3)に、ハルト、ミズキ、ユイを配置します。

*   **ユイの位置について:**
    *   ユイが3位の場合:
        *   残りの席は1, 2位。人はハルト, ミズキ。
        *   ハルト < ミズキ なので、ハルト=1位, ミズキ=2位。
        *   条件6: ハルト $\neq$ 2位。これはOK (1位)。
        *   条件4: ミズキ $\neq$ 3位。これはOK (2位)。
        *   条件7: ミズキ $\neq$ 5位。これはOK。
        *   このパターンは成立します。
            *   1位: ハルト
            *   2位: ミズキ
            *   3位: ユイ
            *   4位: アオイ
            *   5位: ソウタ
            *   検証:
                *   ハルト(1) < ミズキ(2) -> OK
                *   ユイ(3) != 1,5 -> OK
                *   アオイ(4) -> ソウタ(5) -> OK
                *   ミズキ(2) != 3 -> OK
                *   ユイ(3) < アオイ(4) -> OK
                *   ハルト(1) != 2 -> OK
                *   ミズキ(2) != 5 -> OK
            *   この解は妥当です。この場合、3位は**ユイ**です。

    *   ユイが2位の場合:
        *   残りの席は1, 3位。人はハルト, ミズキ。
        *   条件4: ミズキ $\neq$ 3位。よってミズキは1位でなければならない。
        *   すると、ハルトは3位となる。
        *   条件1: ハルト < ミズキ。
        *   ここでは ハルト(3) < ミズキ(1) となり、これは「ハルトはミズキより前に着いた」という条件と矛盾します（3位は1位より後なので、ハルトはミズキより後ろになる）。
        *   よって、ユイが2位のパターンは成立しません。

    *   ユイが1位の場合:
        *   条件2によりユイは1位になれないため、不適切。

したがって、唯一成立するのは「ユイ=3位」のケースのみです。

### 最終的な到着順
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

3位に到着したのはユイです。

答え: ユイ
