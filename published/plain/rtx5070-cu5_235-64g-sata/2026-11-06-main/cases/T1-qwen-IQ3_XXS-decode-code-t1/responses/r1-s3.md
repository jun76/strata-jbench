# 単語出現頻度集計ツール (wordfreq)

## 設計

- **入力**: 1つ以上のテキストファイル（または標準入力）
- **オプション**: 上位 N 件（デフォルト 10）、大文字小文字区別の有無、ファイル名表示オプション
- **出力**: 表形式（rank / count / word）

## 実装: `wordfreq.py`

```python
#!/usr/bin/env python3
"""wordfreq - Count word frequencies in text files and display top N words."""

import argparse
import re
import sys
from collections import Counter
from typing import Optional, Sequence, TextIO


def tokenize(text: str) -> list[str]:
    """Split text into words using a regex pattern.

    Args:
        text: The input text to tokenize.

    Returns:
        A list of word tokens (lowercase by convention).

    Examples:
        >>> tokenize("Hello, World! Hello.")
        ['hello', 'world', 'hello']
    """
    return re.findall(r"[a-zA-Z']+", text)


def count_words(text: str, ignore_case: bool = True) -> Counter:
    """Count word frequencies in the given text.

    Args:
        text: The input text.
        ignore_case: If True, words are lowercased before counting.

    Returns:
        A collections.Counter with word -> frequency mapping.

    Examples:
        >>> count_words("The cat the Cat CAT")
        Counter({'cat': 3, 'the': 2})
        >>> count_words("The cat the Cat CAT", ignore_case=False)
        Counter({'The': 1, 'cat': 1, 'the': 1, 'Cat': 1, 'CAT': 1})
    """
    words = tokenize(text)
    if not ignore_case:
        return Counter(words)
    return Counter(w.lower() for w in words)
