与えられた条件から、5人の到着順（1位～5位）を論理的に推論します。

**1. ソウタとアオイの関係**
「ソウタはアオイのすぐ後に着いた」という条件から、ソウタとアオイは以下のいずれかの隣接する位置関係にあることが分かります。
- 1位：アオイ、2位：ソウタ
- 2位：アオイ、3位：ソウタ
- 3位：アオイ、4位：ソウタ
- 4位：アオイ、5位：ソウタ

**2. アオイとユイの関係**
「アオイはユイより後に着いた」という条件から、アオイの順位はユイより大きい（遅い）必要があります。
また、「ユイは1位でも5位でもない」とあるため、ユイは2位、3位、4位のいずれかです。

**3. ハルト、ミズキ、その他の条件**
- ハルトはミズキより前に着いた（ハルト < ミズキ）。
- ハルトは2位ではない。
- ミズキは3位ではない。
- ミズキは最後（5位）ではない。

これらの情報を組み合わせて、ケースごとに検討します。

---

**ケースA: アオイとソウタが1位と2位の場合**
アオイ=1位、ソウタ=2位
- アオイ(1)より後ろにユイがいる必要があるため、ユイは3,4,5位。
- ユイは5位ではないので、ユイ=3位 または 4位。
- 残りの人はハルトとミズキ。残りの順位は3,4,5からユイを除いた2つと、ユイが入らない1つ。
- ハルト < ミズキ かつ ハルト≠2位（2位はソウタなのでこれは自動的に満たされる）。
- ミズキ≠3位、ミズキ≠5位。
  - もしユイ=3位なら、残りの順位は4位と5位。ミズキは3,5不可なのでミズキ=4位、ハルト=5位になるが、ハルト<ミズキに違反する（5位は4位より後）。
  - もしユイ=4位なら、残りの順位は3位と5位。ミズキは3,5不可なのでミズキの位置がない。矛盾。
- よって、このケースは成立しません。

**ケースB: アオイとソウタが2位と3位の場合**
アオイ=2位、ソウタ=3位
- アオイ(2)より後ろにユイがいる必要があり、ユイ≠1,5。
- ユイは4位のみ可能（2,3は埋まっているため）。
- ユイ=4位。
- 残りの順位は1位と5位。残りの人はハルトとミズキ。
- ハルト < ミズキ なので、ハルト=1位、ミズキ=5位。
- しかし、条件「ミズキは最後ではない」に違反する。
- よって、このケースは成立しません。

**ケースC: アオイとソウタが3位と4位の場合**
アオイ=3位、ソウタ=4位
- アオイ(3)より後ろにユイがいる必要があり、ユイ≠1,5。
- ユイは4位しか取り得ないが、4位はソウタが占めている。矛盾。
- よって、このケースは成立しません。

**ケースD: アオイとソウタが4位と5位の場合**
アオイ=4位、ソウタ=5位
- アオイ(4)より後ろにユイがいる必要があり、ユイ≠1,5。
- 残りの順位は1位、2位、3位。
- ユイは1,5不可なので、ユイは2位または3位。

ここからユイの位置について考えます。

**子ケース D1: ユイ=2位の場合**
- 残りの順位は1位と3位。残りの人はハルトとミズキ。
- ハルト < ミズキ なので、ハルト=1位、ミズキ=3位。
- しかし、条件「ミズキは3位ではない」に違反する。
- よって、ユイ=2位は成立しません。

**子ケース D2: ユイ=3位の場合**
- 残りの順位は1位と2位。残りの人はハルトとミズキ。
- ハルト < ミズキ なので、ハルト=1位、ミズキ=2位。
- 条件を確認します。
  - ハルト(1) < ミズキ(2) → OK
  - ユイ(3) は1位でも5位でもない → OK
  - ソウタ(5) はアオイ(4)のすぐ後 → OK
  - ミズキ(2) は3位ではない → OK
  - アオイ(4) はユイ(3)より後 → OK
  - ハルト(1) は2位ではない → OK
  - ミズキ(2) は最後ではない → OK
- すべての条件を満たします。

したがって、到着順は以下のようになります。
1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

3位に到着したのはユイです。
