与えられた条件をもとに、5人の到着順番（1位〜5位）を論理的に推論していきます。

**1. アオイとソウタの関係、およびユイとの関係**
*   「ソウタはアオイのすぐ後に着いた」より、アオイとソウタは連番で、かつアオイ < ソウタ（番号が小さいほど早い）です。
    *   可能性のあるペア：(1,2), (2,3), (3,4), (4,5)
*   「アオイはユイより後に着いた」より、ユイ < アオイ です。
    *   よって、アオイが1位であることはできません。（ユイが0位になるため）
    *   アオイとソウタのペアは (2,3), (3,4), (4,5) に限定されます。
    *   この時、ユイはアオイより早い位置にいなければなりません。

**2. ユイの位置の絞り込み**
*   「ユイは1位でも5位でもない」より、ユイは 2位、3位、4位のいずれかです。

**3. パターン別の検証**

**ケースA：アオイとソウタが (4,5) である場合**
*   アオイ=4, ソウタ=5
*   ユイはアオイ(4)より早いので、ユイは 1, 2, 3 のいずれか。
*   ユイは1位ではないので、ユイは 2位 または 3位。
*   残りの人は ハルト と ミズキ で、残りのポジションは (1, ?) と (?, ?) です。
    *   もしユイ=2位なら、残り1位と3位にハルトとミズキが入ります。
        *   「ハルトはミズキより前に着いた」より、ハルト < ミズキ。
        *   よって ハルト=1位, ミズキ=3位。
        *   しかし、「ミズキは3位ではない」という条件と矛盾します。
    *   もしユイ=3位なら、残り1位と2位にハルトとミズキが入ります。
        *   「ハルトはミズキより前に着いた」より、ハルト=1位, ミズキ=2位。
        *   ここで「ハルトは2位ではない」（OK）、ミズキは3位ではない（OK）、ミズキは最後ではない（OK）を確認。
        *   このパターンでの順位は以下の通り：
            1. ハルト
            2. ミズキ
            3. ユイ
            4. アオイ
            5. ソウタ
        *   全ての条件を確認：
            *   ハルト(1) < ミズキ(2) → OK
            *   ユイ(3) は1位・5位ではない → OK
            *   ソウタ(5) はアオイ(4)のすぐ後 → OK
            *   ミズキ(2) は3位ではない → OK
            *   アオイ(4) > ユイ(3) → OK
            *   ハルト(1) は2位ではない → OK
            *   ミズキ(2) は最後ではない → OK
        *   このパターンは成立しています。この場合、3位は**ユイ**です。

    *   さらに他の可能性がないか確認します。
    *   もしユイ=2位、アオイ=4, ソウタ=5で、ハルト/ミズキが1/3の場合、ミズキが3位になってしまうためNGでした。

**ケースB：アオイとソウタが (3,4) である場合**

*   ユイはアオイ(3)より早いので、ユイは 1位 または 2位。

**ケースC：アオイとソウタが (2,3) である場合**
