# 単語出現頻度集計ツール

以下は、テキストファイルを読み込んで単語の出現頻度を集計し、上位 N 件を表形式で表示するコマンドラインツールです。

wordfreq.py — テキストファイルの単語出現頻度を集計し、上位 N 件を表形式で表示する。

使い方:
    python wordfreq.py <input_file> [-n N] [-i] [--width WIDTH]

オプション:
    -n, --top     表示する上位件数 (デフォルト: 10)
    -i, --case    大文字/小文字を区別しない (デフォルト: 区別する)

    """単語とその出現回数を保持するデータクラス。"""
    word: str
    count: int

    def __str__(self) -> str:
        return f"{self.word}\t{self.count}"


def tokenize_text(text: str, case_sensitive: bool = False) -> Counter[str]:
    """
    テキストから単語トークンを抽出し、Counter で頻度を集計する。

    Args:
        text: 入力テキスト。
        case_sensitive: False の場合、単語を小文字に変換して集計する。

    Returns:
        単語ごとの出現回数を Counter で返す。
    """
    # Unicode 対応の単語区切り: \w+ で単語トークンを抽出
    tokens: list[str] = re.findall(r"\w+", text, re.UNICODE)

    if not case_sensitive:
        tokens = [token.lower() for token in tokens]

    return Counter(tokens)
