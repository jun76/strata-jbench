Word Frequency Counter CLI Tool.

Usage:
    python word_count.py <file> [--top N] [--min-length M] [--ignore-case]

Arguments:

        "file",
        type=Path,
        help="Path to the input text file",
    )

        "--top",
        type=int,

    )

        "--min-length",
        type=int,
        default=1,
        help="Minimum word length to consider",
    )

        "--ignore-case",
        action="store_true",
        help="Ignore case when counting words",
    )
    return parser.parse_args()
