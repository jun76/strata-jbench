Let the prize be in one box and check the truth of the labels.

- If the prize is in **A**:
  - A says “The prize is in this box” → true
  - B says “The prize is not in this box” → true
  - C says “The prize is not in box A” → false  
  Two labels are true, so this is impossible.

- If the prize is in **B**:
  - A says “The prize is in this box” → false
  - B says “The prize is not in this box” → false
  - C says “The prize is not in box A” → true  
  Exactly one label is true, so this works.

- If the prize is in **C**:
  - A says “The prize is in this box” → false
  - B says “The prize is not in this box” → true
  - C says “The prize is not in box A” → true  
  Two labels are true, so this is impossible.

Therefore, the prize is in box B.

Answer: B
