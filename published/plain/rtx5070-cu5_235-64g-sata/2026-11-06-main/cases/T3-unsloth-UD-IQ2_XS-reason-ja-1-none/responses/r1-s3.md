5人（アオイ、ハルト、ミズキ、ソウタ、ユイ）の到着順を論理的に推論していきます。

**1. 条件の整理**
*   (1) ハルト < ミズキ
*   (2) ユイ ≠ 1, ユイ ≠ 5
*   (3) ソウタ = アオイ + 1 （アオイの直後がソウタ）
*   (4) ミズキ ≠ 3
*   (5) アオイ > ユイ （アオイはユイより後）
*   (6) ハルト ≠ 2
*   (7) ミズキ ≠ 5

**2. 推理プロセス**

**ステップ1：ユイとアオイの関係からスタート地点を絞る**
条件(3)より、アオイとソウタは必ず隣接しており、「アオイ, ソウタ」の並びで存在します。
条件(5)より、ユイはアオイより前にいるため、ユイ < アオイ < ソウタ という順序関係が成り立ちます。
つまり、ユイ、アオイ、ソウタの3人はこの順番で並んでおり、ソウタは最低でも3位以上（ユイが1位ならソウタは3位）になります。また、アオイはソウタの直前なので、アオイは最大でも4位です（ソウタが5位の場合）。

条件(2)より、ユイは1位か5位ではありません。
ユイ < アオイ < ソウタ という関係があるため、ユイが5位であることはあり得ません（アオイがもっと後ろになる必要があるため）。よって、ユイは2位、3位、4位の可能性がありますが、アオイとソウタの存在により制限されます。

**ステップ2：ハルトの位置を考える**
条件(1)より、ハルト < ミズキ。
条件(6)より、ハルト ≠ 2。
条件(4)(7)より、ミズキ ≠ 3, ミズキ ≠ 5。

まず、ハルトが1位であるケースと、ハルトが3位以上であるケースを検討します。

**ケースA：ハルトが1位の場合**
ハルト=1です。
残りの人はミズキ、ソウタ、ユイ、アオイです。
ハルト(1) < ミズキ なので、ミズキは2〜5位です。
しかし、ミズキ ≠ 3, ミズキ ≠ 5 ですので、ミズキは **2位か4位** です。

同時に、ユイ < アオイ < ソウタ のブロックがあります。
ユイは1位ではないので、ユイは3位以降の可能性がありますが、アオイ、ソウタが続くため、ユイは最大でも3位です（ユイ=3ならアオイ=4, ソウタ=5）。
もしユイ=4ならアオイ=5, ソウタ=6となり不可能。
もしユイ=2ならアオイ=3, ソウタ=4またはアオイ=3, ソウタ=4... wait, アオイとソウタは隣接。
ユイ=2なら、アオイとソウタは3,4或者4,5のセット。

サブケースA1：ミズキ=2の場合
ハルト(1), ミズキ(2)
残り：3, 4, 5位に ユイ, アオイ, ソウタ のブロック（ユイ<アオイ<ソウタ、かつアオイとソウタは隣接）。
ユイは3位から始められません。なぜなら、ユイ=3ならアオイ=4, ソウタ=5で「ユイ(3), アオイ(4), ソウタ(5)」となり、これは条件を満たします。

このケースでは、**3位はユイ** となります。

サブケースA2：ミズキ=4の場合
ハルト(1), ミズキ(4)
残り：2, 3, 5位に ユイ, アオイ, ソウタ のブロック。
ユイ < アオイ < ソウタ かつ アオイ-ソウタ隣接。
ユイが2位なら、アオイとソウタは3,4或者4,5のセット。
4位はミズキなので、アオイ、ソウタが4位に入れない。
したがって、ユイ=2, アオイ=3, ソウタ=4 は不可（4位はミズキ）。
ユイ=2, アオイ=?, ソウタ=?
残りは3位と5位だが、アオイとソウタは隣接しなければならず、3と5は隣接していない。
よって、ユイ=2の場合、アオイとソウタは並べられない。
ユイ=3なら、アオイ=4, ソウタ=5 だが4位はミズキ。不可。
よってミズキ=4の場合、ユイ、アオイ、ソウタを配置できない。
したがって、ハルトが1位のときはミズキは2位でなければならず、その結果ユイが3位になります。

**ケースB：ハルトが3位の場合**
ハルト=3です。
条件(1) ハルト(3) < ミズキ なので、ミズキは4位か5位です。
条件(4)(7) ミズキ ≠ 3, ミズキ ≠ 5 なので、ミズキは **4位** しかあり得ません。
ハルト(3), ミズキ(4)
残りの人：ユイ, アオイ, ソウタ
残り順位：1位, 2位, 5位
ユイ < アオイ < ソウタ かつ アオイ-ソウタ隣接。
ソウタが5位だとすれば、アオイは4位。しかし4位はミズキです。矛盾。
ソウタが2位だとすれば、アオイは1位。
ユイ < アオイ(1) は不可能です（1位より前は存在しない）。
よって、ハルトが3位のケースは成立しません。

**ケースC：ハルトが4位の場合**
ハルト(4) < ミズキ なので、ミズキは5位です。
しかし条件(7)より ミズキ ≠ 5 です。
よって、ハルトが4位のケースは成立しません。

**ケースD：ハルトが5位の場合**
ハルト(5) < ミズキ となる人は存在しません。
よって、ハルトが5位のケースは成立しません。

**ケースE：ハルトが2位の場合**
条件(6)より ハルト ≠ 2 なので除外。

以上より、唯一成立するケースは **ケースA** です。
