If the prize were in box A, then labels A and B would both be true, which is not allowed.

If the prize were in box C, then labels B and C would both be true, which is also not allowed.

If the prize is in box B, then:
- Label A is false.
- Label B is false.
- Label C is true.

This gives exactly one true label, so the prize is in box B.

Answer: B
