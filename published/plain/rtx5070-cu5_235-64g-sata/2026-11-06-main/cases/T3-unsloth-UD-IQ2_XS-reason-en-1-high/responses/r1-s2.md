If the prize is in box A:
- Box A's label is true.
- Box B's label is true.
- Box C's label is false.

That gives two true labels, which is not allowed.

If the prize is in box B:
- Box A's label is false.
- Box B's label is false.
- Box C's label is true.

That gives exactly one true label, which works.

If the prize is in box C:
- Box A's label is false.
- Box B's label is true.
- Box C's label is true.

That gives two true labels, which is not allowed.

Therefore, the prize must be in box B.

Answer: B
