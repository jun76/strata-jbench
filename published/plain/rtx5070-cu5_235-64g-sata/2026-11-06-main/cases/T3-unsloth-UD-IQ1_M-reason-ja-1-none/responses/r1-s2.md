この論理パズルを解くために、与えられた条件を整理し、各人の到着順位を推論していきます。

1人から5人までの順位を1〜5とします。
人物：アオイ、ハルト、ミズキ、ソウタ、ユイ

**条件：**
1. ハルト < ミズキ （ハルトはミズキより前）
2. ユイ ≠ 1, ユイ ≠ 5
3. ソウタ = アオイ + 1 （アオイのすぐ後。アオイの順位を $A$、ソウタを $S$ とすると $S = A + 1$）
4. ミズキ ≠ 3
5. ユイ < アオイ （ユイはアオイより前）
6. ハルト ≠ 2
7. ミズキ ≠ 5

---

### ステップ1：ソウタとアオイの位置を考える
条件3より、「アオイ」の直後が「ソウタ」です。
可能な（アオイ、ソウタ）の組み合わせは以下の4パターンです。
- (1, 2)
- (2, 3)
- (3, 4)
- (4, 5)

### ステップ2：ユイとアオイの位置関係から絞り込む
条件5より、ユイ < アオイ です。
また、条件2より、ユイは1位か5位ではありません（2, 3, 4位のみ）。

もし **アオイ=1** だと、その前にユイがいられないため、アオイは1位ではありません。
したがって、（アオイ, ソウタ）= (1, 2) は除外されます。

残るパターン：
- A: (2, 3) → アオイ=2, ソウタ=3
- B: (3, 4) → アオイ=3, ソウタ=4
- C: (4, 5) → アオイ=4, ソウタ=5

それぞれのケースを検証します。

---

### ケースA：アオイ=2, ソウタ=3
ユイ < アオイ(2) なので、ユイは **1位** しかありません。
しかし、条件2で「ユイは1位でもない」とあります。
→ **矛盾するため、このケースは除外されます。**

### ケースB：アオイ=3, ソウタ=4
ユイ < アオイ(3) なので、ユイは **1位または2位** です。
条件2よりユイは1位ではないので、**ユイ=2** です。

現在の順位：
1: ?
2: ユイ
3: アオイ
4: ソウタ
5: ?

残りの人物は **ハルト** と **ミズキ**。
残りの順位は **1位** と **5位**。

条件1：ハルト < ミズキ
1位と5位では、ハルト=1, ミズキ=5 が成立します。

しかし、条件7で「ミズキは最後（5位）ではない」とあります。
→ **矛盾するため、このケースは除外されます。**

### ケースC：アオイ=4, ソウタ=5
ユイ < アオイ(4) なので、ユイは **1, 2, 3位** のどれかです。
条件2よりユイは1位ではないので、ユイは **2位または3位** です。

現在の確定情報：
4: アオイ
5: ソウタ

残りの順位：**1, 2, 3**
残りの人物：**ハルト, ミズキ, ユイ**

ここで残った人物と順位への配置を考えます。

**ミズキの制限：**
条件1：ハルト < ミズキ
条件4：ミズキ ≠ 3
条件7：ミズキ ≠ 5（すでに5位はソウタなのでOK）

**ハルトの制限：**
条件6：ハルト ≠ 2

利用可能な順位：1, 2, 3

ミズキが3位になれないので、ミズキは **1位か2位** です。

- **もしミズキ=1なら：**
  ハルト < ミズキ(1) は不可能（1位より前は無い）。
  → ミズキは1位ではありません。

- **したがって、ミズキは2位しかありません。**
  ミズキ=2 を仮定します。

ミズキ=2 の場合：
残りの順位：**1, 3**
残りの人物：**ハルト, ユイ**

条件1：ハルト < ミズキ(2) なので、ハルトは **1位** でなければなりません。
ハルト=1 を確認します。
条件6：ハルト ≠ 2 （1位なのでOK）

残った人物はユイで、残った順位は3位です。
ユイ=3 を確認します。
条件2：ユイは1位でも5位でもない（3位なのでOK）
条件5：ユイ(3) < アオイ(4) （OK）

すべての条件を満たす配列が得られました。

---

### 最終的な順位確認

1位: ハルト
2位: ミズキ
3位: ユイ
4位: アオイ
5位: ソウタ

**条件チェック：**
1. ハルト(1) < ミズキ(2) → OK
2. ユイ(3) は1位でも5位でもない → OK
3. ソウタ(5) はアオイ(4)のすぐ後 → OK
4. ミズキ(2) は3位ではない → OK
5. ユイ(3) < アオイ(4) → OK
6. ハルト(1) は2位ではない → OK
7. ミズキ(2) は最後ではない → OK

したがって、3位に到着したのはユイです。

答え: ユイ
